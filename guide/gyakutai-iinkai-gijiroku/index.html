虐待防止委員会の議事録ひな形と例｜放課後等デイサービスの議題例・身体拘束適正化委員会

虐待防止委員会の議事録には、開催日時・場所・出席者（管理者または虐待防止担当者を含む）、検討した事例と分析、決定事項（担当・期限）、従業者への周知方法を書きます。身体拘束等適正化委員会と一体開催する場合は、身体拘束等の実施状況の確認と、事例がなくても支援の状況を確認したことも残します。解釈通知では委員会の対応状況を記録し5年間保存することとされています。議事録は実際に開いた会議の記録であり、開いていない会議の議事録を作ってはいけません。

まず1分で確認：あなたの事業所に減算のリスクがあるかを無料で診断し、必要な書類の雛形をその場で作れます（登録不要）。

減算リスクを無料診断書類テンプレートを無料で作る

虐待防止委員会は年1回以上の開催が必要で、運営指導では「開いたこと」を議事録で確認されます。議事録がなかったり、中身から委員会として検討したことが読み取れなかったりすると、委員会を開いていない状態と同じように扱われるおそれがあります。

結論から言うと、議事録に必要なのは次の5点です。

  1. いつ・どこで・誰が集まったか（管理者または虐待防止担当者の出席が分かること）
  2. 何を検討したか（報告された事例の集計・分析、職場環境の確認など）
  3. 何を決めたか（再発防止策・改善策と、担当者・期限）
  4. 結果をどう従業者に周知したか（方法と日付）
  5. 身体拘束等適正化委員会と一体開催する場合は、身体拘束等についても検討したこと

減算そのものの要件（委員会・研修・担当者）は「虐待防止措置未実施減算とは？」、身体拘束の4要件は「身体拘束廃止未実施減算とは？」の記事で解説しています。この記事は議事録の書き方に絞ります。

項目書く内容ポイント

開催日時・場所年月日、開始・終了時刻、場所（オンラインならその旨）テレビ電話装置等での開催も認められています

議事録の例（放課後等デイサービス・記入例）

以下は、架空の放課後等デイサービス「さくらんぼ教室（架空）」の議事録の記入例です。事業所・人物・出来事はすべて架空です。自分の事業所で実際に話し合った内容に置き換えて使ってください。

項目記入例
名称虐待防止委員会（身体拘束等適正化委員会と一体開催）議事録
開催日時2026年9月18日（金）17:30〜18:30
場所さくらんぼ教室（架空）相談室
出席者管理者（委員長・虐待防止担当者）、児童発達支援管理責任者、児童指導員2名、保育士1名
欠席者なし
議題1. ヒヤリハット報告シートの運用状況 2. 教室を飛び出そうとした場面への対応 3. 職員の言葉づかい 4. 身体拘束の実施状況と指針の見直し 5. 虐待防止研修の実施 6. 結果の周知方法・次回予定
検討内容（抜粋）4月の委員会で決めたヒヤリハット報告シートは4〜8月で7件提出（送迎時4件、活動中の他児とのトラブル3件）。夏休み中、利用者Aが教室を飛び出そうとした際、職員が後ろから両腕をつかんで止めた場面があった（けがなし、職員本人から報告）。身体拘束に当たるかは意見が分かれた。保護者には管理者から当日中に電話で説明済み。職員間で強い口調が出ることがあるとの意見が保育士からあった。身体拘束は現在行っていないことを確認した
決定事項1. 出入口付近に職員が1名立つ配置にする 2. パーテーションで仕切ったクールダウンスペースを用意する（扉は閉めない） 3. 強い口調に気づいたら職員同士で声をかけ合う 4. やむを得ない場合の手続きは指針どおりとし、指針の見直しは次回委員会で行う 5. 10月に全職員対象の虐待防止研修（60分）を実施、講師は児童発達支援管理責任者、欠席者には資料と動画で個別に実施
周知方法9月の職員会議で管理者から報告し、議事録を休憩室に掲示する。会議欠席者には個別に伝達し、確認欄に署名をもらう
次回予定2027年3月

記入例のポイントは次のとおりです。

  • 「身体拘束に当たるか判断が分かれた」場面も、そのまま書いて構いません。判断に迷った事例を検討し、同じ場面を防ぐ方法を決めたことこそが、委員会の記録として意味を持ちます。
  • 決定事項には、実際の議事録では担当者と期限の欄を設けて埋めます。
  • 書類サンプルのページでは、この記入例の元になった議事次第・議事録・身体拘束等適正化の確認チェックリストを全文で公開しています。

議題の例（放デイ・児発でよく取り上げる議題）

解釈通知は、委員会の役割として「虐待防止のための計画づくり」「虐待防止のチェックとモニタリング」「虐待発生後の検証と再発防止策の検討」の3つを挙げています。身体拘束適正化検討委員会では、身体拘束等の報告事例の集計・分析と、身体拘束等を行わない支援方法の検討が中心です。これに沿って、放課後等デイサービス・児童発達支援で取り上げやすい議題を例としてまとめました。毎回すべてを扱う必要はありません。年間計画に割り振って使ってください。

時期の例議題の例委員会の役割との対応議事録に残すこと
年度初め年間計画（委員会・研修の時期）、担当者・委員の確認、指針の確認計画づくり開催予定月、研修の時期と講師、担当者名

長期休暇の前夏休み・冬休みの活動内容と体制、外出時のリスク計画づくり職員配置と注意点
研修の前後研修の内容・講師・欠席者へのフォロー、理解度テストの結果計画づくり研修の日程、参加状況、次回への改善点
年度末指針の見直し、1年間の振り返り、次年度計画案計画づくり見直し日と変更点（変更なしも記録）
随時（臨時開催）虐待やその疑いがある事案の検証と再発防止策発生後の検証事実経過、市町村への通報の有無、再発防止策

虐待やその疑いがある事案は、委員会の開催を待たずに対応します。障害児通所支援の従事者による障害児への虐待が疑われる場合は、障害者虐待防止法により市町村への通報義務があります。事業所内の委員会で検討しただけで終わらせないでください。

結果の周知方法の記録

解釈通知は、委員会での検討結果を従業者に周知徹底することを求めています。議事録に「周知する」と書いただけでは、実際に伝わったかどうかが分かりません。周知の方法ごとに、次のような記録を残しておくと確認しやすくなります。

周知の方法残す記録注意点
職員会議で報告職員会議の議事録（報告日、報告者、出席者）欠席者への伝達方法を別に決めておきます
議事録の掲示掲示日、掲示場所掲示しただけでは読んだか分からないため、確認欄を併用すると確実です
回覧回覧表（氏名、確認日、確認印または署名）非常勤職員・送迎担当なども対象に含めます
メール・業務チャット送信日、送信先、既読や返信の記録記録を印刷するか保存場所を決めておきます
欠席者・新規採用者への個別説明説明日、説明者、相手の署名新規採用者には研修とあわせて説明すると漏れが減ります

周知した内容に、利用者や家族が特定できる情報が含まれる場合は、掲示や回覧の範囲に配慮します。個人名をイニシャルや「利用者A」に置き換えるなどの工夫をしましょう。

身体拘束適正化委員会の議事録（一体開催するときの書き方）

虐待防止委員会と身体拘束等適正化委員会（解釈通知上の名称は「身体拘束適正化検討委員会」）は、一体的に設置・運営できます。一体開催の場合も、身体拘束等について検討したことが議事録から読み取れるようにしてください。

  • 名称に「身体拘束等適正化委員会と一体開催」と書く
  • 議題に「身体拘束等の実施状況」を独立した項目として立てる
  • 身体拘束等を行った事例があれば、記録（態様・時間・心身の状況・緊急やむを得ない理由）がそろっているか、3要件（切迫性・非代替性・一時性）を組織として確認したかを検証した結果を書く
  • 事例がなかった場合も「実施なし」と書き、未然防止の観点から支援の状況を確認した内容（判断に迷う場面がなかったか、環境の工夫など）を残す
  • 指針の見直しを行った場合は、見直した日と変更点を書く

運営指導でよくある不備

  • 議事録がない、またはメモ書きだけで日付・出席者が分からない
  • 出席者に管理者も虐待防止担当者もいない、または誰が担当者か分からない
  • 検討内容が「特になし」だけ。報告事例がない場合でも、支援の状況や職場環境を確認した内容が必要です
  • 決定事項に担当者・期限がないため、次回の委員会で実行状況を確認できない
  • 周知の記録がない。「職員会議で報告」と書いてあるのに、職員会議の記録に該当する報告がない
  • 一体開催のはずが、身体拘束等について何も書かれていない
  • 毎回ほぼ同じ文面の議事録が続いている。前回の決定事項の検証や新しい事例の検討がないと、委員会として機能しているか疑問を持たれます

実際に開いていない会議の議事録を作ってはいけません

議事録は、実際に開いた会議の記録です。運営指導の直前に、開いていない委員会の議事録を作ったり、開催日や出席者を事実と違う内容で書いたりしてはいけません。

  • 都道府県知事等から報告や帳簿書類の提出を命じられた際（障害者総合支援法第48条第1項。監査などで用いられます）に虚偽の報告をすることは、指定の取消しや効力停止の事由として法律に定められています（同法第50条第1項第7号。障害児通所支援は児童福祉法第21条の5の22第1項・第21条の5の24第1項第7号）。運営指導の資料として作った記録も、監査に移行すれば同じ扱いになりえます
  • 放課後等デイサービス・児童発達支援などの障害児通所支援でも、児童福祉法に同じ仕組みがあります。報告や帳簿書類の提出を命じられた際（同法第21条の5の22第1項）に虚偽の報告をすることは、指定の取消し等の事由です（同法第21条の5の24第1項第7号）
  • 減算を免れる目的であれば、給付費の請求に関する不正（障害者総合支援法第50条第1項第6号、児童福祉法第21条の5の24第1項第6号）として扱われるおそれもあります
  • 何より、委員会を開かないままでは、虐待の未然防止という本来の目的が果たせません

委員会を開いていなかったことに気づいたら、すぐに委員会を開き、その日付のまま正しく記録してください。減算の扱いや改善計画の提出が必要かどうかは、指定権者に相談しましょう。

よくある質問

虐待防止委員会の議事録に決まった様式はありますか？

国が定めた統一様式はありません。開催日時・場所、出席者（管理者または虐待防止担当者を含む）、検討内容、決定事項、従業者への周知方法が分かれば形式は問われません。指定権者が参考様式を示している場合はそれに合わせると確認がスムーズです。

報告された虐待やヒヤリハットが0件でも委員会を開く必要がありますか？

はい。委員会は年1回以上の開催が必要で、事例がなくても開きます。議事録には「報告0件」と書いたうえで、職場環境や支援の状況を確認した内容、研修計画などを残しましょう。身体拘束適正化検討委員会についても、事例がない場合に支援の状況等を確認することが解釈通知で求められています。

議事録はどのくらいの期間保存すればよいですか？

解釈通知では、委員会における対応状況を適切に記録し5年間保存することとされています。事業所の指定基準を定めた条例で別の年限が定められていることもあるため、指定権者に確認してください。

委員会を開き忘れていました。過去の日付で議事録を作ってもよいですか？

いけません。開いていない会議の議事録を作ることは虚偽の記録にあたり、監査などで虚偽の報告として扱われれば指定の取消し等の事由になりえます。すぐに委員会を開いてその日付で記録し、減算や改善計画の扱いは指定権者に相談してください。
