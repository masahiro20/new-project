Allowlist Builder デモ

.mcp.json や VS Code の mcp.json を貼り付けると、起動設定ルールでサーバーごとに approve / review / deny を判定し、承認したものだけで managed-mcp.json と allowedMcpServers を生成します。判定はすべてこのページの中で行い、入力内容はどこにも送信しません。

判定は静的な「パターンを検出」した結果です。悪意や安全性を断定するものではありません。実在のプロジェクト名が出る箇所の検出も、パターンの指摘であって悪意の断定ではありません。

設定を貼り付けて判定

INPUT → VERDICT

mcpServers（Claude Code / Claude Desktop）と servers（VS Code）の両方に対応。コメントと末尾のカンマも読めます。入力するたびに再判定します。

シークレットの直書き（env・ヘッダー・URL のクエリ・--password などの引数）は ${VAR} に置き換えてから出力します。URL のクエリを置き換えたサーバーは、serverUrl をホストとパスで照合するパターン（例：https://host/path?*）にして、実際の URL と照合できるようにします（Claude Code の serverUrl は * に対応。Copilot 側の * 対応は未確認）。引数を置き換えた stdio サーバーの serverCommand は完全一致なので、配布前に確認してください。managed-mcp.json はマシン上の全ユーザーが読めるため、値は各ユーザーの環境で設定してください。

    

  


  

    
検査済みサンプル

    
公開リポジトリ100件のステージ2検査（regex＋AST、コードは実行していない）から代表例を静的データとして同梱しています。名前を選ぶと、そのサーバーで検出したパターンを表示します。検出は「パターン」であり、各プロジェクトの悪意を断定するものではありません。

    

      

      

    

  


  

    
Atlas は静的解析のみを行い、検査対象のコードを実行しません。判定は参考情報であり、安全性を保証するものではありません。

    
このページは外部と通信しません。外部の通信を行うコード・フォント・画像を含まず、サンプルデータとルールはページに埋め込まれています。
