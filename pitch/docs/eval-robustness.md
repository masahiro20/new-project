# 劣化条件での頑健性評価（P3 Pitch、2026-10-09）

人の声での評価（`docs/eval-plan.md`、録音者待ちで保留）の代わりに、合成音声に実際の録音に近い劣化を加えて
判定の合格率を測り、どの条件に弱いかを一覧にしました。**判定の改善はしていません**（別担当）。
ここにあるのは測定と原因の切り分けだけです。

スクリプト：`scripts/eval-robustness.mjs`（node で実行、外部通信なし）

```sh
node scripts/eval-robustness.mjs                       # 既定：300語（＋最小対）× seed 3 × 全82条件、4コアで約19分
node scripts/eval-robustness.mjs --words 40 --seeds 1  # 手早く（約2分）
node scripts/eval-robustness.mjs --conditions noise,reverb-0.8,clip-20   # 軸名・条件 id・接頭辞* で絞る（baseline は常に含む）
node scripts/eval-robustness.mjs --list                # 条件の一覧
#   --md out.md  表を保存   --csv fails.csv  失敗サンプルと中間値   --json all.json  全記録
#   --fails 5    条件ごとの失敗例   --workers N   --from-json all.json  保存した記録から集計だけやり直す
```

## 1. 方法

- **流れはアプリと同じ：** 劣化させた音声 → `pickUtterance`（demo/decode.js、最大 4 s）→ `normalize` →
  `extractF0`（vendor/pitchy）→ `judge`（既定値のまま、区切りは auto）。
- **音声：** `synthesizeWord`（src/synth.js）と同じ合成。スクリプト内の `synth()` はその写しで、
  (1) きしみ声のオプション、(2) 正解の F0 と有声区間の出力だけを足したもの（きしみ声なしでは
  `synthesizeWord` とビット単位で一致することを起動時に確認します）。合成は常に 16 kHz で行い、
  他のサンプルレートへは窓付き sinc で変換します（注意 4 を参照）。
- **基準の話者：** 140 Hz、下がり目 3.5 半音、下がり傾向 0.4 半音/モーラ、ゆらぎ ±0.15 半音、モーラ長 0.15 s（±25 %）、
  「が」×1.3、16 kHz、雑音なし、前後 0.25 s の無音。各条件はここから1つの軸だけを変えます（＋代表的な組み合わせ9つ）。
- **語：** `data/lexicon-2000.json` から（モーラ数 × 型）で層化した 300 語（固定 seed、各層最低3語）＋
  同じかなでアクセントの違う語（最小対、68語）を必ず含め、計 **360語**。
- **読み：** 各語を辞書どおりの k（正しい読み）と、`demo/lexicon.js` の `wrongK`（ページの「違う発音」と同じ k）で言わせます。
  seed 3つ（語・seed ごとに合成の乱数を固定し、全条件で同じ音声を使う＝対応のある比較）。1条件あたり
  正しい読み 1,080、違う読み 1,077 サンプル、全体で 174,903 サンプル（無声化の条件だけ対象の31語）。
- **区間：** 語単位のクラスタ・ブートストラップ（1,000回）の 95 % 区間。同じ語の seed 違いは独立でないためです。
  あわせて seed ごとの合格率の最小–最大（seed 幅）を出しています。
- **SNR** は、きれいな音声の発話区間（最初のモーラの始まり〜「が」の終わり）の平均パワーに対する比です。

### 原因の切り分け（中間値）

失敗したサンプル（正しい読みの不合格、違う読みの合格）ごとに中間値を記録し、次の順で主因を1つ決めます。

1. **切り出し(VAD)**：`pickUtterance` が発話を 50 ms を超えて切り落とした。
2. **判定不能**：`judge` がエラー（no-voice / too-short）。有声率 < 50 % なら **F0追跡** に数える。
3. **発話範囲(span)**：`judge` の span（有声区間＋エネルギーによる最大約1モーラの延長）の始端か終端が、正解から 0.5 モーラを超えてずれた。
4. **区切り**：正解のモーラ境界で区切り直して同じテンプレート当てはめをすると合否が正しくなる（＝オラクル）。
5. **F0追跡**：正解の境界でも F0 が1フレームも残らないモーラがある、有声率 < 50 %、または F0 大誤差（正解から 2 半音超）≥ 10 %。
6. **段差不足(minStep)**：F0 も境界も正しいが、H/L の差が `minStep`（1.2 半音）未満で平板と読まれた。
7. **当てはめ(テンプレート)**：F0 も境界も正しいのに、型の当てはめが外れた。

表の列：有声率 = 正解で有声のフレームのうち `cleanTrack` 後に F0 が残った割合（中央値。基準でも子音の境目と
立ち上がりで 94 %）、F0 大誤差 = 残ったフレームのうち正解から 2 半音以上ずれた割合（平均）、境界誤差 = 語内のモーラ境界の誤差の
中央値、span = 始端 / 終端の誤差（モーラ単位、符号付き中央値。始端の負＝早すぎ、終端の正＝遅すぎ）、オラクル = 正解の境界で
区切った場合の正しい読みの合格率。

## 2. 要約

**基準：正しい読みの合格率 99.9 %［99.7–100.0］、誤合格率 0.0 %、k の完全一致 99.9 %**（`eval-segmentation` と同程度）。

各軸の最悪値（正しい読みの合格率／誤合格率）：

| 軸 | 最悪の条件 | 合格率 | 誤合格率 | 現実的な範囲での目安 |
|---|---|---|---|---|
| 話者 | 280 Hz | 95.8 % | 0.3 % | 85–240 Hz は 99.0 % 以上 |
| 話速 | モーラ長 0.09 s | 99.0 % | 0.0 % | ほぼ影響なし |
| ピッチの幅 | 下がり目 1.0 半音 | 52.5 % | 50.4 % | 1.5 半音で 93.4 %、2 半音以上で 99.5 % 以上（6 半音で 96.9 %）。下がり傾向 1.2 半音/モーラで 65.4 % |
| ノイズ | ハム 50 Hz・SNR 5 dB | 2.0 % | 0.1 % | SNR 20 dB で 90.6–95.0 %、10 dB で 81.1–90.1 % |
| 響き | RT60 1.2 s | 68.2 % | 8.5 % | RT60 0.2 s でも 76.2 % |
| マイク | AGC | 91.9 % | 0.7 % | 電話帯域 94.8 %。AAC・クリッピング・サンプルレートは 98 % 以上 |
| 録音の前後 | 話し声の環境音（前 5 s） | 94.3 % | 1.1 % | 無音・クリック・吸気・操作音は 99.9 % 以上 |
| 発話の性質 | 無声化 | 62.4 % | 17.2 % | 語末きしみは合格率 90.8 % だが **誤合格率 31.8 %** |
| 組み合わせ | スマホ・カフェ | 59.7 % | 19.0 % | スマホ・静かな部屋 84.0 %、電話 88.5 % |

**一番の発見：失敗の大半は1つの仕組みから来ています。** 雑音・響き・AGC・話し声の環境音で落ちた分の
ほぼすべてが「発話範囲(span)」で、正解の境界で区切れば（オラクル）94–100 % 合格します。F0 そのものはほとんど正しく
（F0 大誤差 ≈ 0 %）、`judge` の発話範囲の端がずれて、モーラ枠全体が前後にずれているのが原因です。
ずれた枠では「が」の枠に「が」以外の音が入るので、**尾高（下がり目が「が」の直前）と中高が特に落ちます**
（RT60 0.8 s で尾高 1 %、中高 22 %、平板 100 %。ピンク 20 dB で尾高 79 %、中高 74 %）。平板はほとんど影響を受けません。

## 3. 弱点の上位（推定原因つき）

実際の録音で起きやすさも考えて並べています（合格率の単純な順位は 4 章の「弱い条件」の表）。

1. **部屋の響き（RT60 0.2–1.2 s で 68–76 %、誤合格 4–9 %）— 発話範囲（終端）。**
   span の終端の誤差は中央値 +1.3（RT60 0.2 s）〜 +4.3 モーラ（1.2 s）。残響の尾にも声の周期性が残るので、pitchy が
   「が」の後も 0.2–0.5 s ほど有声と判定し（発話の外での有声 0.48 s、RT60 0.8 s）、span がそこまで伸びます。
   その結果「が」の枠が後ろにずれて広がり、下がり目が早く（または平板に）読まれます（不合格の型は「早い」と「平板」がほぼ半々）。
   オラクルは 96–99 %、有声率は 88–94 % で、F0 追跡や区切りの手がかりの問題ではありません。
   DRR +3 dB はやや厳しめの設定ですが、RT60 0.2 s（よく吸音された部屋）でも 76 % なので、普通の部屋でも起きると見ます。
2. **定常ノイズ・話し声（SNR 20 dB で 93.8–95.0 %、10 dB で 81–90 %）— 発話範囲（両端）。**
   span の始端 −0.64、終端 +0.82 モーラ（ピンク 20 dB）。`judge` の `utteranceSpan` は、エネルギーが「大きいフレームの
   95 パーセンタイル −30 dB」以上ならば有声区間の外へ最大約1モーラまで延長します。雑音が −30 dB より大きい（SNR がおよそ 30 dB 未満）と
   雑音の区間が全部「音あり」になり、**両端が毎回いっぱいまで延長されます**。白色・ピンク・ハム 50 Hz の SNR 30 dB では起きません（99.8–99.9 %）。
   AGC も同じ（雑音床を持ち上げるので始端 −0.65 モーラ）。SNR 5 dB になると有声率が 28–58 % まで落ち、F0 追跡の失敗が加わります。
3. **電源ハム（60 Hz は SNR 30 dB でも 96.2 %、SNR 5 dB で 50 Hz 2.0 %・60 Hz 10.2 %、誤合格 26.5 %）— F0 追跡。**
   pitchy はハムの周期にロックします。50 Hz は `fmin`（60 Hz）未満なので全フレームが捨てられて「声が聞こえない」（有声率 0 %）、
   60 Hz は範囲内なので 60/120 Hz を F0 として拾い（F0 大誤差 95 %）、でたらめな型になります。SNR 10–20 dB では
   主因は 2. と同じ発話範囲です。ノート PC の充電中などで起きやすい雑音です。
4. **無声化（該当31語で 62.4 %、誤合格 17.2 %）— 発話範囲（始端）。**
   語頭のモーラが無声化し、次のモーラが破裂音・破擦音で始まる語で 36–44 %（機械 きかい、月 つき、靴 くつ、舌 した、歯科 しか、
   不幸 ふこう は3 seed とも不合格）、語中の無声化は 100 %。span は有声区間から前へエネルギーをたどって延長しますが、次のモーラの閉鎖（無音）で延長が止まるため、
   無声化した最初のモーラの分だけ始端が遅れます（始端 +1.07 モーラ）。無声化は破裂音・破擦音の前で起きる
   のが普通なので、実際の発話でもこの組み合わせが多いはずです。中高・尾高・頭高で落ち、平板は 100 %。
5. **きしみ声（強：76.1 %・誤合格 21.0 %、語末のみ：誤合格 31.8 %）— F0 追跡。**
   きしんだ区間は pitchy の clarity が下がって有声率が 53 %（強）・67 %（語末）に落ちます。語末（「が」）だけがきしむと、
   **平板の語を尾高で（「が」で下げて）言っても合格**します（誤合格 336件のほぼすべてがこの組み合わせ）。「が」の F0 が
   ほとんど残らず、残ったフレームは直前の高い部分の尾なので「が」が高く読まれるためです（分類上は「当てはめ」に入りますが、
   実態は「が」の枠の F0 欠落）。きしみ声は文末・低い音で起きやすく、まさに「が」の位置です。

ほかに目立つもの：

- **下がり傾向が強い話し方（1.2 半音/モーラで 65.4 %）— 当てはめ。** 平板の語が 28 % しか合格しません（3–4 モーラで顕著）。
  `maxDeclination`（0.6 半音/モーラ）を超える下がり傾向は当てはめで吸収できず、最後の方の「下がり」として読まれます（不合格の型は「遅い」）。
  F0 も境界も正しい（オラクルも 65.5 %）ので判定モデルの限界です。0.8 半音/モーラまでは 99.8 %。
- **下がり目の小さい話し方（1.0 半音で正しい合格 52.5 %・誤合格 50.4 %、1.5 半音で 93.4 %・3.9 %）— 段差不足。** `minStep` 1.2 半音の
  まわりで判定が二分されるのは仕様どおりです。学習者の「平板気味の声」が 1.0–1.5 半音だと、正しい場所で下げても半分は「下がっていない」
  と言われ、違う型でも半分は合格します。閾値の妥当性は人の声で確かめる必要があります。
- **電話帯域（300–3400 Hz で 94.8 %）・下がり目 6 半音（96.9 %）— F0 追跡。** どちらも「はし」「つゆ」「てにす」のような、
  無声子音で始まる短い第1モーラが頭高（k = 1）のときに、そのモーラの F0 が1フレームも残らず平板と読まれます。
  基本周波数が帯域外になる・急な下降で clarity が下がる、のどちらかで短い母音のフレームが消えるためです。
- **高い声（280 Hz で 95.8 %）・「が」が長い（×2.5 で 96.7 %）— 区切り／発話範囲。** 280 Hz では終端 +0.48 モーラ
  （声の余韻を長く有声と判定）、「が」×2.5 では「が」の枠が事前分布（×1.2）よりはるかに長く、境界が前にずれます（オラクル 100 %）。

**問題にならなかったもの：** 話速 0.09–0.22 s（99.0 % 以上）、85–240 Hz、ゆらぎ ±1 半音まで、白色・ピンク・バブル・ハム 50 Hz の
SNR 30 dB、帯域 100–7000 Hz、コンプレッサ、クリッピング +6 / +12 dB（+20 dB で 98.3 %）、AAC 64 / 32 kbps、サンプルレート 8–48 kHz、
前後の無音（0–3 s）、クリック音、吸気音、操作音、きしみ声（弱）。`pickUtterance` による切り落とし（VAD）は、
スマホ・カフェの組み合わせ（36件、3 %）以外ではほぼ起きていません。

**誤合格の多い条件**（違う読みを合格にする、学習者の信頼を最も損なう失敗）：下がり目 1.0 半音 50.4 %、語末きしみ 31.8 %、
ハム 60 Hz 5 dB 26.5 %、バブル 5 dB 22.6 %、きしみ声（強）21.0 %、スマホ・カフェ 19.0 %、無声化 17.2 %。
手順書の目標（誤合格 5 % 以下）を超えるのは、このほか響き（RT60 0.4 s 以上：5.2–8.7 %）、SNR 5 dB の雑音（白色 10.6 %、ピンク 8.1 %）、
ハム 60 Hz 10 dB（5.1 %）、下がり傾向 1.2 半音/モーラ（6.7 %）と、組み合わせ4つ（低い男性＋速い＋響き 12.5 %、ノート PC 9.9 %、
平板気味＋ピンク 20 dB 5.8 %、スマホ・カフェ）です。

### 改善担当への手がかり（測定から言えることだけ）

- 発話範囲の端（`utteranceSpan`）が最大の要因です。雑音の大きさに応じた基準（雑音床からの相対値）にすること、
  残響の尾を有声区間に入れないこと（エネルギーの減衰や clarity の低下で終端を決める）が効きそうです。
  ただし、どれも合成音声での推測なので、人の声で確かめてから採用してください。
- 語頭の無声化は、延長が閉鎖（無音）で止まることが原因です。
- ハムは F0 抽出の前にハムを除く（ノッチ／ハイパス）ことが考えられます。

## 5. 注意（合成音声の限界）

1. **これは人の声の評価の代わりにはなりません。** 合成音声は母音がきれいな倍音列で、F0 の微細な揺れ・声質・
   調音結合・子音のスペクトルが実際とは違います。とくに残響の尾や雑音の中で pitchy がどこまで有声と判定するかは、
   実際の声では変わり得ます。順位（どの条件が弱いか）と原因の方向を見るためのもので、絶対値は目安です。
2. **劣化のモデルは単純です。** 残響は指数減衰の雑音（初期反射の構造なし、DRR は固定）、バブルは合成のブザー声 6人、
   AGC・コンプレッサは一般的な形を1つずつ、AAC は ffmpeg の内蔵エンコーダ（iPhone の Apple AAC とは別物）です。
   スマホの実際の処理（雑音抑圧、エコーキャンセル、ビームフォーミング）は入れていません。雑音抑圧は 2. の発話範囲の問題を
   軽くする方向にも、F0 を削る方向にも働き得ます。
3. **話者の性質は1つずつ変えています。** 実際の話者は複数の軸が同時に動きます（例：低い声ほどきしみやすい）。
   組み合わせ9つはその一部だけです。無声化・きしみ声の「辞書どおりの型で言った」という前提も、実際の発話では
   聞き取りで確かめる必要があります（無声化したモーラに下がり目があると、実際には位置がずれて聞こえることがあります）。
4. **`synthesizeWord` の振幅の平滑化はサンプル単位です**（`va += (vt − va) · 0.01`）。そのため 8 kHz で合成すると声の立ち上がりと余韻が
   2倍長くなり（16 kHz の約 68 ms に対して約 135 ms）、それだけで判定が 85 % まで落ちました（開発中の88語での試行。判定の問題ではなく合成の問題）。
   このスクリプトでは常に 16 kHz で合成し、窓付き sinc で変換しています。`synthesizeWord` を 16 kHz 以外で使う他のテスト・スクリプトにも
   同じ偏りがあります（`m4a.test.js` は 48 kHz で合成しています。余韻が短くなる方向なので判定には有利）。
5. **語は 360 語（2,000語から層化＋最小対）です。** 5 モーラの頭高や 4 モーラの尾高のように語数の少ない層は各層 3 語程度なので、
   層ごとの数字はぶれます。無声化の条件は該当する 31 語だけで、区間が広くなっています（46–79 %）。
6. **主因の判定は規則によるものです**（1 章）。複数の原因が重なるサンプルは最初に当てはまったものに数えています。
   語末きしみの「当てはめ」のように、規則の名前と実態がずれる場合は本文で補っています。`--csv` で全失敗の中間値が出るので、
   個々のサンプルはそこで確認できます。
