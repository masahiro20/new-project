## 最小対で練習 (minimal-pair practice) — 2026-10-09

- 2026-10-09: 「最小対（minimal pair）」＝かなが同じでアクセントが違う語。アクセントの組がまったく同じ語は1つの選択肢にまとめます（紙・髪 → 1つの答え）。そのため 川・皮・革 や 雲・蜘蛛 は対になりません。
- 2026-10-09: 複数のアクセントを持つ語：選択肢として使えるのは、他のどの選択肢も認めない *区別できる* k を持つ場合だけです（鹿[0,2] 対 歯科[1,2] → 0 対 1）。グループには使える選択肢が2つ以上必要です。巣/酢、脳/能、錨/怒り、機械/機会、鳴き声/泣き声 は除外しました。2,000語の辞書での結果：29グループ（かなが同じグループ61のうち、アクセントが違うものは34）。
- 2026-10-09: 合成サンプル、ドリルの問題、H/L の表示には各選択肢の区別できる k を使うので、ドリルがどちらとも取れる型を再生することはありません。
- 2026-10-09: 分類は k の完全一致のみです（`classifyAgainstPair`）：match / ambiguous（目標と別の選択肢が k を共有）/ other / none。「最も近い k」への代替はしません。k の数値上の距離は聞こえ方の距離ではないためです（0 と n は が でしか違わない）。
- 2026-10-09: 録音は目標の語に対して `judge()` で判定します。対としての判定は `r.pass` ではなく、検出した k から決めます。
- 2026-10-09: ファイル処理の流れ（decode → pickUtterance → F0 → judge）と `play()` は `demo/pipeline.js` に移し、demo.js と practice.js で共有します。practice.js にはこの処理を `initPractice(deps)` で注入するので、その純粋関数はブラウザなしで Node のテストから読み込めます。
- 2026-10-09: タブではなく、メインページの1セクション（ヘッダーにジャンプリンク付き）にしました。既存の判定画面の DOM／QA の約束事に手を触れずに済むためです。練習モードは `window.__practiceLast` / `window.__practiceDrill` に書き込み、`__pitchLast` や `#result` には決して書きません。
- 2026-10-09: ドリルのスコアはそのセッションだけです（localStorage なし）。消すものも、共用端末に残るものもありません。ドリルの声は毎回変えます（シード、基本周波数 115–200 Hz）。学習者が特定のサンプル1つではなく、音の形そのものを聞くようにするためです。

## 結果の共有カード画像・Anki への書き出し — 2026-10-09

- 2026-10-09: コードは `demo/share.js` と `demo/anki.js` にあります。demo.js は `mountShare`/`mountAnki` を import し、判定のたびに `afterJudge({ result, word, track, source })` を1回呼ぶだけです。古いカードの扱いは `#result[data-state]` を、Anki の検索結果の件数は `#word-select` を MutationObserver で監視するので、demo.js にこれ以上フックを足す必要はありません。
- 2026-10-09: 共有カード＝ `drawShareCard(ctx, prepareShareCard(…))` で作る 1200×630 の PNG。データ準備は純粋関数（0–1 に正規化した座標、H/L、短い理由）で単体テスト済み、描画は記録用のスタブ context でテストしています。常にライトテーマのトークンを使い、フォントはシステムの日本語フォントです。ファイル名も音声も含めません。
- 2026-10-09: カードは常に `<img src="data:…">` のプレビューと「画像を長押し（右クリック）で保存できます」の表示で見せます。claude.ai の Artifact で確実に動くのはこの方法だけだからです。「共有」は `navigator.canShare({ files })` が true のときだけ表示し（拒否 → メッセージ、AbortError は無視）、そうでなければトップレベルのページでのみダウンロードボタンを出します。
- 2026-10-09: 「ダウンロードできる」＝ `window.top === window.self`。Artifact はサンドボックス化された iframe で動き（ダウンロードは黙って遮断されます）、PWA とローカルで開いたファイルはトップレベルです。Anki 用テキストには、コピーと `<textarea readonly>`（全文選択済み、`execCommand('copy')` の代替あり）をどの環境でも用意します。
- 2026-10-09: Anki ファイル＝ `#separator:tab`、`#html:true`、`#notetype:Basic`、`#deck:Pitch::Accent`、`#columns`、`#tags column:3` を持つ TSV で、その後に "Accent data: UniDic (NINJAL), BSD licence" という `#` コメントを置きます（TSV にはデッキの説明欄がないため）。各フィールドは HTML エスケープし（`"` を含む）、改行 → `<br>`、タブ → 空白にするので、1行は必ずちょうど3フィールドになります。
- 2026-10-09: 裏面はインラインスタイルのみを使います（標準の Basic ノートタイプには CSS がないため）。高いモーラに上線、下がり目に右の罫線、が は薄く表示し、さらに `L H ＋L` のテキスト行、「尾高型［2］ 「はし」の後、「が」で下がる」、訳語を載せます。複数のアクセントを持つ語は、認められるアクセントをすべて並べます。タグ：認められる型ごとに `pitch::<type>`、`p3pitch`、さらに範囲に応じて `pitch::minimal-pair` / `pitch::failed`。
- 2026-10-09: 最小対の範囲は demo/practice.js の `buildMinimalPairs` を再利用します（練習モードと同じ定義）。その形が将来変わった場合は「かなが同じで、異なるアクセントが2つ以上」に切り替えます。
- 2026-10-09: 「この回で不合格だった単語」は、判定画面で判定した実際の録音だけを数えます。合成サンプル（読み込み時の自動サンプルを含む）は除外します。練習モードの試行は数えません（判定画面を通らないため）。そのセッションだけで、何も保存しません。

## 2026-10-09 — 「wrong」サンプルは っ／ん／ー での下がり目を避ける（Kana）
- `wrongK` は特殊モーラでの下がり目を選ばなくなりました。っ での下がり目は聞き取れない（F0 がない）ので、区切りの修正（っ の枠はピッチを持たない）以降、そのようなサンプルは平板と区別できず、意味のある誤った読みになりません（筆者 [1,0] で k=2 を使っていた）。判定自体はこの変更で変わりません。変わるのは、デモが「wrong」として再生する対比だけです。

## 2026-10-09 — Artifact からのファイル保存（Kana）
- Artifact は `downloads` capability を宣言しています。`saveBlob` は、使える場合は `claude.use("downloads").save()` を使い（閲覧者が確認します）、そうでなければトップレベルのページ（PWA／ブラウザ）で `<a download>` リンクを使います。コピーと画像プレビューは代替手段として残します。

## 評価協力モード — 2026-10-09

- 2026-10-09: 目的は、ネイティブ話者や学習者の録音と判定結果を **端末内だけ** に貯め、本人が自分で zip に書き出して開発者に渡せるようにすること。ページは何も送信しません（渡し方は本人任せ）。コードは `demo/evalmode.js`。demo.js は `afterJudge` に `samples, rate` を足して `evalMode.judged(e)` を呼ぶだけ、practice.js は `deps.onJudged` を1か所で呼ぶだけです。
- 2026-10-09: 既定はオフ。オンにするには、保存するもの・保存しないもの・保存場所・消し方の説明を読んでチェックを入れる必要があります。オンはそのページを開いている間だけで、再読み込みするとオフに戻ります（保存済みの録音は削除するまで残ります）。同意する前は IndexedDB のデータベースも作りません（読み込み時は `indexedDB.databases()` で既存の保存があるかだけを調べ、調べられないブラウザでは「保存済みの録音を表示」ボタンを出します）。
- 2026-10-09: 保存する音声は **元のファイルではなく、判定に使った部分（最長約4秒）を 16 kHz・モノラル・16 bit の wav にしたもの**。1件 ≤ 約128 KB で、100件でも約13 MB。元のファイルは長さも形式もばらばらで（12秒のメモ、m4a・webm など）、iPhone のボイスメモには録音場所や機器名などのメタデータが入ることがあり、前後に関係ない会話が入ることもあるためです。ファイル名も保存しません（氏名が入っていることがある）。16 kHz への変換は `src/f0.js` の `resample`（F0 解析と同じ）。判定はブラウザが出した元のサンプリング周波数で行うので、wav から再判定すると結果がわずかに変わることがあります（元の周波数は JSON に記録）。
- 2026-10-09: 保存する判定結果：pass、verdict、detectedK、expectedK、equivalentK、flat、高低の幅、segments（ラベル・時刻・値）、F0 列（20 ms に間引き、Hz と半音）。candidates や 10 ms の全フレームは保存しません。判定できなかった録音（声が検出できない等）も保存します（判定不能率の評価に使うため）。合成音声のサンプルは判定画面でも練習モードでも保存しません（`source.kind === 'file'` のときだけ）。
- 2026-10-09: 本人が入力する情報は選択肢だけ（自由記述なし）：話者の区分（答えない／日本語ネイティブ／学習者 入門・初級／中級／上級）、出身地域（答えない／東京方言圏／それ以外）、どの型で言ったつもりか（わからない／辞書どおり／違う型で言った＋k）。練習モードの録音は、選んだターゲットの型で言ったつもりとして記録します。
- 2026-10-09: 保存先は IndexedDB（`p3pitch-eval`、wav は ArrayBuffer で保存）。開けない環境（プライベートブラウズ、サイトデータのブロックなど）ではモードを無効にし、理由を表示します。全件削除はページ内の確認ステップ（`confirm()` は Artifact の iframe で使えないため使わない）。
- 2026-10-09: 書き出しは依存なしの自前 zip（無圧縮 STORE＋CRC32、ファイル名は UTF-8 フラグ付き）：`README.txt`（中身の説明、録音の権利は話者にある旨、開発者に渡す場合の同意文、端末内の消し方）、`manifest.json`、各録音の `rec-NNN-wXXXX.wav` と `.json`。ファイル名は `Pitch-eval-YYYYMMDD.zip`。保存は anki.js の `saveBlob`（Artifact では downloads 機能、PWA ではダウンロード）。

## 創設サポーター（買い切り）— 2026-10-09

- 2026-10-09: 方針は `peter-hq/revenue/p3-monetization.md` と本部の決定 d31：最初の有料は「創設サポーター」買い切り（$19 の案）。売るのは判定と関係のない機能（回数・単語リスト・Anki・記録・練習の範囲）で、判定の質では差を付けません。月額はまだ出しません。購入画面に「判定はベータで調整中です。精度を約束するものではありません。」と明記します。
- 2026-10-09: 購入は Ko-fi、キーは手作業で送る前提。登録のない静的なページなので **署名つきのライセンスキー** にし、ページに埋め込んだ公開鍵だけで、端末の中で検証します（外部への通信なし）。署名は WebCrypto の ECDSA P-256／SHA-256（iOS Safari を含めて広く使える。Ed25519 は使わない）。
- 2026-10-09: キーの中身は 9 バイト（版・通し番号・発行日・機能フラグ）＋署名 64 バイト。氏名・メールなどの個人情報は入れません。署名するのは `"P3PITCH-SUPPORTER-v1\0"` ＋中身（ほかの用途の署名と取り違えないため）。表記は Crockford base32 を5文字ずつハイフンで区切り、先頭に `PITCH-`（約145文字）。大文字小文字・前後の空白・改行・全角・ハイフン類（ー・－ など）の揺れを吸収し、O→0、I/L→1 と読みます。余りのビットが 0 でない書き方は拒否します。
- 2026-10-09: 公開鍵は `demo/supporter-pubkey.js`（JWK）。**本番の鍵ペアはまだ作りません**（秘密鍵の保管者はオーナー・本部の判断）。`null`（未設定）のあいだはキー入力欄を「準備中」にし、どのキーも何も解除しません（fail closed）。取り消しは同じファイルの `REVOKED_SERIALS`（通し番号）。保存済みのキーもページを開くたびに検証し直すので、取り消しは公開し直したページから効きます。
- 2026-10-09: 秘密鍵はリポジトリの外にだけ置きます。`scripts/supporter-key.mjs init` は git の作業ツリーの中への保存を拒否し、0600 で新規作成のみ（上書きしない）。`issue` は秘密鍵と公開鍵ファイルが対でないとき・取り消し済みの番号のときは発行しません。`.gitignore` に `*.pem` など。テスト用の公開鍵を差し込むビルド（`SUPPORTER_PUBKEY=…`）は `dist/`・`site/` に書けません。
- 2026-10-09: 検証済みのキーは localStorage（`pitch-supporter-key`、try/catch）に保存し、解除の状態はページ内の状態（`createEntitlement`）として持ちます。保存できない環境では、そのページを開いている間だけ解除します。
- 2026-10-09: 無料／サポーターの差は `gatesFor()` 1か所、数字とお金の表示は `PLAN` 1か所（仮置きの値と、オーナー判断待ちの値には TODO）。判定：無料は1日20語。**異なる語の数** で数え、同じ語のやり直しは数えません（同じ語を言い直すのが練習の中心なので）。録音ファイルで判定できたときだけ数え、合成音声のサンプル・聞き分けドリル・判定できなかった録音は数えません。判定画面と練習の言い分けで共通。日付は端末の時計（ローカルの 0 時で切り替わり）。上限の案内は「判定の中身は同じで、違うのは回数だけ」と書きます。
- 2026-10-09: 評価協力モードがオンのあいだは、1日の上限を適用せず数えもしません。精度の検証（Pro に進む条件）を止めないためです（オンにするには同意が必要で、録音も端末に保存されるので、抜け道としての旨みは小さい）。
- 2026-10-09: 最小対：無料は聞き分けドリルを `buildMinimalPairs` の先頭5組（はし・あめ・はな・かき・かみ）だけ。言い分け（録音で判定）はどの組でも使えます（判定の回数の上限だけが効く）。Anki：無料は「この回で不合格だった単語」だけ、サポーターは この単語・検索結果・自分の単語リスト・最小対 を含む全部。共有カードは両方とも同じ。
- 2026-10-09: 自分の単語リスト（`demo/mylists.js`、サポーター）：名前つきで複数。判定画面の単語・検索結果をまとめて追加、語を押すと判定画面でその語を選ぶ、「リストの次の語を練習」、Anki に書き出し（タグ `pitch::mylist`）。保存は localStorage（`pitch-lists-v1`）。キーを削除しても消さず、操作できなくなるだけです。
