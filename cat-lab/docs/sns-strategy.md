# SNSでシェアされるための設計メモ

## 誰が、なぜシェアするのか

| 気持ち | 設計 |
|---|---|
| **うちの子を自慢したい**（いちばん強い動機） | カードの主役は猫。名前を大きく、猫種どおりの見た目で描く。**実際の写真も入れられる**（端末内だけで処理） |
| **「わかる〜」と言われたい** | 口ぐせ・特技・弱点などの「あるある」をカードに載せる。見た人が自分の猫に当てはめて反応できる |
| **人と比べたい** | レア度（UR 4% / SSR 12% / SR 34% / R 50%）とレーダーチャート。「うちはSSRだった」が会話のきっかけになる |
| **自分も「いい人」に見られたい** | 結果はどれも愛情がベース（家来も執事もオタクも、猫を大事にしている）。ネガティブな結果は出さない |

## 体験の流れ

1. **トップ**：完成カードの見本を最初に見せる（何がもらえるか一目でわかる）
2. **うちの子をえらぶ**：37種。猫種名は愛称（スコ・ブリショーなど）で、選ぶだけで楽しい
3. **12の「もしも」**：結果が予想しにくい質問。猫種専用の2問で「うちの子のことだ」と感じさせる
4. **カード開封**：ガチャのような開封演出とレア度の発表で、気分が上がった瞬間にシェアボタンを出す
5. **シェア**：保存（長押しでも可）、ストーリーズ用の縦長画像、X、LINE。写真でつくり直しもできる
6. **拡散の入口**：カード下部に「#猫様との関係診断 あなたの家の猫様は？」。見た人が同じ診断を探せる

## 見た目のルール

- 白ベース＋いちごミルク色のピンクを差し色にする。関係ごとのテーマ色は、カードと結果ページの差し色だけに使う
- 太い線・強い影は使わず、やわらかい影と大きめの角丸にする
- 猫は「ゆるかわ」寄り。細い茶色の線、離れぎみの小さめの目、ほっぺ
- 絵文字は端末によって見え方が変わるので、ブランド要素（ロゴ・肉球）には使わず図形で描く
