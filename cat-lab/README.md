# 主従研究所（cat-lab）

猫様と下僕の関係を、大真面目に調べるエンタメ診断サイト。
16の「事情聴取」に答えると、主従関係を「鑑定調書」として発行します。

## 特徴

- **関係性鑑定課**：16問の事情聴取 → 4指標（君臨・甘え・気まぐれ・要求）→ 全16タイプ＋下僕等級を判定
- **調書**：タイプ解説・決定的証拠・観察所見・研究員の見解を、1枚の書類にまとめて表示
- **シェア**：調書を画像（PNG）で保存、Xシェア、結果リンク、友達への挑戦状
- **比較**：挑戦状リンクから診断すると、二匹の調書を並べて比較
- **タイプ図鑑 / 用語集**：読み物ページ
- **サーバーに何も保存しない**：結果は回答コードとしてURLに入っています。AIも外部APIも使いません（結果は毎回同じ）

## 構成

| 場所 | 内容 |
|---|---|
| `lib/questions.ts` | 設問・選択肢・観察所見（回答は選択肢の番号16桁で表現。並びを変えると既存URLの結果が変わる） |
| `lib/types.ts` | 16タイプ、下僕等級、指標ごとの解説 |
| `lib/scoring.ts` | 採点、調書の組み立て、比較 |
| `components/Interview.tsx` | 事情聴取フロー（クライアント） |
| `components/ShareActions.tsx` | 画像保存（Canvas）・シェア |
| `app/chosa` / `app/chosho` | 聴取ページ / 調書ページ |

## 動かす

```bash
cd cat-lab
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
```

公開時は環境変数 `NEXT_PUBLIC_SITE_URL`（例：`https://example.com`）を設定してください。
