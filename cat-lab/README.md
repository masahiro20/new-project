# 主従研究所（cat-lab）

「うちの猫様と、ほんとうはどんな関係？」を診断するエンタメサイト。
うちの子（柄8種・猫種12種）をえらんで12の「もしも」の質問に答えると、ふたりの関係をオリジナルのイラストにします。

## 特徴

- **20種類の猫**：柄（キジトラ・茶トラ・サバ白・三毛・黒猫・白猫・ハチワレ・サビ）と猫種（スコティッシュ・マンチカン・アメショ・ロシアンブルー・ラグドール・ブリティッシュ・ノルウェージャン・メインクーン・ベンガル・シャム・ペルシャ・スフィンクス）。耳の形・長毛・ポイントカラー・目の色などを描き分け
- **質問**：共通の「もしも」10問 ＋ 猫種ごとの特徴を生かした専用2問。選択肢は複数の指標に効くので、答えから結果を読みにくい
- **12の関係**：王様と家来、推しとオタク、恋人同士、ツンデレ幼なじみ など。どの関係もほぼ同じ割合で出るよう、シミュレーションで補正値を決めている（`lib/relations.ts` の `offset`）
- **関係イラスト**：12関係 × 3シーン。猫種・指標による猫の表情（王冠・ほっぺ・ウインク・鳴き顔）・セリフ（各5種）・人の髪型と服の色が回答ごとに変わる
- **共有**：イラスト画像（4:5）、Instagramストーリーズ用（9:16）、調書画像、X・LINE・リンクコピー、友達への挑戦状（2匹の比較）
- **サーバーに何も保存しない**：結果は回答コードとしてURLに入る。AIも外部APIも使わない

## 構成

| 場所 | 内容 |
|---|---|
| `lib/cat.ts` | 猫イラスト（SVG）の生成。猫種ごとの見た目 |
| `lib/human.ts` | 「あなた」のちびキャラ（ポーズ・表情） |
| `lib/scenes.ts` | 関係イラストのシーン（12関係 × 3） |
| `lib/questions.ts` | 共通の質問と指標 |
| `lib/breeds.ts` | 猫種の特徴・傾向・専用の質問 |
| `lib/relations.ts` | 12の関係（説明・セリフ・典型値） |
| `lib/scoring.ts` | 採点、関係の判定、調書の組み立て、比較 |
| `components/ShareActions.tsx` | 画像の生成（Canvas）と共有 |

回答は「選んだ選択肢の番号」12桁でURLに入ります。質問や選択肢の並びを変えると、既存の結果URLの内容が変わります。

## 動かす

```bash
cd cat-lab
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
```

公開時は環境変数 `NEXT_PUBLIC_SITE_URL`（例：`https://example.com`）を設定してください。
