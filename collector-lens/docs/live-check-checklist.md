# 実ページでの抽出確認チェックリスト（人が手で行う）

**作成：Ren（P4） / 2026-10-08**

## なぜ人が行うのか
クラウド上の Claude が Chromium を自動操作して実サイトを開くことは、たとえ30件以内でも、LY利用規約15(5)が禁じる BOT アクセスにあたるおそれがあります。これはステージ1で自分たちが指摘したリスクです。また、このコンテナは海外のサーバー上にあり、ヤフオクの地域制限にもかかる可能性があります。そのため、確認は**人が自分の Chrome で普段どおりに閲覧して**行います。

## 準備
1. `cd collector-lens && npm install && npm run package`
2. `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」→ `collector-lens/dist`

## ルール
- 1サイト最大10件、合計30件以内。普段どおりの速さで、検索結果から出品ページを開くだけにする。
- **HTML やスクリーンショットは保存しない。** 記録は下の表の件数と問題点のメモだけ。
- robots.txt で禁止されているパス（ヤフオクの `/closedsearch` など）は開かない。
- ログインや入札はしない。

## 記録表（1件ごとに ○ / × / −）
| # | サイト | ジャンル | パネル表示 | タイトル | 状態 | 返品 | 説明文 | ランク | 誤警告 | 見落とし | メモ（語句だけ。本文は貼らない） |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | ヤフオク | カメラ | | | | | | | | | |

## 集計
- サイトごとの「状態」「返品」「説明文」の抽出成功率
- 誤警告の例。否定表現の見逃しがないか（「カビ等ございません」のような言い回し）
- 辞書に足すべき語
