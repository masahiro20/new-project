## 0. 結論（先に）

1. **最初に作るのは『帳簿の書 Vol.1』**（PDF 40ページ、BOOTH ¥700／Ko-fi $5）。**Day 45 に発売**する。発売の条件は **G1 を通過していること**。
2. 次に、Vol.1 が出たあとで **「Vol.0＋Vol.1 セット」**（¥1,000／$8）を Day 60 ごろに出す。
3. その次に **Ko-fi の月額メンバーシップ**（月 $3）を Day 63〜70 に始める。ただし、始めるのは「Ko-fi で買った人・チップをくれた人が5人以上」になってから。
4. **「Webtoon 第1話 フルカラー」は単品では売らない。** G2 を通過したら、無料で WEBTOON CANVAS・Tapas に出し、ファンを集める入口にする（理由は §3-4）。Vol.1 にはその一部（10コマ）だけ載せる。

理由はひとことで言うと、**Vol.1 は「今の買い手」と「今の売り場」と「今の作り方」をそのまま使えて、Vol.0 の中ですでに予告している**から。費用は0円で、チームが作業の9割を受け持てる。オーナーの作業も Vol.0 のときとほぼ同じで済む。さらに、G2 に向けていちばん大事な数字、**「Vol.0 を買った人が次も買うか（リピート率）」** を測れる（§5）。

### 3-4. 「Webtoon 第1話 フルカラー」単品販売（**売らない。無料で出す**）

**売らない理由**
1. **入口がなくなる。** `monetization.md` の90日プランでは、Webtoon 第1話を WEBTOON CANVAS・Tapas に**無料で**出して読者を集め、G2・G3 の「Webtoon 購読者」を増やすことになっている。第1話を有料にすると、この入口がふさがる。
2. **売上が小さい。** ¥300 で売っても、BOOTH では手数料を引くと1件約 ¥238。リピートを生む Vol.1 のほうが効率がいい。
3. **「未発表」の問題。** 第1話の物語を漫画の形で売ると、同じ話を原作として賞に出すときに「発表済み」と見なされるおそれがある（**要確認**：賞ごとの要項）。無料公開でも同じ問題はあるので、出す前に、どの賞に何を出すか（`monetization.md` §3 の6〜12か月の予定）をオーナーが決めておく。
4. **英語圏は AI 作画への反発が強い**（`monetization.md` §1 D）。漫画そのものを有料で売ると、設定資料集よりも反発を受けやすい。

**かわりにやること（G2 を通過してから）**
- WEBTOON CANVAS と Tapas に、英語版を無料で公開する。チームは英語の文字入れ・縦長の書き出し・作品説明文を用意する（作業3日）。

## 5. 推奨：最初は Vol.1、その理由

1. **約束をすでにしている。** Vol.0 の p29 で「帳簿の書 Vol.1（予定）」を予告し、Ko-fi の About にも「支援はそのまま Vol.1 に使われます」と書いた。出さないと信用を失う。
2. **作り方ができあがっている。** `book/build.mjs` と `book.css` をそのまま使え、Vol.0 は約2日で組めた。新しい道具もお金もいらない。
3. **オーナーの手間が少なく、毎月の仕事にならない。** メンバーシップは毎月の投稿という約束になるが、Vol.1 は1回出せば終わる。
4. **いちばん大事な数字が取れる。** G2 の「売上30件」に向けて、Vol.0 の買い手がもう一度お金を払うかどうか（リピート率）が分かる。これはメンバーシップを始めるかどうかの判断材料にもなる。リピート率が低ければ、メンバーシップはやめておく。
5. **温存すべき素材を使いすぎない。** 第1話の脚本は使わず、第2話の脚本は1分半だけ、Webtoon は10コマだけにとどめる。
