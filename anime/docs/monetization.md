# RED LEDGER 収益化ロードマップ（個人オーナー向け）

作成：P7 Anime マーケティング／ビジネス担当　2026-10-08
前提：オーナーは**個人**（法人・製作委員会なし）。目的は「オーナーの収入を増やすこと」。Netflix への直接ピッチは制作会社／製作委員会経由が前提で、個人には現実的でない。したがって本書は「**まず1円を稼ぐ → 小さく積み上げる → 数字を持ってIPとして売り込む**」順に組み立てる。

> 数字は2026-10-08時点で調べた範囲のもの。プラットフォームの規約・手数料は頻繁に変わるため、**実行前に必ず公式ページで再確認**すること。確認できなかった項目は「要確認」と書き、幅で示している。

## 0. 大前提：チームができること／オーナーにしかできないこと

| チーム（Claude Code 含む）がやる | **オーナー本人しかできない** |
|---|---|
| 設定資料・脚本・ネーム台本・商品説明文・投稿文案・ハッシュタグ案・動画の台本と絵コンテ・KPI集計表の作成 | 各プラットフォームの**アカウント作成**（X / YouTube / TikTok / BOOTH / Ko-fi / pixiv / WEBTOON CANVAS / Tapas / Patreon 等） |
| 規約・手数料の調査と要約 | 本人確認・**銀行口座／PayPal／Stripe 登録**、税務情報（W-8BEN 等）の提出 |
| 画像・動画素材の「案」と編集手順書 | 実際の**投稿・公開・価格設定・販売開始** |
| 応募要項のチェックリスト作成 | **支払い**（有料ツール、外注イラストレーター、広告費）／**契約への署名** |
| 問い合わせ文・企画書の下書き | 新人賞・コンテストへの**応募**、出版社とのやりとり、確定申告 |

チームはアカウントを作らない・投稿しない・支払わない。成果物は「オーナーがコピペして使える状態」で渡す。

### 各ルートの調査メモ（出典つき）

**A. 漫画・Webtoon**
- WEBTOON の広告収益分配は「連載中の作品がある・18歳以上・申請とWEBTOONの書面承認」が条件で、承認されても分配は保証されない（[WEBTOON Ad Revenue Sharing Terms](https://webtoons.com/en/terms/adRevenueSharingPolicy)）。「購読者1,000人・月間4万ビュー」という数値基準は二次情報で現行か未確認（[Comicsbeat](https://www.comicsbeat.com/webtoons-super-likes-breakdown/)）。2026年3月にCANVASが統合され、AI翻訳プログラム（オプトイン）も開始（[Business Wire経由](https://www.barchart.com/story/news/980260/webtoon-entertainment-announces-unified-international-canvas-platform-helping-creators-grow-their-audience-and-earnings)、[AWN](https://www.awn.com/news/webtoon-unifies-canvas-new-creator-tools-and-translation-program)）。CANVAS の AI 作画に関する公式規定は今回見つけられず**要確認**。
- ジャンプルーキー! の月例賞は、月間ランキング上位10作から編集部が選考。ブロンズルーキー賞は賞金10万円＋少年ジャンプ+掲載（時期により表記差あり）（[公募ガイド](https://koubo.jp/contest/263579)、[同](https://koubo.jp/contest/344523)）。
- 集英社系の賞で、ランキング1位になったAI生成漫画が失格になったと報じられた（[AUTOMATON](https://automaton-media.com/en/?p=58386)、本文未確認）。**新人賞に AI 作画で出すのは高リスク**と判断する。応募要項に明記がなくても、提出前に編集部へ確認。
- Tapas は過去に「広告収益の分配・有料話の50%」などが報じられているが、数字は古く現行条件は**要確認**（[Wikipedia: Tapas](https://wikipedia.com/wiki/Tapastic)）。

**B. ショート動画**
- YouTube Partner Program（広告分配あり）の現行基準：登録者1,000人＋（過去12か月の長尺総再生4,000時間 または 過去90日のショート再生1,000万回）。下位層は登録者500人＋ショート300万回等（広告分配なし）。**2027年2月1日から新規申請は「ショート2,000万回／90日」または「8,000時間」へ引き上げ**と報道（[Tubefilter](https://www.tubefilter.com/2026/08/10/youtube-partner-program-ad-eligibility-requirements-shorts/amp/)、[Shacknews](https://www.shacknews.com/article/150324/youtube-partner-program-minimum-qualified-public-watch-hours-shorts-views)）。→ **ショートだけで2027年以降のYPPを狙うのは非常に重い。長尺（エピソード版モーションコミック）で4,000時間ルートを併用**するのが現実的。ショートの広告収益はプール配分でクリエイター取り分45%（[YouTube ヘルプ](https://support.google.com/youtube/answer/12504220)、要確認）。
- YouTube は2025年7月に「repetitious content」を「inauthentic content」に改称。AI 利用自体は禁止ではないが、量産・テンプレ型は収益化対象外。写実的な合成コンテンツは申告が必要（[ppc.land](https://ppc.land/youtube-clarifies-inauthentic-content-policy-changes/)、[air.io](https://air.io/en/youtube-glossary/what-is-youtubes-ai-content-disclosure-policy)）。アニメ調の明らかなフィクションは写実的とは言いにくいが、迷ったら申告する。
- TikTok Creator Rewards：18歳以上・フォロワー1万・直近30日10万再生・1分超の動画（日本対象と報道、公式未確認）（[Brandwatch](https://www.brandwatch.com/blog/tiktok-creator-program/)、[ShortSync](https://www.shortsync.app/resources/tiktok-creator-rewards-program-2026)）。

**C. 売り込み**
- テレビアニメ1話の制作費は「約1,500万円とよく言われる」、適正水準は4,000万円程度との見方、1クールで数億円規模の製作委員会が必要（[Business Insider Japan](https://www.businessinsider.jp/article/164211/)）。→ 個人がアニメ本編を自費制作するのは非現実的。**個人がやるべきは「原作（漫画/Webtoon）と数字」を作ること**。
- 少年ジャンプ+漫画賞は2か月ごと年6回締切の常設賞（[公募ガイド](https://koubo.jp/contest/369681)）。ジャンプTOON AWARD など縦読み向けの賞もある（[公募ガイド](https://koubo.jp/contest/315081)）。

**D. 海外**
- Crunchyroll と WEBTOON は2019年に共同開発・共同製作で提携し『神之塔』をアニメ化（[AWN](https://awn.com/print/news/webtoon-and-crunchyroll-team-co-develop-new-animated-content)）。Tapas 発の『The Beginning After the End』も Crunchyroll で配信（[Dexerto](https://www.dexerto.com/anime/the-beginning-after-the-end-anime-crunchyroll-2025-2954825)）。→ **「Webtoonで読者数を証明 → 配信側が共同製作」**は実在する道。
- Kickstarter：成功時のみ5%＋決済手数料（概ね3〜5%）（[Kickstarter Help](https://help.kickstarter.com/hc/en-us/articles/115005028634-What-are-the-fees)）。
- Patreon：2025年8月4日以降に公開した新規クリエイターは一律10%＋決済手数料（[Patreon Help](https://support.patreon.com/hc/en-us/articles/36426991446797)）。

**E. 直接課金**
- BOOTH：2025年10月28日以降、サービス利用料は「5.6%＋45円」（[GameBusiness](https://www.gamebusiness.jp/article/2025/07/24/24711.html)、[BOOTH告知](https://booth.pm/announcements/834)）。AI生成物については、特定作家・作品への依拠性が高い商品や大量・連続出品を監視強化し、非公開化〜アカウント停止（[GameBusiness 2025/07/18](https://www.gamebusiness.jp/article/2025/07/18/24681.html)）。
- pixivFANBOX：手数料は概ね10%と複数の情報源（公式で要確認）（[税理士ドットコム](https://www.zeiri4.com/c_5/q_164420/)）。**FANBOX と pixivリクエストは AI 生成作品の取り扱いを禁止**。pixiv本体は AI生成作品の申告が必須（[Impress Watch](https://www.watch.impress.co.jp/docs/news/1504986.html)、[GameBusiness](https://www.gamebusiness.jp/article/2022/10/20/20966.html)）。
- Ko-fi：無料プランでチップ0%、ショップ等5%（＋PayPal/Stripe手数料）（[Ko-fi Help](https://help.ko-fi.com/hc/en-us/articles/360002506494)）。

### AIと著作権（全ルート共通）
- 日本（文化庁「AIと著作権に関する考え方」）：AIが自律的に生成したもの（簡単な指示のみ）は著作物にならない。人間の創作意図＋創作的寄与（詳細な指示、加筆・修正、選択・配列）が積み重なれば著作物になりうる。既存作品に類似・依拠したAI画像の公開・販売は侵害になりうる（[GameBusiness](https://www.gamebusiness.jp/article/2024/04/19/22981.html)、[東大資料](https://genai.t.u-tokyo.ac.jp/assets/materials/01_03_生成AIの注意点・リスク_03_生成AIと著作権.pdf)）。
- 米国著作権局（2025年1月報告書 Part 2）：**プロンプトだけでは著作者性は認められない**。人間の描いた入力や人間の創作的な配置・修正部分のみ保護（[Sidley](https://datamatters.sidley.com/2025/02/07/u-s-copyright-office-issues-report-on-artificial-intelligence-and-copyrightability/)）。
- **結論**：RED LEDGER の「権利の核」は**人間が書いた文章（世界観・脚本・キャラ設定・セリフ）**とし、ここをすべてチームで作る。ビジュアルは「AI補助＋人間による加筆・構図決定」または人間の作画で、作業ログ（ラフ・修正前後）を保存しておく。将来、出版社・制作会社とライセンス交渉する際に「権利がクリーンか」は必ず聞かれる。

## 2. 推奨：最初の1円への最短ルート

### 結論：**ルートE（BOOTH＋Ko-fi のデジタル販売）× ルートB（X／ショートでの告知）**

- 商品：**『RED LEDGER 帳簿の書 Vol.0』**（PDF、世界観・用語集・キャラ設定・第1話脚本、40〜60ページ）
  - 日本語版：BOOTH で 500円（＋「応援価格」1,000円の2種）
  - 英語版：Ko-fi Shop で $3〜5（＋チップ受付）
  - おまけ：スマホ壁紙3種（レジャーマーク／「払わねえよ。」ロゴ）
- **初期費用：0円**（任意で商用フォント・画像ツールに0〜5,000円）
- **最初の1円まで：2〜6週間**（知人・初期フォロワー1人が買えば到達。最初の販売は「最初の100フォロワー」ができる頃が目安）
- 理由：①文章はチームが今すぐ作れる＝作画コストゼロ ②人間が書いた文章なので著作権がクリーン ③BOOTHは審査待ちがなく即日販売可能 ④販売数＝「お金を払うファンの数」という最も重要なKPIが初日から取れる
- 注意：FANBOX は使わない（画像にAI生成を含めると規約違反になりうる）。画像を載せる場合は、既存作品・作家に似せない、大量出品しない。

## 3. 12〜24か月の「売れるIP」への梯子

1. **0〜3か月：** BOOTH/Ko-fi で1円 → 30件。ショートでフックを検証。
2. **3〜6か月：** Webtoon 第1〜5話を隔週更新。Patreon（英語圏、手数料10%）または Ko-fi メンバーシップ。YouTube は長尺「モーションコミック版」を月1本。
3. **6〜12か月：** 少年ジャンプ+漫画賞・ジャンプルーキー! 月例賞・縦読み系アワードに、**人間の作画（外注含む）で**読切版を応募。WEBTOON の広告分配申請。紙の設定資料集（BOOTH倉庫）。
4. **12〜18か月：** Kickstarter で英語版アートブック＋Webtoon 第1巻（目標 $3,000〜10,000 を想定、送料込みで設計）。
5. **18〜24か月：** 「ピッチパック」完成＝①1ページ企画書 ②シリーズバイブル ③Webtoon 実績（購読者・地域別比率）④SNS数字 ⑤権利整理表（誰が何を作ったか、AI使用範囲）。これを持って出版社編集部、Webtoon系スタジオ、アニメ制作会社のオリジナル企画窓口へ。**Netflix・Crunchyroll には個人で直接ではなく、制作会社／出版社経由**で届く形を目指す。

### 収入の目安（あくまで幅）
- 3か月：0〜1万円／月
- 12か月：1〜10万円／月（直接課金中心）
- 24か月：5〜30万円／月＋賞金・原作料の可能性
いずれも保証はなく、更新頻度とフックの強さで大きく変わる。年間所得が一定額を超えれば確定申告が必要（オーナーが税理士・税務署で確認）。

## 4. やらないこと
- Netflix への直接ピッチ（窓口がない）。
- 有料広告への先行投資（G2通過前）。
- AI生成画像を主体とした商品の FANBOX 販売、新人賞への AI 作画応募。
- 既存ヒット作の絵柄・キャラに寄せた画像の生成・販売。
