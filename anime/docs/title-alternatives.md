## 0. 背景

- 現タイトル「RED LEDGER」（副題『赤い帳簿』）には、Meredith Wild の恋愛サスペンス小説シリーズ **"The Red Ledger"** が先にある（`review-originality-vol0.md` T-1）。
- 今回 USPTO の検索 API で確認したところ、**"THE RED LEDGER"（出願番号 87224443、Waterhouse Press, LLC、第9類・第16類）は出願されていたが失効（dead）**していた。登録商標としては残っていないが、同じ題名の本が書店・電子書籍ストアで売られ続けていることは変わらない。検索で埋もれる問題と混同の問題は残る。
- 守りたいブランド資産は2つ。**①左手首の赤い帳簿の印（レジャーマーク）、②決め台詞「払わねえよ。」/"I'm not paying."**

## 4. 何を確認し、何を確認できなかったか（正直な記録）

### J-PlatPat（日本・特許庁／INPIT）── **確認できなかった**
- `https://www.j-platpat.inpit.go.jp/` へのアクセスは、**WAF（不正アクセス防止の仕組み）により 403 Forbidden** で拒否された（`reject_sorry.html` に転送）。
- `https://www.j-platpat.inpit.go.jp/t0100`（商標検索）は WebFetch で取得できたが、中身は「Loading...」だけの JavaScript アプリで、検索はできなかった。
- INPIT の公開データ（`ip-data.inpit.go.jp`）は、この環境のネットワーク制限で接続できなかった。
- 代わりに試した **WIPO Global Brand Database**（日本の商標データを含む）は、API が認証を求め（"Missing Authentication Token"）、画面は CAPTCHA（altcha）付きで、**これも確認できなかった**。
- **結論：日本の商標（第9・16・28・41類）は、5案すべて未確認。** 「日本で問題なし」とは言えない。

### USPTO（米国）── **一部確認できた**
- `tmsearch.uspto.gov` の画面は JavaScript アプリだが、画面が使っている検索 API（`https://tmsearch.uspto.gov/prod-stage-v1-0-0/tmsearch`、JSON で POST）に直接問い合わせることができた。
- 方法：文字商標（wordmark）に対する完全一致のフレーズ検索と、ワイルドカード検索（例：`defaulter*`、`*ledger*`、`redmark*`）。**失効した商標も含めて**すべて取得し、国際分類（第9・16・28・41類）とその他の分類、現存（LIVE）か失効（dead）かを手作業で見分けた。
- **限界**：①発音が似ているもの（例：KANEGURA と KANAGURA）、表記の揺れ、図形商標の中の文字までは網羅していない。②審査官が行う「類似」の判断（称呼・外観・観念）はしていない。③検索結果は最大200件までしか目で確認していない（"DEFAULT" は143件、"*LEDGER*" は689件で、関連の大きいものだけを抜き出した）。
- 米国以外（EU の EUIPO、英国、韓国、中国など）は**調べていない**。

### Web 検索（既存作品）── **確認できた（ただし網羅ではない）**
- 一般のウェブ検索で、英語題・日本語題それぞれについて、本・漫画・アニメ・ゲーム・映画・Webtoon・Steam・itch.io の同名・類似作品を探した。
- **限界**：Steam・WEBTOON・LINEマンガ・ピッコマ・Amazon（Kindle）・MyAnimeList・IMDb のサイト内検索は直接していない（検索エンジン経由のみ）。小規模な同人作品・ウェブ小説（なろう、カクヨムなど）は漏れている可能性がある。

## 5. 推奨：**LEDGERBREAKER**（日本語題『帳簿破り』、ルビ・英字ロゴ「LEDGERBREAKER」）

**理由**
1. **資産が途切れない。** 「LEDGER（帳簿）」を残すので、手首の赤い帳簿の印、Vol.0『帳簿の書』、これまでの宣伝の言葉がそのまま使える。ロゴは「LEDGER」に**赤い取り消し線**を引き、その下に「BREAKER」。これは劇中の〈デフォルト〉の演出（相手の残高に赤い取り消し線）と同じ絵になる。
2. **決め台詞と意味が一致する。** "LEDGERBREAKER — I'm not paying." / 『帳簿破り ──払わねえよ。』と、題名とキャッチコピーが一つの文として読める。
3. **少年漫画らしい。** 「〜破り」「〜ブレイカー」は、反抗と成り上がりの響きを持つ。日本語の『帳簿破り』は「道場破り」を思わせ、格付けを一つずつ上がっていく本作の構造に合う。
4. **検索で衝突がない。** 今回の自己チェックでは、USPTO（失効を含む）・Web とも同名は0件だった。造語の複合語なので、一般語の DEFAULTER・REDMARK・INFINITE DEBT より検索で見つけてもらいやすい。
5. **DEFAULTER を選ばない理由**：一番分かりやすいが、一般語で識別力が弱く、同じゲーム・アニメの分野にスクウェア・エニックスの『ブレイブリーデフォルト』の現存商標がある。リスクが比較的はっきりしている。

**注意点（推奨案のリスク）**
- 日本語の「レジャー」は「leisure（娯楽）」と読まれるので、**日本向けの題名は『帳簿破り』を主にし、「レジャーブレイカー」はルビか英字ロゴだけ**にする。
- 「LEDGER」には暗号資産の Ledger 社の商標（第9・16類など）がある。分野と全体の印象は違うが、弁理士に判断してもらう。
- 「〜BREAKER」で終わる人気作が多い（『WIND BREAKER』など）。ロゴでは「LEDGER」を大きく、赤い取り消し線を主役にして、「BREAKER」の印象に寄りすぎないようにする。

**次点**：**KANEGURA**（識別力が最も高い）。LEDGERBREAKER が弁理士の調査で使えないと分かった場合、または「LEDGERBREAKER — 金蔵（カネグラ）編」のように、シリーズ題と章題の組み合わせにする場合に使う。

## 6. オーナー（決定者）の次の手順

1. **J-PlatPat を自分のブラウザで確認する**（ここからは確認できなかったため、必須）。
   - 商標検索で「LEDGERBREAKER」「レジャーブレイカー」「帳簿破り」「ちょうぼやぶり」を、第9類（ダウンロード可能な動画・ゲーム・電子出版物）、第16類（印刷物・書籍）、第28類（おもちゃ・ゲーム用品）、第41類（映像の制作・配信、電子出版物の提供）で検索する。
   - 称呼検索（読み）で「レジャー」「ブレイカー」を含むものも確認する。
   - 次点の「KANEGURA」「カネグラ」「金蔵」も同じように確認する。
2. **USPTO を画面からもう一度確認する**（tmsearch.uspto.gov）。今回は API で文字商標を調べたが、図形商標や似た発音の確認は、画面の検索でもう一度行う。
3. **主要市場の商標も確認する**：EUIPO（EU）、英国 IPO、韓国 KIPRIS、中国（配信予定地域に合わせて）。WIPO Global Brand Database を自分のブラウザで使えば、まとめて確認しやすい。
4. **ストアとドメインを確認する**：Steam・WEBTOON・Amazon（Kindle）・MyAnimeList・IMDb で直接検索し、`ledgerbreaker.com` などのドメイン、X／YouTube／TikTok のアカウント名が空いているか確認する。
5. **弁理士に正式な調査を依頼する**（商業化・資金調達・BOOTH 以外での販売の前に）。依頼するときは、次のことを伝える：
   - 候補名（LEDGERBREAKER／帳簿破り、次点 KANEGURA）と使う予定の商品・サービス（アニメ、書籍、グッズ、ゲーム）
   - 今回見つかった近い商標（Ledger SAS の "LEDGER"、Square Enix の "BRAVELY DEFAULT"、失効した "THE RED LEDGER"）
   - 出願する国と分類（第9・16・28・41類が基本。グッズを売るなら第25類（衣類）も）
6. **決まったら**：バイブル・Vol.0・`launch/*.md`・ロゴを一度にまとめて差し替える。Vol.0 はすでに「RED LEDGER」で売っているため、移行期間は「LEDGERBREAKER（旧題 RED LEDGER）」と書き、既存の購入者に分かるようにする。
