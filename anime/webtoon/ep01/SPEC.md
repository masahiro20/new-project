縦スクロールの Webtoon（スマホで読む）第1話のネーム。**40コマ前後**、日本語。
正典：`anime/scripts/ep01-script.md`、`anime/bible/series-bible.md`、`anime/docs/review.md`、`anime/docs/review-originality-vol0.md`、`anime/storyboard/ep01/SPEC.md`（ニルの改訂デザイン、〈デフォルト〉＝3秒の差し押さえ）。キャラの見た目は `anime/book/art/char-*.svg`。

## 構成（Webtoon 第1話はアニメ第1話を圧縮し、覚醒までを1話に入れる）
| 担当 | コマ | 内容 |
|---|---|---|
| 前半 | 1–20 | 取立日の夜：鐘、公開格付け盤、手首の印、路上の歌い手の声が消える（最初の5コマ以内で代償を見せる）。ジンが追われて登場（「この街でいちばん価値のない男です」＋格付け ZERO のカード）。ケイの屋台に逃げ込む短い日常（ツバメ、ケイの「食え。話はそれからだ。」）。ニルが現れ、ケイを取り立てようとする（特別取立状）。ジンの赤い印が脈打ち「……みぃつけた」。 |

## 出力
- 1コマ＝1ファイル：`panels/p01.svg` 〜 `panels/p40.svg`（番号はゼロ埋め2桁）。
- **幅は 800 固定**：`viewBox="0 0 800 H"`、H はコマごとに 400〜1400 で自由（縦長の溜め・横長の速さを演出として使う）。`width`/`height` 属性は付けない。1ファイル 40KB 以内、外部参照なし。
- 各担当は `panels-a.json`（前半）／`panels-b.json`（後半）も書く：
```json
{ "part": "a", "panels": [ { "no": 1, "file": "p01.svg", "gap_after": 80, "note": "演出メモ（読者の視線・間）" } ] }
```
`gap_after` はこのコマの下の余白（px、0〜600）。間（ま）と緊張を作る大事な要素。シーンが変わるところは大きく空ける。

## 描き方（ネーム＝ラフ）
- 背景は透明にせず、コマの中は白 `#FFFFFF`、枠線なしでもよい（Webtoon は枠なしコマも多い）。夜の場面はコマ全体を濃いグレー `#3A3A3A`〜`#1E1E1E` で塗ってよい。
- 主線 `#2A2A2A`、トーン `#D6D6D6` / `#B0B0B0`。**色は赤 `#E5172F` だけ**（ジンとハザマの印、赤いインク、「契約停止」カウンター）。例外：最終コマのミオの瞳だけ琥珀 `#F0921E`（次話への引き）。
- フキダシ・台詞・擬音は SVG の中に描く。フォントは `font-family="Zen Kaku Gothic New, IPAGothic, sans-serif"`、擬音や決め台詞は `Dela Gothic One, IPAGothic, sans-serif`。台詞は縦書きではなく横書き（Webtoon の慣習）。1フキダシ25字以内、1コマに3フキダシまで。文字サイズは 26px 以上（スマホで読める大きさ）。
- 人物は簡略化したラフでよいが、誰か分かること・表情と動きが読めることが条件。
- 既存作品の名場面・構図をなぞらない。
