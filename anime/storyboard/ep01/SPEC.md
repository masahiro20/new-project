# 第1話 絵コンテ 制作仕様（全エージェント共通）

正典：`anime/scripts/ep01-script.md`（タイムコード付き脚本）、`anime/bible/series-bible.md`、`anime/docs/review.md` と `anime/docs/review-originality-vol0.md`（ショーランナー決定）。
- 〈デフォルト〉は「触れた相手の借力を約3秒“差し押さえ”、その間ジンが奪って使う」。第1話ではニルの鎖を奪って引き寄せる。
- ニルの外見（改訂版）：**フードなし**。平たいつばの制帽、刈り込んだ灰色の髪、高い立ち襟の黒いフロックコート。仮面は「閉じた帳簿の表紙」形の長方形・象牙色で、目は**横一本のスリット**、片側に背表紙の綴じ目。楕円の仮面や、目の穴が2つの仮面は描かない。
- キャラの見た目は `anime/book/art/char-*.svg` と `anime/visuals/characters-lineup.png` に合わせる。

## JSON 形式（UTF-8）
```json
{
  "seq": "S1",
  "range": ["00:00", "01:00"],
  "scene_titles": ["底帳・夜市「肋骨通り」・夜"],
  "cuts": [
    {
      "cut": 1,
      "scene": "底帳・夜市「肋骨通り」・夜",
      "sec": 4.0,
      "frames": ["s1-c01a.svg", "s1-c01b.svg"],
      "camera": "FIX / PAN UP / T.U. / T.B. / FOLLOW / 手持ち など",
      "shot": "LS / FS / MS / BS / CU / ECU / 俯瞰 / あおり",
      "picture": "画面の内容（何が映っているか）",
      "action": "動き・芝居・エフェクト",
      "dialogue": "台詞（JA、話者「…」形式。無ければ空）",
      "dialogue_en": "英語字幕（無ければ空）",
      "sound": "SE / BGM / MA"
    }
  ]
}
```
- 文字のみの範囲（T1・T2）は `"frames": []` とする。
- 1カットに複数のフレームを付けてよい（カメラワークの始点・終点、芝居の変化）。合計フレーム数の目安：S1 約22、S2 約26、S3 約24、S4 約12。

## フレーム（SVG）の描き方
- `viewBox="0 0 1600 900"`（16:9）。`width`/`height` 属性は付けない。外部参照なし。1枚あたり 30KB 以内。
- **絵コンテの線画**：背景は白 `#FFFFFF`。主線 `#2A2A2A`（太さ 3〜5）、補助線・遠景 `#8A8A8A`、影やトーンはグレーの塗り `#D6D6D6` / `#B8B8B8`、夜の暗さは `#4A4A4A` の面で表す。
- **色は2色だけ**：帳簿の赤 `#E5172F` は「ジンとハザマの印・赤いインク・『契約停止』カウンター」にだけ使う。カメラ指示（PAN の矢印、T.U. の枠など）は青 `#2E6BD6` の線と小さい英字ラベル。
- 文字：画面内の看板・UI（公開格付け、「契約停止 00:03」など）は描いてよい。`font-family="Zen Kaku Gothic New, IBM Plex Mono, IPAGothic, sans-serif"`。カット番号や台詞はフレームに描かない（ビューア側で表示）。
- 人物は簡略化した絵コンテ調（頭身・ポーズ・視線が分かれば十分）。顔は目と眉の線で表情が分かる程度。全員の見分けがつくシルエットにする。
- 構図・レンズ感・奥行き（前景／中景／遠景）をきちんと描く。アニメ演出として成立する画面設計にする。
