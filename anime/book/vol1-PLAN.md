# 『帳簿の書 Vol.1』/ "Book of the Ledger Vol.1" — 制作プラン（日本語版の下書き）

作成：P7 Anime 編集部　2026-10-09
準拠（拘束力あり）：`../docs/next-products.md` §1（守るルール）・§3-1（中身・ページ数・価格）・§8（抜粋の記録）。あわせて `../docs/decisions.md`、`../bible/series-bible.md`、`../scripts/ep01〜03-script.md`。

- 判型：A5（148×210mm）、**40ページ**。今回は日本語版 `vol1-ja.html` だけを作る（英語版 `vol1-en.html` は後の作業。同じページ構成にする）。
- 価格（参考・オーナーが設定）：BOOTH ¥700（応援版 ¥1,500 は Vol.0 応援版の実績しだい）／Ko-fi $5。
- スタイル：Vol.0 と同じ `book.css` のクラスだけを使う。足りない分は `vol1-ja.html` の `<style>` に最小限で追加（Vol.0 の追加分を引き継ぐ）。1 `<section class="page">` = 1ページ。はみ出しは削る。
- 書き出し：`node build.mjs vol1-ja.html`。`<img src="….svg">` は HTML ファイルの場所を基準に解決して埋め込まれる（`art/…`、`../storyboard/ep01/frames/…`、`../webtoon/ep01/clean/color/…` のどれも可）。
- **ネタバレの範囲：第2話「投資契約」まで。** 第3話以降の設定（監査官の名前、決済の儀の手順、照会不能の残高の扱い、保証人席、ケイの延滞の決着、誕生日の記憶）は書かない。

| 第1話の脚本の文章 | 上限（約3分）を Vol.0 で使い切った | 絵コンテは絵と演出の解説だけ。台詞欄は黒塗りで伏せる |
| 第3話の新設定 | ネタバレ範囲外 | 決済円の図はバイブル §2-5 と第2話の範囲で描く |
