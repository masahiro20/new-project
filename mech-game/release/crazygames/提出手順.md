# CrazyGames 提出手順（オーナー向け）

鋼脚戦機 GRANDSTRIDE を CrazyGames に出すための手順です。登録・提出・公開はオーナーが行います（P8 は行いません）。

> **先に読むこと：提出の前に、ゲーム内の文章の英語化が必要です。** CrazyGames は英語での表示を必須としています。いまのビルドは日本語が主で、ラジオ・ブリーフィング・リザルト・整備の説明などが日本語のみです（詳細は `審査要件チェック.md`）。英語化が済むまでは提出しないでください。済んだら P8 が zip を作り直します。

## 0. 事前に必要なもの

- CrazyGames の Developer Portal のアカウント（https://developer.crazygames.com/ ）。無料です。開発者名は「Team GRANDSTRIDE」を想定しています
- 支払いの受け取り：月に 1 回、残高が €100 以上になったとき（銀行送金または PayPal）。€100 未満は翌月に繰り越されます。支払い・税の書類の要件は、登録後に Payouts のページと利用規約で確認してください（P8 は公開資料で確認できていません）
- このフォルダのファイル一式

## 1. 全体の流れ（公式の説明にもとづく）

1. **Basic Launch**：ゲームを提出 → CrazyGames の審査 → 通れば公開。**この段階では広告が出ず、収益もありません。** 目安は 7 日以上かつ 500 プレイで、その間の数字（平均プレイ時間、1 分以上遊ぶ人の割合、翌日に戻る人の割合）で次に進めるかが決まります
2. **Full Launch**：Basic の結果がよければ招待され、広告の収益分配が始まります（このビルドは SDK 組み込み済みなので、そのまま対応できます）
3. 独占の条件はありません。itch.io や Steam と並行して出せます

審査の期間は公式に決まった日数が示されていません。結果はメールで届きます。

## 2. 提出（Developer Portal → Submit a game）

| 欄 | 入れる値 |
|---|---|
| Game title | `GRANDSTRIDE` |
| Build | `grandstride-crazygames.zip` をアップロード（index.html がルート） |
| Game type | HTML5 |
| Progress save（Data モジュール） | **有効にする**（オン）。切っても動きますが、通常の localStorage に保存されます |
| Account integration（User モジュール） | 使っていない（オフ） |
| Supported devices | Desktop、Mobile（タッチ対応） |
| Orientation | Landscape（横向き） |
| Languages | English（ゲーム内の英語化が済んでいること）、Japanese |
| Description / Instructions / Tags | `submission-en.md` の文面 |
| Covers | `covers/` の 3 枚（landscape / portrait / square） |
| Screenshots・動画 | `../itch/screenshots/` の画像、`../../store/media/trailer-15s.webm` |
| Age / content | PEGI 12 相当（SF の戦闘。人物への暴力・流血・性的表現・賭博表現なし） |
| 他の販路 | itch.io に公開済みであることは申告して構いません（独占は不要）。ゲーム内に他社ポータルの広告・ロゴ・リンクはありません |

欄の名前や並びは、Portal の更新で変わることがあります。違うときは近い欄に入れ、分からない欄は止まって本部に知らせてください。

## 3. 提出前の確認（Portal の Preview で）

- [ ] 出撃 → MISSION 01 のクリアまたは敗北 → リザルト → 「次の作戦へ」まで進める（Basic Launch 中は広告が出ないが、止まらずに進む）
- [ ] マウス視点（クリックで固定、Esc または P で一時停止）。**iframe の中でマウスの固定が効くか**を必ず確認する（効かなければタッチ操作に切り替わらないため、本部に連絡）
- [ ] 画面サイズ 907×510、1280×720、全画面でも文字が読める（公式が試すサイズ）
- [ ] ブラウザは Chrome と Edge。余裕があれば Safari と Firefox も
- [ ] スマホ（横向き）でタッチ操作ができる
- [ ] 音：最初のクリックの後に鳴る。iPhone でバックグラウンドから戻ったあとも鳴る（`resume()` を呼ぶ処理は音声側に入っています）
- [ ] 広告ブロックを入れた状態でも普通に遊べる（Full Launch 後に確認）

## 4. 提出後

- 結果のメールを待つ。**却下されたときは、理由を P8 に渡してください。** 直して再提出できます（意味のある改善が必要）
- Basic Launch の数字は、Portal の画面で見られます。本部の基準（平均プレイ 10 分以上、1 分以上遊ぶ人 80% 以上、翌日に戻る人 10〜15%）に照らして、ピーターに報告してください
- Full Launch に招待されたら、広告が出る状態で上の確認をもう一度行う（広告中に音が止まる、広告のあと次の出撃に進む）
- 更新は同じ画面から zip を差し替える。更新は通常その日のうちに反映され、Basic Launch 中は即時です（公式の説明）
