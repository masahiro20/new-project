# CrazyGames 提出手順（オーナー向け・画面の順）

鋼脚戦機 GRANDSTRIDE を CrazyGames に出す手順です。登録・提出・公開はオーナーだけができます（P8 は行いません）。所要時間は約 40 分です。

> **この手順の根拠と限界**：CrazyGames の公開資料（https://docs.crazygames.com/ の requirements / sdk / faq）と、Developer Portal の説明にもとづいています。Portal のログイン後の画面は P8 から見られないため、**欄の名前や並び順は実際と少し違うことがあります。** 違うときは、近い欄に下の値を入れてください。分からない欄、お金・契約に関わる欄は、入力せずに止まって本部（ピーター）に知らせてください。
> ゲーム内の文は英語化済みです（英語が基準。ブラウザの言語が日本語のときだけ日本語で始まり、タイトル画面の LANGUAGE ボタンで切り替えられます）。

## 0. 手元に置くもの

このフォルダ（`mech-game/release/crazygames/`）の次のファイル。

| 用途 | ファイル |
|---|---|
| ゲーム本体（アップロード） | `grandstride-crazygames.zip`（約 300KB、index.html がルート） |
| カバー 3 枚 | `covers/landscape-1920x1080.png`、`covers/portrait-800x1200.png`、`covers/square-800x800.png` |
| スクリーンショット 9 枚 | `screenshots/01-title.png` 〜 `09-result.png`（1280×720、英語 UI） |
| 動画（任意） | `../../store/media/trailer-15s.webm`（15 秒） |
| 説明文（コピペ用） | `submission-en.md`（英語。提出の本文はこれ）、`submission-ja.md`（日本語。日本語欄があるとき用） |

## 1. アカウントを作る（Developer Portal）

1. ブラウザで https://developer.crazygames.com/ を開き、**Sign up**（または Log in）を押す
2. メールアドレスで登録する（Google などでのログインでも可。**普段使うメール**にする。審査の結果はメールで届く）
3. 開発者名（Developer / Studio name）の欄は **`Team GRANDSTRIDE`**
4. 国は **Japan**
5. 支払い（Payouts）の設定は、**いまは飛ばしてよい**。広告収益が出る Full Launch の後に、Payouts のページで銀行送金か PayPal を設定する（残高が €100 を超えた月に支払い。足りない分は繰り越し）。税の書類の要件は、そのページで確認して本部に知らせる

## 2. ゲームを提出する（Submit a game / New game）

画面は上から順に次のとおり。

**画面 A：基本情報（Basic info）**
| 欄 | 入れる値 |
|---|---|
| Game title | `GRANDSTRIDE` |
| Short description（一言） | `submission-en.md` の「Short description」 |
| Description | `submission-en.md` の「Description」を貼る |
| Instructions / How to play | `submission-en.md` の「How to play」 |
| Categories / Tags | Action、Shooter（なければ近いもの）。タグ：Mech、Robot、First person、3D、Sci-fi、Singleplayer、Boss fight、Upgrades |
| Languages | English（必須）、Japanese |

**画面 B：ビルド（Upload）**
1. 種類は **HTML5**（Unity などではない）
2. `grandstride-crazygames.zip` をドラッグ＆ドロップ（解凍せず、zip のまま。または zip の中身のフォルダごと）
3. アップロードが終わると、ファイル一覧に `index.html` が出る。出ていれば OK

**画面 C：設定（Settings / SDK modules）**
| 欄 | 値 |
|---|---|
| Progress save（Data モジュール） | **オン**（このゲームは SDK のデータ保存を使っている） |
| Account integration（User モジュール） | オフ（使っていない） |
| In-game purchases | なし |
| Multiplayer / Chat | なし |
| Devices | Desktop と Mobile |
| Orientation | Landscape（横向き） |
| Ads | CrazyGames の SDK 広告（midgame のみを使う）。最初の Basic Launch 中は広告が出ない（仕様） |

**画面 D：画像と動画（Media）**
1. Covers：横 16:9 に `landscape-1920x1080.png`、縦 2:3 に `portrait-800x1200.png`、正方形に `square-800x800.png`
2. Screenshots：`screenshots/` の 01 → 09 の順
3. Video（任意）：`trailer-15s.webm`

**画面 E：年齢・内容（Content / Age）**
- 対象年齢：13 歳以上（PEGI 12 相当）。子ども向けではない
- 内容の申告：SF の戦闘（昆虫型の機械が相手）。流血・人物への暴力・性的表現・賭博・飲酒喫煙・チャット・外部リンクはなし
- AI の使用：`submission-en.md` の「Notes for the review team」の AI disclosure を、備考欄（Notes）に貼る

**画面 F：確認と提出（Preview → Submit）**
1. **Preview**（プレビュー）を押して、CrazyGames のページの中でゲームを動かす（次の「3. 確認」を実施）
2. 問題がなければ **Submit**（Submit for review）を押す。Basic Launch に入る

## 3. Preview での確認（提出前・約 10 分）

- [ ] 画面中央の LAUNCH → 出撃演出（初回は約 5 秒、キー or クリックでスキップ可）→ 操作案内 → 戦闘まで進む
- [ ] **マウスで視点が動く**（ゲーム画面を 1 回クリックして固定。`Esc` か `P` で一時停止、固定が外れる）。**iframe の中で固定が効かないときは、提出せず本部に連絡**
- [ ] 画面の文字が読める。ブラウザ窓を小さく（約 900×510）しても、全画面にしても、はみ出さない
- [ ] 作戦の終了 → リザルト → 「NEXT MISSION」または「RELAUNCH」で次へ進める（Basic Launch 中は広告が出ないが、止まらずに進む）
- [ ] タイトル画面の右上 LANGUAGE ボタンで日本語に切り替わる（ページが読み込み直される）。もう一度押すと英語に戻る
- [ ] Chrome と Edge で動く。余裕があれば Safari と Firefox も
- [ ] スマホ（横向き）でタッチ操作ができる（左スティック、右側ドラッグ、FIRE / BOOST / DASH）
- [ ] 音が最初のクリックの後に鳴る
- [ ] ブラウザのコンソール（F12）に赤いエラーがない（SDK の注意書きは可）

## 4. 提出後

1. 審査の結果は **メールで届く**（日数は公式に決まっていない。数日〜2 週間程度の見込み）。受け取ったら、本文をそのまま本部に渡す
2. **Basic Launch**：公開されると、広告も収益もない試験期間に入る。目安は 7 日以上かつ 500 プレイ。Portal の画面で、平均プレイ時間、1 分以上遊んだ人の割合、翌日に戻る人の割合が見られる。**数字を毎週 1 回本部に報告**（基準：平均 10 分以上、1 分以上 80% 以上、翌日 10〜15%）
3. **Full Launch**：基準を満たすと CrazyGames から招待が来る。招待されたら、広告が出る状態で「3. 確認」をもう一度行い（広告中に音が止まる、広告のあと次の出撃に進む）、Payouts を設定する
4. 更新：同じ画面から zip を差し替える。公式の説明では、通常は同じ日のうちに反映され、Basic Launch 中は即時
5. 却下されたら：理由のメールを本部に渡す。P8 が直して zip を作り直し、再提出（意味のある改善が必要）

## 5. 本部に知らせること

- 提出した日と、ゲームの URL
- 審査結果のメール
- Basic Launch の 3 つの数字（毎週）
- 困ったとき：Developer Support https://developer.crazygames.com/support （ブラウザのコンソールのエラーを先に確認し、Preview で再現するならそのリンクを添える）
