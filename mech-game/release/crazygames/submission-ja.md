日本語の欄があるとき、または本部・オーナーが内容を確かめるための訳です。提出の本文は `submission-en.md`（英語）を使ってください。

## タイトル
GRANDSTRIDE（鋼脚戦機）

## 一言説明
全高28mの四脚戦機を、コックピットから操縦。防潮堤を守り、機体を強化し、殻王を倒せ。

## 説明
海が下層の街をのみ込み、灰殻（Ashshell）が防潮堤を登ってくる。あなたは四脚戦機 HEKATON TYPE-04 の鞍座に座る。

GRANDSTRIDE は、ブラウザで遊べる一人称のコックピット視点のメカアクション。鞍座から降りることはない。計器を読み、警告灯に目を配り、四本の脚で踏ん張って、防衛線を守る。

- 3つの作戦、3体のボス：殻王、双殻王、渦殻王。
- 四本の脚、四つの脚圧ゲージ。旋回・着地・被弾で減り、ゼロになった脚は機体を傾け、遅くする。
- 一定のリズムで歩いて共鳴率を上げ、鼓動モード OVERBEAT へ。ただし炉温に注意。
- 整備で資材を使い、脚・炉・装甲を強化。
- 勲章、HARD モード、日替わり目標、勝てない作戦のための支援モード。
- すべての音はリアルタイム合成。進行は自動で保存される。

## 操作
PC：W / S で前進・後退、A / D で旋回、マウスで照準、左クリックで射撃、Shift で疾走、Space で跳躍（Space + A / D で横跳び）、Esc または P で一時停止。
スマホ：左スティックで移動・旋回、右側ドラッグで視点、FIRE / BOOST / DASH ボタン。

## タグ・カテゴリ
アクション、シューティング、メカ、ロボット、一人称、3D、SF、一人用、ボス戦、強化

## 言語
英語・日本語（タイトル画面で切り替え。ブラウザの言語で開く）

## 向き・端末
横向き。PC とスマホ（タッチ）。

## 年齢・内容
昆虫型の機械が相手の SF 戦闘。流血なし、人物への暴力なし、賭博なし、チャットなし、外部リンクなし。

## 審査チームへのメモ
- 広告：midgame のみ。作戦のリザルト画面でボタンを押した直後にだけ要求する（作戦中、メニュー、タイトルでは出さない）。広告中は音を消し、広告がなければそのまま続行する。
- 保存：SDK の Data モジュールを使う。
- AI の使用：生成 AI（Claude）を多用し、Team GRANDSTRIDE の指示のもとで制作した。コード・文章・設計資料は AI が下書きし、チームがプレイして確認・編集・承認した。AI の画像生成モデルと AI 生成の音声ファイルは使っていない。映像は AI が書いた three.js のコードが実行時に描き、音はすべて Web Audio API でリアルタイムに合成している。
