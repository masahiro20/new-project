# CrazyGames 審査要件チェック（GRANDSTRIDE）

- 調べた日: 2026-10-13。出典は公式の開発者向け資料 https://docs.crazygames.com/ の次のページ：requirements（technical / gameplay / ads / game-covers / quality）、sdk（intro / video-ads / game / data）、faq。
- 守ったこと：`docs.crazygames.com/robots.txt` は `/sdk/user*` だけを禁止しているので、そこは読んでいません。Developer Portal の利用規約・ログインが要るページは読んでいません（オーナーの登録後に確認が必要。下の「未確認」参照）。
- 状態: ○＝対応済み、△＝対応したが実機（Portal の Preview）で要確認、×＝未対応（提出前に必須）。

## 要件と対応状況

| 区分 | 要件（公式） | 状態 | このビルドの対応 |
|---|---|---|---|
| 技術 | 初回ダウンロード 50MB 以下（モバイル特集は 20MB 以下）、全体 250MB・1,500 ファイル以下 | ○ | zip 約 300KB、約 10 ファイル |
| 技術 | 相対パスのみ（絶対パスは読めない） | ○ | Three.js r128 とフォントを同梱し、`three.r128.min.js`・`fonts/` を相対参照。外部通信は SDK の `<script>` だけ（テストで確認） |
| 技術 | Chrome と Edge で動く。Safari で不調なら Safari では無効にされる | △ | Chromium（Playwright）で確認済み。Edge/Safari は Preview で確認 |
| 技術 | マウス・キーボード、モバイル対応ならタッチ。デスクトップは横向き | ○ | キーボード・マウス・タッチ対応。横向き |
| 技術 | モバイルは `body` に `user-select:none` | ○ | CrazyGames 版の `<head>` に入れた |
| 技術 | iOS は AudioContext をユーザー操作の中で `resume()` | △ | `audio.js` が touch/click で `resume()` を呼ぶ。iPhone の実機は未確認 |
| 技術 | SDK：`Gameplay start/stop`、Data モジュール（セーブがある場合）、Load start/stop（任意） | ○ | `src/crazygames.js`。セーブは Data モジュールに載せる。Data が無効なら通常の localStorage |
| 技術 | 個人データを集める場合は規約・プライバシーの表示 | ○ | 集めていない（外部通信なし、セーブは端末内／SDK） |
| ゲーム | 画面サイズ 907×510 ほか各サイズで文字が読める | △ | 800×450 までテスト済み。907×510・1280×720・全画面は Preview で確認 |
| ゲーム | 物理がリフレッシュレート（144/165Hz）で変わらない | ○ | 時間差分（dt）で動く。QA で fps を変えて確認済み（`weakhit_fps.js`） |
| ゲーム | 英語の表示（必須）。ユーザーの locale に合わせ、無ければ英語 | ○ | 2026-10-14 に英語化。英語が基準で、初期表示は SDK の locale（なければブラウザの言語）が日本語のときだけ日本語。タイトル画面の LANGUAGE ボタンで切り替え（選択は保存される）。画面・ラジオ・操作案内・リザルト・整備・デイリーを英訳（`tests/t12_i18n.js` で、日本語が残っていないことと画面からのはみ出しを確認）。 |
| ゲーム | 操作が直感的 | ○ | 初回の操作案内あり（スキップ可） |
| ゲーム | 名前・素材・内容が独自 | ○ | 完全オリジナル（world-bible.md） |
| ゲーム | 独自の全画面ボタンは禁止 | ○ | 全画面ボタンなし（Portal 側の全画面を使う） |
| ゲーム | 他のゲーム・プラットフォームの宣伝禁止（アプリストアのリンクは常に禁止） | ○ | ゲーム内にリンクなし |
| ゲーム | 13 歳以上、PEGI 12 に収まる | ○ | SF の戦闘（昆虫型の敵）。流血・人物への暴力・性的表現なし |
| ゲーム | （Full Launch）新規ユーザーは即プレイ、最大 1 クリック | △ | タイトル → 出撃ボタン 1 回で始まる（初回は約 5 秒の出撃演出、2 回目以降は約 1 秒）。Preview で確認 |
| 広告 | SDK 経由の広告のみ | ○ | `requestAd('midgame')` のみ |
| 広告 | プレイ中に割り込まない／連続で出さない／ある程度遊んでから | ○ | 作戦の合間（リザルトのボタンを押した直後）だけ。累計 60 秒未満は出さない。SDK が 3 分に 1 回まで |
| 広告 | ナビゲーションボタン（メイン画面・設定・ショップ）では出さない | ○ | 「タイトルへ」「整備」では出さない。「次の作戦へ」「再出撃」「支援モードで再出撃」のみ |
| 広告 | 広告中はゲームを止め、UI を塞ぎ、adFinished/adError まで待つ | ○ | 全面の待ち画面でボタンを押せなくする（リザルト画面でのみ要求するので、ゲームは動いていない） |
| 広告 | 音は、広告が実際に始まったときに消し、終わったら戻す | ○ | `adStarted` で消音、`adFinished`/`adError` で復帰 |
| 広告 | `adError`（広告なし）でも続行できる | ○ | そのまま次へ進む。90 秒たって応答がなくても進む |
| 広告 | 広告ブロックでも普通に遊べる | ○ | 同上（`adError` として扱う）。ペナルティなし |
| 広告 | Basic Launch 中は広告無効でも止まらない | ○ | `adsDisabledBasicLaunch` は `adError` として処理 |
| 広告 | リワード・バナーのルール | ○ | 使わない |
| SDK | `muteAudio` 設定を音量切替より優先 | ○ | 設定と変更通知に対応（`master()`） |
| SDK | タブ切替・フォーカス喪失では gameplayStart/Stop を呼ばない | ○ | 自動一時停止（blur / hidden）では送らない |
| SDK | `happytime` は大きな達成だけ。`reportGameCompletedPercentage` は 0〜100 | ○ | 殻王を撃破しランク A 以上のときだけ happytime。クリアした作戦数 ÷ 3 を報告 |
| 品質（推奨） | 制限キー（Esc は全画面を解除、Ctrl+W）を避ける | △ | 一時停止は `Esc` と `P`。Esc は全画面を解除するが、P でも止められる。キー割当の変更は不要と判断（異論があれば Preview の結果で再検討） |
| 品質（推奨） | オンボーディングはスキップ可 | ○ | 初回の操作案内はスキップ可 |
| カバー | 3 種（1920×1080、800×1200、800×800）。題字のみ。枠・アイコン・"NEW" 等なし | ○ | `covers/`（題字「GRANDSTRIDE」だけ。画面は実際のゲーム描画）。1:1 は題字で機体がやや隠れる |
| FAQ | 独占不要。ほかの販路に出していても可 | ○ | itch.io と並行 |
| FAQ | AI 生成コンテンツの方針は公開資料に記載なし。「独自でない（クローン・素材の使い回し）」は却下理由 | △ | 提出文に AI 使用の開示を入れた（`submission-en.md`）。不安があれば Developer Support に問い合わせ |
