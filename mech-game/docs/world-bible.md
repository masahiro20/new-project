# P8 共有設定（全担当が守る用語集）

既存作品（エヴァンゲリオン等）の名称・用語・デザインは使わない。「使徒」「A.T.フィールド」「エントリープラグ」「シンクロ率」「LCL」「暴走」「ATフィールド」「プラグスーツ」なども禁止。以下の独自用語だけを使う。

| 用語 | 読み / 英語 | 意味 |
|---|---|---|
| 鋼脚戦機 グランドストライド | GRANDSTRIDE | ゲームタイトル |
| 四脚機「ヘカトン」 | HEKATON (TYPE-04) | プレイヤーが乗る全高28mの四足歩行戦機 |
| 鞍士（あんし） | RIDER | 戦機の操縦士。プレイヤー |
| 鞍座（あんざ） | SADDLE | コックピット。機体の胸部にある操縦席 |
| 共鳴率 | RESONANCE (%) | 鞍士の神経と機体の同調の度合い。高いほど反応が速く、武装が強い。被弾や過熱で下がり、リズムよく歩く・連続命中で上がる。100%超で「鼓動モード（OVERBEAT）」 |
| 脚圧 | GRIP (FL/FR/RL/RR) | 4本脚それぞれの踏ん張り。旋回・着地・被弾で消耗。0の脚があると転倒の危険、移動が遅くなる |
| 炉温 | CORE TEMP | 機体の動力炉の温度。ダッシュ・ブースト・射撃で上昇。過熱すると強制冷却 |
| 灰殻（はいがら） | ASHSHELL | 敵。旧時代の自律兵器群。甲虫型・浮遊型・大型「殻王（シェルロード）」 |
| 汀都（ていと） | SHORE CITY | 舞台。海に沈みかけた巨大都市。2091年 |
| 管制 | CONTROL / 管制官「イツカ」 | 無線でミッションを支援する声（テキスト） |
| 出撃 | LAUNCH | ゲーム開始ボタン |
