## 2. コア体験（3本柱）

| 柱 | 一言 | 具体 |
|---|---|---|
| ① 乗り込む | 「起動してるのは俺だ」 | 出撃シーケンスを手で踏む。計器・警告灯・管制イツカの声で鞍座の中にいる感覚を作る |
| ② 踏みしめる | 「この重さを支えているのは俺の脚だ」 | 4本脚それぞれの脚圧を管理。踏ん張って撃つ・耐える・跳ぶ。軽快さより「質量」 |
| ③ 共鳴する | 「機体と鼓動が重なる」 | リズムよく歩き当て続けると共鳴率が上がり、100%超の鼓動モードで一気に逆転 |

## 3. ゲームループ

**30秒ループ**

| 秒 | プレイヤーの行動 | 感じること |
|---|---|---|
| 0–5 | 管制イツカが接敵を告げる。歩律に合わせて前進、共鳴率がじわりと上昇 | 緊張と高揚 |
| 5–12 | 甲虫型の群れに射撃。連続命中で共鳴率↑、炉温↑ | 撃つ快感 |
| 12–18 | 浮遊型の砲撃。旋回・回避で脚圧FL/FRが減り警告灯が点滅 | 「脚が持たない」焦り |
| 18–24 | 踏み据え（停止して脚圧回復）か、熱逃し（炉温を下げる代わりに無防備）を選ぶ | 判断の重み |
| 24–30 | 共鳴率100%到達 → 鼓動モードで殲滅。計器が赤から金に変わる | カタルシス |

| 単位 | 流れ | 報酬 |
|---|---|---|
| ミッション（5〜10分） | ブリーフィング → 出撃シーケンス → 3〜4波の灰殻 → 殻王/中型戦 → 帰投・評価 | 資材、殻片（強化素材）、評価ランク S〜D |
| メタ（数時間） | 格納庫で換装 → 鞍士スキル習得 → 共鳴の絆が深まる → 汀都の区画を奪還 → 新作戦解放 | 新パーツ、絆イベント、物語の進行 |

## 4. 操縦の独自要素

| 要素 | ルール | プレイヤーが感じること | 他メカゲームとの違い |
|---|---|---|---|
| 共鳴率 RESONANCE | 0〜120%。連続命中・一定リズムの歩行で上昇、被弾・過熱・転倒で低下。高いほど旋回速度/照準追従/武装威力が上がる。100%超で鼓動モード（約10秒、全武装強化・脚圧減少無効）、終了後は60%まで低下 | 「機体が自分の延長になる」感覚。上手さが数値で見える | 一般的なエネルギーゲージではなく「操縦の上手さ＝機体性能」。スキルがそのまま強さに直結 |
| 脚圧 GRIP（FL/FR/RL/RR） | 各脚0〜100。旋回で外側の脚、着地で全脚、被弾で被弾側の脚が消耗。踏み据え（停止）で回復。0の脚が1本で速度-30%、2本で転倒（数秒の無防備＋共鳴率-20%） | 巨体の重さと不安定さ。「右前脚がもう限界だ」という具体的な焦り | 体力ではなく「姿勢」を管理する。四脚ならではの左右前後の駆け引き |
| 炉温 CORE TEMP | ダッシュ・跳躍ブースト・射撃で上昇。85%で警告、100%で強制冷却（約4秒移動・射撃不可）。熱逃し操作で任意に排熱できるが2秒間無防備 | 撃ちすぎの誘惑と自制。排熱の白煙と轟音の快感 | 単なるオーバーヒートでなく、共鳴率低下と連動して「機体が苦しむ」演出 |
| 鞍座の計器と警告灯 | 鞍座視点HUD：共鳴率メーター（中央）、脚圧4本（機体シルエット上）、炉温計、警告灯パネル（脚圧低下=黄、過熱=赤、転倒危険=赤点滅、鼓動モード=金）。警告時は警報音＋イツカの音声テキスト | 「計器を読んで機体を感じる」パイロット感 | 画面端の数字ではなく、鞍座に組み込まれた物理計器として表示。視点を外に出さない |
| 出撃シーケンス | 出撃ボタン → 鞍座ロック → 炉点火（キー長押しで炉温を適正帯に合わせる）→ 神経接続（タイミング入力で初期共鳴率が決まる 40〜70%）→ 四脚ロック解除 → 射出。全体20〜30秒、2回目以降はスキップ可 | 自分の手で機体を起こす儀式。上手く入ると有利に始まる | 演出だけのムービーではなく、手順の出来が戦闘の初期値になる |

## 5. 敵：灰殻（ASHSHELL）

| 名称 | 型 | 役割 | プレイヤーへの圧 |
|---|---|---|---|
| 這殻（はいかく）★ | 小型甲虫型 | 群れで脚にまとわりつく雑魚 | 脚圧をじわじわ削る。撃って共鳴率を稼ぐ「燃料」 |
| 角殻（かくかく）★ | 中型甲虫型・突進 | 正面から体当たり | 被弾側の脚圧を大きく削る。回避か踏み据えで受けるか |
| 浮殻（ふかく）★ | 浮遊型・砲撃 | 遠距離から曲射 | 足を止めさせない。旋回を強要し脚圧を消耗させる |
| 霧殻（むかく）★ | 浮遊型・妨害 | 灰の霧で計器を乱す | 計器の一部が読めなくなる。鞍座演出の見せ場 |
| 錨殻（びょうかく）★ | 大型・地中型 | 地面から脚を掴み拘束 | 1本の脚が固定され、残り3本で戦う |
| 殻王 SHELLLORD | 超大型ボス | 各幕の最終戦。弱点の殻を順に剥がす | 全要素の総合試験。鼓動モードの使いどころが勝敗を分ける |

## 6. 成長要素

| 系統 | 内容 | 例 |
|---|---|---|
| 脚部換装 | 脚圧上限・回復速度・機動性のトレードオフ | 重装脚（脚圧↑速度↓）、跳躍脚（ブースト跳躍可、着地消耗↑）、杭脚（踏み据えで砲撃安定） |
| 武装換装 | 背部2・腕部2のスロット。炉温負荷が異なる | 連装機関砲、杭打ち砲、熱線刃、拡散噴進弾 |
| 炉換装 | 炉温上限と冷却速度、鼓動モード時間 | 安定炉（冷却↑）、高鳴炉（鼓動モード延長、過熱しやすい） |
| 鞍士スキル | ミッション評価で得る技能点でツリー習得 | 「踏み据え短縮」「歩律の才（共鳴率上昇+15%）」「冷静な排熱（熱逃し中の被ダメ半減）」 |
| 共鳴の絆 BOND★ | 同じヘカトンで出撃を重ねると絆レベル上昇。初期共鳴率・鼓動モード時間が伸び、機体が鞍士の癖を覚える（例：よく使う旋回方向の脚圧消耗軽減） | 機体を乗り換えると絆は別管理 → 「相棒」への愛着 |
| 周回 | クリア後「深灰作戦」：灰殻が強化・霧殻常駐、限定パーツ。評価Sでコスメ解放 | 鞍座内装・機体塗装・イツカの別台詞 |

## 8. プロトタイプ（MISSION 01）で検証すること

| 検証項目 | 成功基準 |
|---|---|
| 出撃シーケンスが「乗り込む儀式」として楽しいか | 初回プレイヤーの過半数がスキップせず最後まで操作、「乗った感」があると回答 |
| 脚圧4本の管理が分かり、面白いか | 説明なしで2分以内に「踏み据え」を自発的に使う |
| 共鳴率の上昇→鼓動モードが気持ちいいか | 1ミッション中に1回以上発動し、発動時に撃破ペースが上がる |
| 炉温と熱逃しの判断が生まれるか | 強制冷却を1回経験した後、自主的な熱逃しが増える |
| 鞍座HUDが読めるか | 警告灯の意味を事後アンケートで8割が説明できる |

**MISSION 01 の範囲**: 防潮堤エリア1面／敵は這殻・角殻・浮殻の3種＋小型殻王1体／武装は連装機関砲のみ／出撃シーケンス・共鳴率・脚圧・炉温・警告灯・イツカの無線テキスト・評価画面。

**次に足すもの（優先順）**: ①格納庫と脚部換装（3種） ②霧殻・錨殻 ③鞍士スキルツリー ④共鳴の絆 ⑤第1幕の通し（3ミッション）→ Steam 体験版／ストアページ公開でウィッシュリスト計測。
