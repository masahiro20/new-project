# MISSION 03 実装仕様「汀都 第三防潮堤外縁 嵐中観測戦」

> 用語は world-bible.md / game-design.md に準拠。★は本書で追加する用語（game.html の用語コメントにも追記すること）。

## 1. コンセプト
| 項目 | 内容 |
|---|---|
| 一行 | 暴風雨で目が利かない干潟で、四脚を踏み据えて地面の震えを読み、計器だけを頼りに灰殻と殻王を狩る |
| 新しい遊びの軸（1つ） | **視界不良と計器頼み**。目で見えない敵を、レーダー・脚圧計・雷光で「読む」 |
| M01 との違い | M01 は見えている敵を撃つ基本戦。M03 は「まず見つける」が先に来る |
| M02 との違い | M02 は突進の予兆を見て躱す反応戦。M03 は止まって探る／動いて撃つを切り替える判断戦 |
| この案を選んだ理由 | ①四脚を地面に据えると4点の震えで方角が分かる＝「脚」が武器以外の役割を持つのは四脚だけ ②鞍座の計器を読む柱（コア体験①）が主役になる ③霧と雨は Three.js の fog と粒子で安く作れる（高低差の地形は当たり判定と脚の接地を全部作り直すので見送り） ④霧殻は game-design.md 5節で予定済みの敵 |
| 新操作 | なし（既存の踏み据えに**震動探知★ TREMOR SCAN** を乗せる：停止1.2秒でピン、4秒間レーダーが広がる） |

## 2. ステージ「汀都 第三防潮堤外縁・干潟区画」
| 項目 | 内容 |
|---|---|
| 場所 | 第1幕「上陸」の締め。防潮堤の外側、潮が引いた干潟。旧送電塔と半分沈んだ観測塔が立つ |
| 地形 | 平坦（y=0 のまま）。範囲は x ±260 / z ±260 の四角。外周は高波の壁（境界の台詞を流用） |
| 天候 | 暴風雨。基本の視界 約90m。9〜14秒ごとに雷光で0.4秒だけ約400mまで見える |
| 雰囲気 | 青灰色の闇、横殴りの雨、遠い雷鳴。計器の光だけが暖かい。雷光の一瞬に巨大な影が見える |
| 構成要素（当たり判定は塔だけ） | 地面（canvasTex の濡れた泥＋水たまりの反射色）／送電塔 約40本（InstancedMesh、細い箱4本＋横桁）／観測塔3基（円柱＋回転灯）／防潮堤の壁（長い箱1枚、北側）／雨（線状の粒子、カメラに追従する箱の中だけ）／雷光（HemisphereLight の強さと fog 密度を一瞬だけ変える） |
| 品質「低」 | 雨の粒子は Q.fx で4割まで／送電塔は bldR で遠いものを描かない／観測塔の回転灯の光（PointLight）は setDeco(false) で切る／雷光時の空の閃光の板は描かない。**fog の密度だけは全品質で同じ値に固定**（視界がゲーム性そのものなので、品質で難度が変わってはいけない。Q.fog は使わない） |

## 3. 敵
| 名称 | 挙動 | 予兆 | 対処 |
|---|---|---|---|
| 霧殻（むかく）HAZE（新） | 高さ20m前後を漂い、半径45mの灰の霧を出す。自分は撃たない。霧の中ではレーダーに砂嵐、脚圧計4本が「---」表示、照準の固定が外れる。HP は浮殻の6割 | 霧を出す1.5秒前に白く脈打つ＋低いさえずり音。レーダーの砂嵐の中心が霧殻の位置 | 砂嵐の中心へ撃つ。雷光で姿が見える。倒すと霧が3秒で晴れる。踏み据えの震動探知では映らない（浮いているので） |
| 既存（這殻・浮殻・衝角殻） | M02 と同じ。這殻と衝角殻は地上型なので震動探知に映る | 衝角殻の溜めの赤い光は霧越しでも見える（予兆の光だけは fog の影響を受けない） | 既存どおり |

**ボス：渦殻王（うずがらおう）★ MAELSHELL**（干潟の泥の下を泳ぐ殻王。HP は双殻王の1.3倍）

| 段階 | HP | 行動 | 攻撃パターン | 弱点・崩し方 |
|---|---|---|---|---|
| 1 潜行 | 100〜65% | 泥の中を回り、6〜8秒ごとに浮上 | 浮上の突き上げ（半径22m、ダメージ＋全脚の脚圧-18）。予兆は**近い脚の脚圧計が震えて点滅**＋足元に水の輪 | 予兆で跳躍すれば回避（waveDodges に数える）。浮上後3秒、背中の吸気口3つが開く＝弱点 |
| 2 嵐の目 | 65〜30% | 地上に出て周りを歩く。視界が約50mまで落ちる | 雷を呼ぶ：地面に予告円（2秒）→落雷。8連の光弾（浮殻の弾を流用） | 吸気口は雷光の間だけ光って見える。レーダーには常に映る（大きすぎて隠れない） |
| 3 渦 | 30〜0% | 潜っては浮上を3秒おきに繰り返し、霧殻を2体呼ぶ | 突き上げ＋光弾。霧殻の霧の中では計器が乱れる | 霧殻を先に落とすか、踏み据えで浮上地点を読んで待ち伏せ。鼓動モードの使いどころ |

## 4. ミッションの流れ（制限時間 5:00）
| 時刻 | 出来事 | 狙い |

|---|---|

## 7. 実装メモ
| 流用する仕組み | 使い方 |
|---|---|
| STAGES / setStage / buildPort / applyStageQuality | buildStorm() を buildPort を手本に追加。setStage('storm') の遅延生成。stage.fogFixed を足し、setStage で Q.fog の代わりに使う |
| addCollider / clearAt / spawnPos / buildingAt / losClear | 送電塔・観測塔の当たり判定と出現位置 |
| MISSIONS / SPAWN_ORDER_2 / updSpawns / spawnBoss / BOSS_TYPES | MISSIONS[3]（stage:'storm', time:300, boss:'mael'）。ボス出現条件に「塔3基」を足す |
| makeFloater / spawnEnemy / updEnemies / removeEnemy / killEnemy | makeHaze() は makeFloater の色違い＋霧の板。updEnemies に haze と mael の分岐 |
| makeTwin / updTwin / twinTransform / updTwinTransform | 渦殻王の段階遷移と演出の型。weakInfo / weakPoint / aimPoint に吸気口を追加 |
| hurt(amount, src, extraGrip) | 突き上げは extraGrip で全脚の脚圧を削る |
| updPlayer（脚圧回復の「停止」条件）/ P.grounded / waveDodges | 踏み据え判定を関数 isBracing() に切り出して震動探知と塔起動で共用。突き上げ回避を waveDodges に数える |
| drawRadar / updHUD / gripColor | drawRadar(dt) の range を変数化（嵐120／ピン中300）。霧の中は砂嵐描画と脚圧の「---」 |
| emit / makeParticles / setParticleCap / dustBurst / updAmbient | 雨は専用の粒子（Q.fx で上限）。雷光は updAmbient でタイマー管理 |
| say / calcReward / applyDaily / newRunStats / loadSave / m2Unlocked / selectMission / refreshTitle | 無線、報酬、デイリー。newRunStats に kills.haze・scans・flashHits・towers。loadSave の cleared を 1〜3 に。mUnlocked(id) に一般化 |

| 追加する __GAME フック | 返り値・動作 |
|---|---|
| startMission(3) / m3Unlocked | 現状 1/2 に丸めているので 3 を通す／SAVE.cleared[2] |
| storm | {fog, visibility, lightningIn, radarRange, scanT, hazeLevel(0〜1)} |
| towers | [{id, x, z, prog, done}] |
| debugActivateTower(i) / debugLightning() / debugBossPhase(n) / debugSetWeather('clear'\|'storm') | 塔の即時起動／雷光を今すぐ／渦殻王を n 段階目から（debugBossPhase2 を一般化）／晴れにして見た目確認。すべて debug 扱いで記録しない |

| テスト観点 | 確認内容 |
|---|---|
| 解放 | M02 未クリアで M03 は選べない。クリア後に選べ、保存を読み直しても残る |
| 品質・探知 | low/mid/high で storm.fog が同じ、low で雨粒子4割。停止1.2秒でピン、移動・跳躍で中断。浮いた霧殻は映らず地上型は映る |
| 霧殻・塔 | 霧の中で脚圧計が「---」、撃破後3秒で戻る。溜めの光は霧越しに見える。塔は 25m以内で4秒踏み据えで起動、離れると進捗が止まる。3基＋14体でボスが出る |
| ボス | 段階 65%/30% で遷移。突き上げの予兆が脚圧計に出て、跳躍で回避すると waveDodges+1 |
| 終了・性能 | 時間切れで敗北、debug の回は記録・デイリーに数えない、資材が calcReward の式どおり。mid で M02 と同等の fps |

## 8. バランスの目安（初見〜3回目の想定クリア率）
| 強化の合計段階（脚＋炉＋装甲、0〜15） | 想定クリア率 | 意図 |
|---|---|---|
| 0〜2 | 20〜30% | 上手い人は無強化でも勝てる。多くは一度負けて整備へ |
| 3〜5（M01・M02 初クリア分の資材で届く） | 45〜55% | 標準の到達点。2〜3回目で勝てる |
| 6〜9 | 65〜75% | 脚の強化が効く（脚圧↑で突き上げに耐える、踏み据えの回復が速い） |
| 10〜15 | 85〜90% | S ランクと残り時間のデイリーを狙う段階 |

M01（3分）＋M02（4分）＋M03（5分）で通し約12分。負け1回と整備を含めて1回の訪問が15分前後になり、平均プレイ10分以上を狙う。
