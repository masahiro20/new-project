        How it works & assumptions
        
    
        The calculator totals your input, cache-write, cache-read and output tokens, prices each model in your data at its own list price (your “current” cost), then prices the whole bundle on every candidate model.
        
    
        
      
          
        
        • Tokenizers differ. Anthropic, OpenAI and Google count tokens differently, so the same text gives different token counts. Cross-provider comparisons are estimates; same-provider ones are tighter.
          • 
        
        • Cache handling. With “Keep my cache hit ratio” on, cache-read tokens are charged at the target’s cache-read price and cache-write tokens at its cache-write price. Anthropic cache writes use the 5-minute price; 1-hour writes cost 2× input. On OpenAI targets each input token is billed as exactly one of input, cached input or cache write, so writes use the listed cache-write price (or the input price when none is listed). Gemini has no cache-write price; it bills cached tokens at a lower rate plus storage per hour. Here, cache-write tokens on Gemini targets are charged at the input price and cache storage is not included. Turn it off to price every input token at the normal input price.
          • 
        
        • 30-day normalisation multiplies totals by 30 ÷ the number of days your data covers (first to last date).
          • 
      
        
      
          
        
        • Claude Haiku 5.5 is priced at its tier for prompts up to 100K tokens. Prompts over 100K cost more ($0.50 input / $2.50 output / $0.05 cache read / $0.625 5-minute write per 1M).
          • 
        
        • OpenAI prices are the Standard tier for prompts up to 272K input tokens. Long-context (>272K) prices are higher and not applied.
          • 
        
        • Gemini prices are the Paid tier, Standard, text/image/video input. Gemini 3.1 Pro Preview and 2.5 Pro use the tier for prompts up to 200K tokens (over 200K is higher and not applied). Gemini 3.8 / 3.7 / 3.6 Flash use a promotional price that runs through 2026-12-31.
          • 
        
        • Not included: Batch or Flex discounts, long-context surcharges, Fast/priority modes, regional or data-residency uplifts, taxes and credits.
          • 
        
        • Cost only. Quality, latency and context limits differ between models. Test on your real tasks before you switch.

        FAQ
        
    
        Is my usage data uploaded anywhere?
      
        No. Parsing and maths run in JavaScript in this page. There is no backend, no analytics and no tracking, and the page’s Content-Security-Policy blocks network requests. You can load it, go offline and it still works.
        
    
        Which files can I use?
      
        Anthropic Console usage CSV, Anthropic Admin API usage_report/messages JSON, OpenAI usage CSV, OpenAI Admin API /v1/organization/usage/completions JSON, or a generic CSV with date,model,input_tokens,output_tokens[,cached_input_tokens]. The format is detected automatically; comma, tab and semicolon separators work.
        
    
        Can I use Google Gemini usage?
      
        There is no dedicated Gemini export parser. Put your Gemini token counts into the generic CSV above (for example from your own logs of usageMetadata: prompt tokens as input_tokens, candidates plus thinking tokens as output_tokens, cached content tokens as cached_input_tokens). Model names such as gemini-3.8-flash or models/gemini-2.5-pro are matched to the price table.
        
    
        What does “Copy share link” share?
      
        Only settings and aggregate token totals, encoded in the part of the URL after #, which browsers do not send to the server. Your pasted data is never put in the link. Open “What’s in this link” under the results to see exactly what it contains before you copy it. The totals do reveal how much you use, so share it only with people who may see that.
        
    
        Why doesn’t “current cost” match my invoice exactly?
      
        It uses list prices at the standard tier. Batch discounts, long-context tiers, regional uplifts, credits and taxes are not included, and some exports round token counts.
        
    
        A model in my data says “not in price table”.
      
        That usage is left out of the current cost, and the difference column is hidden so you don’t compare against a partial total. Candidate costs still include all of your tokens.
        
    
        How current are the prices?
      
        They were checked against the official pages on 2026-10-09. Each row links to its source. If a price is ever marked “Unverified”, it is left out of totals until you type a price in yourself.
