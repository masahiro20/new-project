## 1. 虐待防止　［減算］

虐待防止措置未実施減算（所定単位数の1%）。減算になるのは、委員会を開いていない、研修をしていない、担当者を置いていない、のいずれかの場合です。

| 確認 | 書類・体制 | 保管場所 |
| --- | --- | --- |
| □ | 虐待防止委員会を1年に1回以上開いた記録（議事録）がある　※「年度内」ではなく「直近1年以内」で数える自治体があります。数え方は指定権者に確認してください。 | 　 |
| □ | 委員会の結果を従業者に周知した記録がある（回覧の確認欄、職員会議の記録など）　※周知は運営基準で求められています。 | 　 |
| □ | 虐待防止研修を1年に1回以上行い、資料と参加者名簿が残っている | 　 |
| □ | 新規採用者に虐待防止研修を行った記録がある　※解釈通知は、新規採用時には必ず研修を行うことが重要としています。 | 　 |
| □ | 研修を欠席した職員へのフォロー（資料の配布、録画での受講など）の記録がある | 　 |
| □ | 虐待防止の担当者が決まっていて、運営規程や体制表で分かる | 　 |


## 2. 身体拘束等の適正化　［減算］

身体拘束廃止未実施減算（放課後等デイサービス・児童発達支援は所定単位数の1%）。身体拘束をしていない事業所でも、4つの要件はすべて必要です。

| 確認 | 書類・体制 | 保管場所 |
| --- | --- | --- |
| □ | 身体拘束等を行った場合の記録様式がある（態様・時間・本人の心身の状況・緊急やむを得ない理由）　※使ったことがなくても、様式は用意しておきます。 | 　 |
| □ | 身体拘束等の適正化のための委員会を1年に1回以上開き、結果を周知した記録がある　※虐待防止委員会と一体で開く場合は、両方の議題を扱ったことが議事録で分かるようにします。 | 　 |
| □ | 身体拘束等の適正化のための指針がある | 　 |
| □ | 身体拘束等の適正化のための研修を1年に1回以上行った記録がある　※虐待防止研修と一体で行う場合も、身体拘束の内容を扱ったことを記録します。 | 　 |
| □ | 緊急やむを得ない場合の3要件（切迫性・非代替性・一時性）を、組織として確認する手順を決めている | 　 |


## 3. 業務継続計画（BCP）　［減算］

業務継続計画未策定減算（所定単位数の1%）。減算の要件は、感染症と自然災害の業務継続計画を策定し、計画に従って必要な措置を講じていることです。経過措置は令和7年3月末で終わっています。

| 確認 | 書類・体制 | 保管場所 |
| --- | --- | --- |
| □ | 感染症の業務継続計画がある | 　 |
| □ | 自然災害の業務継続計画がある（感染症と一体で作ってもかまいません） | 　 |
| □ | 計画を従業者に周知し、研修と訓練（シミュレーション）を1年に1回以上行った記録がある　※運営基準上の義務です。減算の要件そのものではありませんが、運営指導で確認されます。 | 　 |
| □ | 計画を定期的に見直した記録がある | 　 |
| □ | 子ども特有の場面（休校・下校時刻の変更、送迎ルートの災害、保護者への引き渡し）が計画に入っている | 　 |


## 4. 公表と報告　［減算］

障害児通所支援には、公表と報告の義務があります。届出や報告がないと減算になるものがあります。

| 確認 | 書類・体制 | 保管場所 |
| --- | --- | --- |
| □ | 5領域との関連を示した事業所全体の支援プログラムを作り、インターネット等で公表している　※公表の方法・内容を指定権者に届け出ていないと、支援プログラム未公表減算（所定単位数の85%で算定）になります。届出の方法は自治体ごとに違います。 | 　 |
| □ | 従業者評価・自己評価・保護者評価を行い、おおむね年1回以上、結果と改善の内容を公表している | 　 |
| □ | 障害福祉サービス等情報公表制度への報告をしている　※報告していないと、情報公表未報告減算（所定単位数の5%）になります。 | 　 |

## もし減算の対象になっていたら

- 虐待防止・身体拘束の減算は、基準を満たしていない状況が確認された月の翌月から、改善が認められた月まで、利用者全員について行われます。さかのぼっては適用されません。速やかに改善計画を指定権者に出し、その後、改善状況を報告します（期限は指定権者の指示に従ってください）。
- 業務継続計画未策定減算は、運営指導等で未策定が分かった場合、基準を満たさない事実が生じた時点までさかのぼって適用されます（令和6年度報酬改定Q&A VOL.1 問15）。情報公表未報告減算は、報告していないことが都道府県等で確認され、報告するよう指導されても報告しない場合に、未報告の時点にさかのぼって適用されます（同 問19）。
- 減算すべき月に減算せずに請求していた場合の取扱い（請求の修正など）は、指定権者に確認してください。
