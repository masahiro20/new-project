# 今週オーナーにお願いする3件のやり方

作成：Midas（2026-10-09）　対象：オーナー（masahiro20 さん）

**大事なこと**
- パスワード、マイナンバー、口座番号、カード番号は、本部やチームに**送らないでください**。終わったら「できた」と、お店やページの URL だけ教えてください。
- 画面の名前やボタンの位置は、サイトの更新で変わることがあります。見つからないときは、画面の写真（個人情報は隠して）を送ってもらえれば、本部が案内します。
- どれも費用はかかりません。

## 1. itch.io に登録し、お金の受け取り方を設定する（約30分・10/12まで）
**何のため**：P8 のゲーム（GRANDSTRIDE）を 10/13 に無料で公開し、気に入った人が投げ銭できるようにするため。

1. https://itch.io を開き、右上の「Register」から登録します（メールアドレスとパスワード）。
2. 「ゲームを公開する人（creator）」として使う設定を選びます。
3. 設定の「Payment」で、お金の受け取り方を選びます。**「itch.io がまとめて受け取る方式（Payouts）」を選んでください。**
   - こちらだと、海外の消費税の手続きを itch.io がやってくれます。
4. 受け取り先として、PayPal か Payoneer のどちらかをつなぎます（PayPal をお持ちならそれで十分です）。
5. **税の質問票（tax interview）**に答えます。
   - アメリカの会社からお金を受け取るための書類（W-8BEN）です。
   - **納税者番号を入れないと、売上の30%が差し引かれます。**
   - 日本の番号（マイナンバー）を書くかどうかは、入力の前に本部と一緒に確認しましょう。今わかっているのは「番号なしだと30%」ということだけです。
   - 質問票は、最初にお金を引き出すときまでに済めば大丈夫です。今日できなければ、後回しでかまいません。
6. 登録が終わったら、ゲームのページの作成は本部が文面と画像を用意します。オーナーは貼り付けと公開ボタンだけです（10/12 の夜）。

**終わったら本部に伝えること**：「itch.io 登録できた」と、自分のページの URL（例：https://○○.itch.io）。

## 2. BOOTH と Ko-fi に登録し、振込先を入れる（約30分・10/16まで）
**何のため**：P7 の設定資料集（LEDGERBREAKER『帳簿の書 Vol.0』）を、10/22 に日本語版は BOOTH（500円）、英語版は Ko-fi（4ドル）で売るため。

### BOOTH（日本語版）
1. https://booth.pm を開き、pixiv のアカウントでログインします（なければ作ります）。
2. 「ショップを開設」を選び、ショップ名を入れます。
   - 案：「LEDGERBREAKER」。本部で変えても大丈夫です。
3. 売上の振込先（銀行口座）を登録します。
4. **販売者の表示（特定商取引法の表記）は、まだ入れないでください。** お願い3で決めてから入れます。

### Ko-fi（英語版）
1. https://ko-fi.com を開き、「Sign up」から登録します。
2. お金の受け取り先として、PayPal か Stripe をつなぎます（PayPal が簡単です）。
3. 「Shop」を使える状態にします。
   - 商品の登録は、本部が用意した英語の文面を貼るだけです（10/19）。

**終わったら本部に伝えること**：「BOOTH と Ko-fi 登録できた」と、それぞれのショップの URL。

## 3. P7 を売る前の確認2つ（約35分・10/16まで）

### 3-1. 作品の名前が、もう他の人に登録されていないか調べる（約20分）
**何のため**：作品名「LEDGERBREAKER」「帳簿破り」が他の人の商標になっていると、売った後に名前を変えなければならなくなるため。前の名前（RED LEDGER）は、同じ名前の小説があったので変えました。

**日本（特許庁の無料の検索サイト J-PlatPat）**
1. https://www.j-platpat.inpit.go.jp/ を開きます。
2. 「商標」→「商標検索」を開きます。
3. 次の3つを、1つずつ入れて検索します。
   - `LEDGERBREAKER`
   - `帳簿破り`
   - `レジャーブレイカー`
4. 結果が出たら、その商標が登録されている分野（「区分」）を見ます。今回関係があるのは、次の4つです。
   - 9類：ダウンロードできる電子書籍など
   - 16類：本など
   - 28類：おもちゃ
   - 41類：電子書籍の提供、娯楽

**アメリカ（米国特許商標庁の無料検索）**
1. https://tmsearch.uspto.gov/ を開きます。
2. `LEDGERBREAKER` と `LEDGER BREAKER` で検索します。

**本部に伝えること**
- 「何件出たか」と、出た場合はその名前と区分。画面の写真でもかまいません。
- 0件なら「0件」とだけ。
- 判断は本部がします。似た名前があって判断が難しい場合だけ、専門家に相談するかどうかをオーナーに聞きます。

### 3-2. 販売者の表示をどうするか決める（約15分）
**何のため**：ネットで物を売るときは、法律（特定商取引法）で、販売者の名前・住所・電話番号などを表示する決まりがあります。

**選び方**（どれにするか、オーナーが決めてください）
| 案 | 内容 | 向いている場合 |
|---|---|---|
| A | 名前・住所・電話番号をそのまま表示する | 住所を出しても気にならない |
| B | 「請求があれば、すぐにお知らせします」と書き、住所と電話番号を表示しない | 自宅の住所を出したくない。**ただし、この方法が使える条件があり、本部が消費者庁のガイドで確かめてから使います** |
| C | 住所を借りられるサービス（バーチャルオフィス）の住所を使う | 自宅は出したくないが、住所は表示したい。**月に費用がかかるので、今はおすすめしません** |

**本部に伝えること**：A・B・C のどれにするか。B を選んだ場合は、本部が条件を確かめて、表示の文面を用意します。
