# P8 GRANDSTRIDE　収益化の比較（CrazyGames・itch.io・Steam）

作成：Midas（2026-10-09）
元にしたもの：
- P8 チームの `mech-game/docs/monetization.md`（`peter/p8-mech-game`）
- Midas の `peter-hq/revenue/p8-launch.md`（公式資料の確認つき）

金額は、各販路を始めてから12か月の手取り（手数料を引いた後、税の前）。1ドル＝150円。

## 結論
1. **itch.io は今週出す（費用0円、手間は約30分）。** 最初の1円と、遊んだ人の声を取る場所。
2. **CrazyGames は、手直しの後（2〜3週目）に出す。** 広告の収益は大きくないが、費用0円で、プレイ数と「遊ばれるか」の数字が手に入る。
3. **Steam のページは、ゲートを満たすまで作らない。** 登録費 $100（約1.5万円）と、オーナーの手続きが一番重い。数字（週8のゲート）が出てから判断する。

## 比較表
| | itch.io（無料＋投げ銭） | CrazyGames（広告の収益分配） | Steam（ページ → 早期アクセス） |
|---|---|---|---|
| **お金の入り方** | 投げ銭（推奨 $3）、のちに支援者版 $4.99 | 広告の収益分配。分配率は公式に非公開（ゲームジャムの規約では広告60%） | 買い切り（早期アクセスで $9.99 前後の案） |
| **12か月の見込み（P8 チームの試算）** | 悲観 約0.75万／標準 約9.5万／楽観 約68万円 | 悲観 ほぼ0（支払い基準 €100 に届かない）／標準 約13.5万／楽観 約162万円 | 発売後の初年度：失敗 約12万／控えめ 約38万／標準 約185万／楽観 約945万円。**発売は 2027年夏の予定なので、この12か月に入るのは1〜2か月分だけ** |
| **始めるまでの費用** | 0円 | 0円 | **$100（約1.5万円）**。売上が $1,000 を超えると取り戻せる。カプセル画像などを外注するなら 3〜10万円 |
| **始めるまでの時間** | 当日（審査なし） | Basic Launch の審査の後、7〜21日の試験。数字が良ければ本公開に招待 | 新しい開発者は、支払いから30日たたないと発売できない。ページは発売の2週間以上前に公開 |
| **オーナーの手間** | 登録、受け取り方法、税の質問票（約30分） | 開発者アカウント、受け取り（Tipalti）の登録（約30分）。SDK の組み込みは P8 チーム | Steamworks の登録（本人確認、銀行口座、税の質問票）、$100 の支払い、価格・発売日の判断（合計 1〜2時間＋判断） |
| **審査・条件** | なし。生成 AI を使った場合は申告が必須 | 平均プレイ10分以上、1分以上遊ぶ人80%以上、翌日に戻る人10〜15%が目安（公式）。今の約3分の作戦では届かない見込み | ページの審査 1〜5日。AI を使った内容の申告 |
| **リスク** | 売上の規模が小さい | 本公開に進めないと収益ゼロ。広告の単価は低い | 埋もれると売れない（売上の中央値は非常に低い） |
| **得られるもの（お金以外）** | 声、最初の支援者 | プレイ数、遊ばれるかの数字（Steam の判断材料） | ウィッシュリスト（発売時の売上を左右する） |

## 判断の順番とゲート（P8 チームの計画に合わせた）
| 時期 | やること | 次に進む条件 |
|---|---|---|
| 週1〜2（10/12〜） | itch.io で公開（10/13 予定） | 14日でプレイ300以上、平均4分以上、コメント・フォロー10以上 |
| 週3〜4 | 手直しのうえ CrazyGames に提出 | 試験で7日以内に500プレイ、本公開へ招待 |
| 週5〜8 | 作戦を3つに増やす。CrazyGames の本公開（広告）、itch の支援者版 $4.99 | 週8で次の3つのうち2つ：itch の購入・投げ銭が30件または $150 以上、X のフォロワー300以上、CrazyGames の月間プレイ2万以上 |
| 週9〜12 | **ここで初めて Steam に $100 を払い、ページを公開** | 公開から30日でウィッシュリスト500以上 |

## Midas の見立て
- 最初の12か月で確実に見込めるのは、itch と CrazyGames を合わせて**標準で20万円台前半**。Steam は2027年夏以降の話。
- **Steam のページを早く作る利点**は「ウィッシュリストを早くためられる」こと。ただ、今のブラウザ版だけでは集まりにくく、$100 と手続きの手間を先に払う理由は弱い。週8のゲートを待つのがよい。
- CrazyGames の広告収益は少額だが、「遊ばれるか」を無料で測れる点が一番の価値。
