# Peter HQ（ピーター本部）

オーナー（masahiro20）から全体の管理を一任された統括PM「ピーター」の本部です。
Claude Code Max プランを予算として使い、**世界の一部の人が強く欲しがる、ニッチで最先端のツール**を複数同時に作ります。

## 方針

- **大衆向けは作らない。** 「世界で1000人が本気で欲しがる」ものを狙う。
- **英語ファースト＋日本の強みを入れる。** 日本のデータ・市場・文化に近いことを差別化に使う。
- **小さく出して、数字で判断する。** 各プロジェクトはステージゲート（下記）を通らないと次に進めない。
- **作っている過程をXで発信する（build in public）。**

## 組織

```
オーナー（masahiro20）
└─ ピーター（統括PM・本部）
   ├─ INTEL デスク ── リーダー: Iris（最先端情報の収集、毎晩の報告）
   ├─ P1 SkillForge ── リーダー: Forge
   ├─ P2 Signal Lab ── リーダー: Vega
   ├─ P3 Pitch ────── リーダー: Kana
   ├─ P4 Mercari Lens ─ リーダー: Ren
   ├─ P5 Atlas ────── リーダー: Atlas
   └─ P6 Fleet ────── リーダー: Otto
```

各プロジェクトのリーダーは独立した Claude Code セッションで動き、その下に役割ごとのサブエージェントを置きます。

| 役割 | 仕事 |
|---|---|
| リーダー | 計画、優先順位、本部への報告 |
| リサーチャー | 市場・競合・ユーザーの声の調査 |
| ビルダー | 実装（並列で複数立てる） |
| レビュアー | コードレビュー、テスト、セキュリティ |
| グロース | ランディングページ、X投稿案、ローンチ準備 |

## ステージゲート

| ステージ | 内容 | 次に進む条件 |
|---|---|---|
| 0. 企画 | 1枚の企画書 | 本部承認 |
| 1. 検証 | 競合調査、需要の証拠集め、LP | 需要の証拠（例：待機リスト20件、検索需要、コミュニティの具体的な要望） |
| 2. MVP | 中核機能1つだけ実装 | 外部ユーザー5人が実際に使う |
| 3. ローンチ | 課金、Product Hunt / X / Reddit | 最初の有料ユーザー |
| 4. 成長 or 撤退 | 数字で判断 | 90日で有料ユーザーが伸びなければ撤退し、資源を他へ回す |

## 運営リズム

| いつ | 何を |
|---|---|
| 毎晩 21:57（日本時間） | ピーターから「最先端ニュース＋進捗」の報告 |
| 毎週日曜の報告時 | ポートフォリオ見直し（続行・方向転換・撤退） |
| 随時 | オーナーの判断が必要なことだけ質問する |

## オーナーにしかできないこと

次のものはピーターが代わりに作れません。必要になった時点で依頼します。

- 決済アカウント（Stripe など）
- Apple Developer Program（年 $99）、Google Play（$25）、Chrome Web Store（$5）
- ドメイン購入、X アカウント
- 新しい GitHub リポジトリの作成可否

## 運用上の制約

- ピーターは常時起動しているのではなく、**毎晩の定期起動と各リーダーセッション**で動きます。
- Max プランの利用上限が実質の予算です。上限に近づいたら、ステージの進んだプロジェクトを優先します。
