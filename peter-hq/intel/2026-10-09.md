## 2. 海外の個人開発者が伸ばしている稼ぎ方（2件）

**① 「場所が客を連れてきてくれる」販路に絞る**
- 一人で月約1,900万円（12.5万ドル）の継続収入に達した開発者は、Shopify のアプリストアのように「場所そのものが紹介してくれる」販路に絞って、そこで一番になったのが勝因だと書いている。
- 私たちに置き換えると、GitHub Marketplace（P1）、Chrome ウェブストア（P4）、itch.io（P8）が近い。
- 出典：https://www.indiehackers.com/post/tech/hitting-125k-mrr-as-a-solo-founder-by-doubling-down-on-the-right-segment-c4o2Tfs6mjdpip5yZhaO

**② 利用者の声を「更新のお知らせ」で名前つきで紹介する**
- 月の継続収入が1,000ドルに届いた個人開発者は、更新のお知らせで「この機能は○○さんの提案」と書くようにしてから、利用者の書き込みが増えたと報告している。
- P8 の devlog や P2 の更新にすぐ使える。
- 出典：https://www.indiehackers.com/post/from-0-to-1k-mrr-in-8-months-bootstrapping-habit-pixel-as-a-solo-dev-684b6c056d

## 3. 48時間で試せる案（既存プロジェクトに足すもの）

**① P1 Kotomark の「GitHub Action」を GitHub Marketplace に載せる準備**
- GitHub Action（自動で台本を検査する部品）はもう作ってある。Marketplace は、開発者が道具を探す「場所が客を連れてくる」販路で、掲載は無料。
- 48時間でやること：掲載ページの文面と画像を作る。
- オーナーの作業：公開用のリポジトリと、掲載の同意。

**② 計算機に「安いモデル（OpenRouter 経由）」の比較を足す**
- StepFun Step 5 や DeepSeek などの安いモデルを、価格を確かめた上で比較に加える。
- 「Claude から安いモデルに替えたら月いくらか」を1つのリンクで見せられる。
- 48時間でやること：価格の確認と追加、紹介の投稿を1本。
- オーナーの作業：投稿の承認だけ。
- 担当は Vega（P2）。Midas は文面を用意する。
