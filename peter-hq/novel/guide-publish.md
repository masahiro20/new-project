# note 公開の手順（あなたの作業は、全部で約40分）

## 最初の1回だけ（約30分）
1. note のアカウントを作る（無料）。X のアカウントで入ってもよい。
2. プロフィールを設定する。文面は profile.md をコピペ。
3. 「マガジン」を1つ作る。名前は「その係、事件の第一発見者です」。説明文は profile.md の2つ目をコピペ。
4. （有料化は6話目から。そのときに、銀行口座の登録と本人確認が必要。今はやらない）

## 1話ごとの手順（約5分 × 5話）
note-ready フォルダの中の、該当話のファイルを使う。
1. note で「投稿」→「テキスト」を開く。
2. タイトル欄に、`epXX_タイトル.txt` の中身をコピペ。
3. 本文欄に、`epXX_本文.txt` の中身をコピペ。
4. 見出し画像に、`epXX_表紙.png` をアップロード。
5. ハッシュタグに、次の4つを入れる：#その係事件の第一発見者 #短編小説 #ミステリー #お仕事小説
6. マガジンに追加（上で作ったマガジンを選ぶ）。
7. 公開日時が指定できる場合は、下の日程に合わせる。できない場合は、その日に「公開」を押す。

画面の名前が違ったら、画面のスクリーンショットを送ってください。手順を直します。

## 公開日程の案
| 日 | 公開 |
|---|---|
| 10/27（火） | 第1話・第2話を同時に（最初に2つ読めるようにする） |
| 10/30（金） | 第3話 |
| 11/3（火） | 第4話 |
| 11/6（金） | 第5話 |
| 11/10（火）〜 | 第6話から有料（200円）。それまでに私が第6話を書く |

## X の運用
- x-posts.md に、投稿文を日付つきで並べてある。X の「予約投稿」にまとめて入れるか、毎朝コピペする。
- note へのリンクは、3回に1回だけ。リンク無しの投稿が、表示されやすい。

## 私が確認済み・未確認のこと
- note に公式の投稿 API は見つかりませんでした。自動投稿は、規約違反の恐れがあるため、やりません。
- note の AI 利用に関する規約は、私はまだ公式の本文で確認できていません。投稿前に、note のヘルプで「生成AI」に関する項目を一度見てください。
- 他の小説サイト（カクヨム、小説家になろう）は、AI 利用の申告が必要です。今回は note だけです。
