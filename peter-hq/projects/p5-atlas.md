# P5 Atlas（リーダー: Atlas）

## 一言で
MCP サーバーとエージェントスキルを**自動でセキュリティ検査し、信頼スコア付きで載せる**ディレクトリ。

## なぜ今
- MCP サーバーやスキルは数千件規模に増えたが、悪意あるコードやプロンプトインジェクションの検査は追いついていない。
- 「AIツール一覧」のような汎用ディレクトリは下火。勝てるのは検証付き・業界特化の型。

## 機能案
- GitHub 上の MCP サーバー／スキルを自動収集し、権限・ネットワーク通信・危険なコードを静的解析
- 「〇〇向け MCP サーバー」のような検索ページを自動生成（SEO）
- 掲載者向けの有料「検証済みバッジ」、企業向けの許可リスト API

## ステージ1でやること
- 既存ディレクトリの調査（規模、検査の有無、収益）
- 検査ルールの初版を作り、100件で試す
