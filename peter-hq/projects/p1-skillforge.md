# P1 SkillForge（リーダー: Forge）

## 一言で
専門業務を丸ごと片付ける Claude Code スキル／エージェントを、ファイル売りではなく**ホスティングして月額で提供**する。

## なぜ今
- SKILL.md 形式は Claude Code、Codex CLI、Gemini CLI など20以上のエージェントで動く共通形式になった。
- 売れているスキルでも月 $500〜3,000 程度。汎用スキルは本体の機能と重なって売れない。勝てるのは**深い専門業務**だけ。

## 候補ニッチ（検証で1つに絞る）
1. 日本に進出する海外企業向け：インボイス制度・電子帳簿保存法・日本語契約書チェック
2. ゲーム・アニメのローカライズQA（用語集の一貫性、文字数制限、ルビ）
3. 特許の先行技術調査（日米の公報を横断）

## ステージ1でやること
- 3候補それぞれの需要の証拠を集める（Reddit、X、求人、既存ツールの価格）
- 1つに絞り、LPと待機リストを作る

## 収益モデル
月額 $29〜99 のホスティング提供。法人向けは個別見積もり。
