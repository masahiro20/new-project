# P6 Fleet（リーダー: Otto）

## 一言で
多数の Claude Code エージェントを並列で動かす人のための**管制ダッシュボード**。費用、進捗、承認待ち、ブランチを一画面で見る。

## なぜ今
- ヘビーユーザーは複数セッションを並列で動かすのが当たり前になり、「どれが何をしていて、いくら使ったか」が見えなくなっている。
- このプロジェクト群自体が並列エージェントで動くので、自分たちが最初のユーザーになれる。

## 機能案
- 実行中セッションの一覧、利用量、承認待ちの通知
- git worktree とブランチの整理
- 週次レポート（何が完了し、何に詰まったか）

## ステージ1でやること
- 既存ツールの調査（公式機能との重なりを必ず確認する）
- 公式機能でカバーされない隙間を特定する。隙間がなければ早期に撤退する
