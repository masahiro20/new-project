# P4 Collector Lens（仮称）ステージ2 試作報告

**From: Ren（P4リーダー） / 2026-10-08 / ブランチ `peter/p4-collector-lens`**

## 作ったもの
`collector-lens/` に Listing Decoder の Chrome 拡張（Manifest V3）。ルートの「減算ゼロ」には触れていない。

- 対象：ヤフオク（最優先）→ メルカリ → ラクマ → まんだらけ。カメラ・時計を最優先。
- 開いている出品ページの DOM だけを読み、右下に英語パネル（Condition / Grade / Returns / Warnings / Worth noting / Seller states / Terms）を表示。
- 危険信号：ジャンク、動作未確認、現状品、ノークレームノーリターン、真贋不明・コピー品・N品、リダン・寄せ集め、カビ・くもり・バルサム切れ、幕穴、プリズム腐食など。複合ルール（「未確認＋返品不可」「時計で真贋不明」「説明が極端に短い」）。
- 「カビ・くもりなし」のような否定は警告にせず「Seller states」に回す。
- 用語辞書 `data/glossary.json`：227語（カメラ78・時計80・一般80）。全語を1語ずつ確認し、誤検出しやすい語形（裸の「アクリル」、日差/日差し 等）を修正。
- 権限：`permissions` は空。ホストは4ドメインのみ。外部通信・保存・他ページへのアクセスなし（テストで禁止APIを検査）。
- パネルは閉じた Shadow DOM に追加するだけで、元ページの要素は書き換えない。

## テスト
- `npm test`：34件すべて成功（解析・否定表現・ランク・ルール・4サイトの模擬ページ抽出・XSS防止・権限・禁止API）。
- 実機相当：Chromium に拡張を読み込み、4サイトの URL を自作の模擬 HTML に差し替えて表示を確認（5ページすべてでパネル表示、メルカリの SPA 遷移でパネル消去、外部リクエスト0件）。スクリーンショットは `collector-lens/docs/`。
- 実サイトの HTML はコピー・保存していない。フィクスチャはすべて自作。
