### D. プロンプトの品質（提案）

1. **減算率を書類に入れる**：研修資料に「この事業所が未実施だと何%減算か」を入れると、受講者の当事者意識が高まる。サービス種別から施設・居住系か訪問・通所系かを判定して、プロンプトに渡す
2. **児童向けの分岐**：放課後等デイサービスと児童発達支援では、こども家庭庁の手引き、児童虐待の通告、保護者対応の事例を使う
3. **研修の時期**：新規採用時の研修も推奨されていることを年間計画に入れる
4. **品質テストを用意する**：11のサービス種別 × 会議メモの有無で、出力を固定のチェックリスト（【要記入】の有無、捏造がないこと、5類型・3要件が入っていること）で自動採点する。モデル更新や改定のたびに回帰テストとして使う

## 7. 追加対応（2026-10-08、本部承認済みの5点）

| # | 対応 | 確認したこと |
|---|---|---|
| B1 | **共通のレート制限と Turnstile を追加。** `UPSTASH_REDIS_REST_URL`／`TOKEN` があれば全インスタンス共通で数え、なければ（または Redis に接続できなければ）従来のメモリ上の制限で動く。新しい依存パッケージは追加していない（REST API を直接呼ぶ）。IP アドレスはハッシュにしてから保存する。IP の取得は `x-real-ip` を優先。Turnstile は `NEXT_PUBLIC_TURNSTILE_SITE_KEY`／`TURNSTILE_SECRET_KEY` を設定したときだけ有効になる | Redis に接続できない状態で、メモリ上の制限に切り替わり、4回目が429になること。Cloudflare 公式のテスト用キーで、失敗用は403、成功用は生成まで進むこと。ブラウザでは、確認が済むまでボタンが押せず、確認後にトークンが送られること |
| B2 | **利用規約 `/terms` を新設**（雛形。【要記入】は運営者名・管轄裁判所・制定日）。フッターとサイトマップに追加 | 表示（200） |
| B3 | **プライバシーポリシーを改訂。** 利用目的、外国にある第三者への提供（個人情報保護法第28条：提供先の国、その国の制度、提供先の措置）、委託先、安全管理措置、開示請求の窓口を追加。【要記入】は運営者名、Anthropic のデータ保存期間、ホスティング先、制定日 | 個人情報保護委員会へのリンク先が実在することを確認 |
| B4 | **購入ボタンの直前に最終確認の表示を追加**（商品、内容・数量、価格、支払方法・時期、提供時期、キャンセル・返金、規約への同意）。フォームと、お試し後の購入カードの両方に表示 | ブラウザで表示を確認 |
| B5 | **完成した有料書類を、決済セッションごとにブラウザへ保存。** 再読み込みしたときは保存分を表示し、足りないセットだけを生成する。途中で止まったもの（エラー・拒否・文字数上限）は保存せず、「この書類を作り直す」ボタンを表示する | 3セットとも保存済みなら生成は0回。2セット保存済みなら、残りの1セットだけを生成。失敗したセットは保存されず、作り直しで再度呼ばれること |
