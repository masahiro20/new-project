# INTEL デスク（リーダー: Iris）

## 役割
世界の最先端情報を毎日集め、本部と各プロジェクトに配る。

## 毎晩の報告（21:57 日本時間）の形式
1. 今日の最先端ニュース（3〜5件、出典リンク付き）
2. 各プロジェクトに関係する動き
3. P2 Signal Lab 向け「48時間で作れそうな話題」3件
4. 各プロジェクトの進捗とオーナーへの確認事項

## 情報源
X（levelsio、marc_louvion、gregisenberg、bcherny など）、Hacker News、Product Hunt、Indie Hackers、Anthropic / OpenAI / Google の公式発表、Reddit の各ニッチ板。
X は直接検索できないことがあるため、記事・ブログ経由の場合はその旨を明記する。
