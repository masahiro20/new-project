### 記事4
**タイトル**：個別支援計画の書き方、まず「6つの手順」がそろっているかを確かめる（放課後等デイサービス・児童発達支援）
**ねらう語**：個別支援計画 書き方 例文 放課後等デイサービス
**本文**：

個別支援計画は、書き方を工夫する前に**作り方の手順がそろっているか**が大切です。放課後等デイサービス・児童発達支援の計画は、基準省令第27条で手順が決まっていて、その一部でも欠けると**個別支援計画未作成減算**の対象になります。この記事では、手順と書く項目、よくあるつまずきを短くまとめます。

（法令上の名称は「放課後等デイサービス計画」「児童発達支援計画」ですが、ここでは現場で一般的な「個別支援計画」と呼びます。）

**作るのは児童発達支援管理責任者、手順は6段階**

1. **アセスメント**：保護者とこどもに面接し、生活の状況や希望、課題を把握する
2. **原案の作成**：意向、支援の方針、目標と達成時期、支援の内容などを書く
3. **担当者等の会議**：支援に当たる担当者を集めて、原案への意見を求める（テレビ電話装置等でも可）
4. **説明と文書による同意**：保護者とこどもに説明し、文書で同意を得る
5. **交付**：計画を**保護者と障害児相談支援事業者**に渡す
6. **モニタリングと見直し**：**少なくとも6か月に1回以上**見直す

計画を変えるときも、アセスメントから交付までを同じように踏みます。それぞれの段階で、面接日、会議の出席者と意見、同意の署名と日付、交付日と交付先を記録に残しておきましょう。

**計画に書く項目と「5領域」**

こども家庭庁のガイドラインは、**本人支援・家族支援・移行支援を必ず書く**よう求めています。本人支援には、「健康・生活」「運動・感覚」「認知・行動」「言語・コミュニケーション」「人間関係・社会性」の**5領域との関連**を書きます。

迷いやすい点は3つです。

- **5つの欄を作って別々の目標を立てる必要はありません。** 1つの支援が複数の領域にまたがるなら、関連する領域をすべて書けば足ります。ただし、計画全体で5つの領域すべてが関連付けられていることが必要です。
- **5領域を書くのは本人支援だけ**です。家族支援・移行支援・地域支援には書かなくてよいとされています。
- **目標の達成時期は最長6か月後まで**。6か月に1回以上見直すためです。

例として、架空の小学3年生「Aさん」の本人支援を1つだけ挙げます。

- （例）支援目標：その日の予定をカードで確認し、変更があったときは自分でカードを並べ替えられる。関連する5領域：認知・行動、言語・コミュニケーション。達成時期：3か月後

ガイドラインは、支援目標や内容が**こどもごとに同じになることや、長期間同じ記載が続くことは想定されない**とも書いています。前回の計画を写して日付だけ変えた計画は注意が必要です。

**支援時間は「2時間30分」のように書く**

令和6年度から、基本報酬は計画に定めた支援時間の区分で決まります。計画には「区分2」ではなく**「2時間30分」のような具体的な時間**を書き（Q&A問5）、**送迎の時間は含めません**（Q&A問2）。計画に時間が定められていない日は、30分以上1時間30分以下の区分で算定することになります（Q&A問4）。

**個別支援計画未作成減算**

計画が作られていない、または作成の手順が適切に行われていない場合、そのこどもについて**所定単位数の70%**で算定し、連続して3か月以上続くと**50%**になります。期間は、該当する月から、その状態が解消された月の**前月まで**です。

「同意の署名が支援開始より後の日付」「6か月を過ぎても見直していない」といった不備も対象になりうるので注意が必要です。具体的にどの不備が減算に当たるか、過去の月の扱いをどうするかは、指定権者に確認してください。

### 記事5
**タイトル**：放デイ・児発の「安全計画」と送迎の置き去り防止、運営指導の前に確かめたい書類
**ねらう語**：安全計画 放課後等デイサービス ひな形／送迎 置き去り防止 安全装置 放課後等デイサービス
**本文**：

安全計画は、BCP（業務継続計画）や非常災害対策計画とは**別の計画**です。放課後等デイサービス・児童発達支援では、令和6年4月1日から義務になっています。減算の仕組みはありませんが、運営基準の違反として運営指導で指摘される項目です。千葉市が公表した令和7年度の運営指導結果でも、「安全計画が策定されていない」「送迎車両に安全装置が設置されていない」事業所があったと報告されています。

この記事では、安全計画と送迎の置き去り防止について、何を書類で示せばよいかを整理します。

**安全計画で求められていること（基準省令第40条の2）**

- 事業所ごとに安全計画を作り、計画に従って必要な措置を講じる
- 職員に周知し、研修と訓練を定期的に行う
- 保護者に、安全計画に基づく取組の内容を周知する
- 定期的に見直し、必要に応じて変更する

こども家庭庁の通知は、計画の中身として、安全点検、マニュアルの策定・共有、こどもへの安全指導、保護者への説明、職員の研修・訓練、再発防止策などを挙げ、**各年度が始まる前に**定めることを求めています。設備等の安全点検は**少なくとも毎学期1回（年3回）以上**行うことが重要とされ、一人ではなく**複数名で**行うことが望ましいとされています。

職員への周知は、計画を配るだけでは足りません。読み合わせやロールプレイングなど、体得できる方法が求められています。非常勤の職員や送迎の運転手も含め、誰がいつ確認したかを記録しておきましょう。

**送迎の置き去り防止（第40条の3）**

1. **すべての車で、乗車と降車のたびに点呼などで所在を確認する。** 外出活動の移動も対象です。
2. **送迎を目的とした車を日常的に運行するなら、ブザー等の安全装置を備え、降車時の確認に使う。**

装置がいらないのは、いわゆる**2列以下の車**などです。ただし、**車椅子のまま乗るスペースも「座席」に数える**ため、福祉車両は列の数え方に注意が必要です。後部座席が横向きの車は、2列でも除外に当たらない可能性があります。迷う車は**指定権者に事前に確認**し、確認した日と回答を記録しておきましょう。2列以下の車でも、点呼などによる所在確認は必要です。

装置を備えなくてよい経過措置は令和6年3月31日で終わり、国の導入補助も令和5年度で終了しています。

**装置があっても、人の確認は省けない**

令和8年9月2日のこども家庭庁などの事務連絡は、安全装置の不適切な運用による置き去り事故が起きているとして、不適切な運用の事例に次のものを挙げています。

- 確認ボタンを、車両後方ではなく運転手の手元に設置していた
- 車内を確認しないまま後方に移動してボタンを押した
- 非常時用のリモコンで、車内を確認せずに警報を解除した

降車後は、運転手が先頭から最後尾まで一列ずつ、座席の下や物かげまで見てから確認ボタンを押します。担当職員が乗車名簿とその日の出欠を照合し、食い違いがあればすぐ管理者に報告します。

**送迎記録に残したいこと**

送迎記録の様式は国から示されていません。運営指導で「毎回、乗車時と降車時に所在を確認し、降車時に装置を使った」ことを示せるよう、乗車名簿、乗車・降車の確認（時刻と確認者）、車内確認と装置の操作、照合の結果、装置の点検整備をそろえておくとよいでしょう。

- （例）15:27 運転手Aが先頭から最後尾まで確認（座席下・3列目の陰を含む）、後方の確認ボタンを操作

安全計画の年間スケジュールの例（安全点検・マニュアル・訓練・研修）は、こちらにまとめています。
https://masahiro20.github.io/new-project/guide/anzen-keikaku-jidou/

対象になる車・ならない車の目安、安全装置の要件、送迎記録の記入例はこちらです。

### 記事6
**タイトル**：年度の後半に確かめたい「まだやっていない研修」、障害福祉の年間研修計画の見直し方
**ねらう語**：障害福祉 年間研修計画 例
**本文**：

10月を過ぎると、年度の残りは半分です。「虐待防止の研修、今年度はもうやったかな」「感染症の研修は2回目が必要だったはず」。年度末に慌てないために、今のうちに年間研修計画を見直しておきましょう。

年間研修計画そのものを「作らなければならない」と定めた条文はありません。ただし運営基準は研修の機会を確保することを求め、解釈通知はそれを「計画的に確保する」ことと説明しています。そして、回数が決まっている研修のうち、**虐待防止研修と身体拘束等の適正化の研修は、実施していないと減算の対象**になります。

**まず押さえる研修・訓練の回数**

| 研修・訓練 | 回数（解釈通知） | 実施しないと |
|---|---|---|
| 虐待防止の研修 | 年1回以上＋新規採用時 | 虐待防止措置未実施減算 |
| 身体拘束等の適正化の研修 | 年1回以上＋新規採用時 | 身体拘束廃止未実施減算（対象外のサービスあり） |
| 感染症の研修・訓練 | サービスにより年1回以上または年2回以上 | 対応する減算はない（運営基準上の義務） |
| BCPの研修・訓練 | 年1回以上（障害者支援施設は年2回以上） | 未策定減算の算定要件ではない（運営基準上の義務） |

感染症の研修・訓練は、居宅介護などの訪問系と就労定着支援・自立生活援助は年1回以上、生活介護・就労移行支援・就労継続支援・共同生活援助、放課後等デイサービス・児童発達支援などは**年2回以上**です（障害者支援施設などは、それぞれの基準と解釈通知で確認してください）。放デイ・児発は、これに加えて**安全計画**に基づく研修・訓練も定期的に行う必要があります。

**年度後半のチェック（例）**

今年度の研修記録を並べて、次の点を確かめます。

- 虐待防止研修を今年度1回以上やったか。記録に日付・参加者・内容があるか
- 身体拘束等の適正化を扱ったか（身体拘束廃止未実施減算の対象のサービス。虐待防止研修の中で扱った場合は、記録にそう書いてあるか）
- 感染症の研修・訓練は、必要な回数（年2回のサービスなら2回目）の予定が入っているか
- BCPの研修・訓練を年1回以上（障害者支援施設は年2回以上）やったか、予定があるか
- 年度の途中で採用した職員に、採用時の虐待防止・身体拘束等の適正化の研修をしたか（解釈通知は「必ず実施することが重要」としている）

**回数を無理なく満たす組み合わせ**

解釈通知は、次の組み合わせを認めています。残りの月が少ないときほど役に立ちます。

- **虐待防止研修の中で身体拘束等の適正化を扱う** → 身体拘束等の適正化の研修を実施したものとみなして差し支えない
- **BCP（感染症）の研修・訓練を、感染症の研修・訓練と一体で行う**
- **協議会や基幹相談支援センター等が実施する虐待防止の研修に参加する**
- **BCPの研修・訓練を、他の事業所と連携して行う**

身体拘束等の適正化を虐待防止研修の中で扱う場合は、研修記録に「身体拘束等の適正化を含む」ことと、扱った内容（3要件、記録の方法、事業所の指針など）を書いておきます。記録から分からないと、身体拘束等の適正化の研修をしていないと見られるおそれがあります。

一方、BCP（自然災害）の訓練と、非常災害の避難・救出訓練を一体で行ってよいと明記した規定は、解説ページの調査では確認できませんでした。同じ日に続けて行うことはできますが、それぞれの訓練として数える場合は記録を分けておくと安心です。扱いに迷う場合は指定権者に確認してください。

**研修記録に残す項目**

研修名、日時・方法、講師、参加者（常勤・非常勤を問わず全員）、欠席者へのフォローの日付、内容と使った資料、理解度の確認、記録者と管理者の確認。様式は決まっていないので、これらの項目（例）をそろえておくとよいでしょう。様式を指定権者が示している場合は、そちらに合わせてください。

### 記事8
**タイトル**：定員超過利用減算は「1日150%」と「3か月125%」の2つの判定、放課後等デイサービス・児童発達支援の計算例
**ねらう語**：定員超過利用減算 放課後等デイサービス
**本文**：

「今日はお休みの子が少なくて、たまたま定員を超えて受け入れた」。定員超過利用減算は、そのような**1日だけ**の場合と、**3か月を通して**受け入れが多い場合で、判定が分かれます。留意事項通知（令和8年5月28日改正後）に沿って、確認できたことだけをまとめます。

**減算の内容**

利用定員を上回る障害児を受け入れたとき、障害児**全員**について、所定単位数の**100分の70**で算定します。元になる所定単位数は、各種加算がなされる**前**の単位数で、加算を含めた合計の70%ではありません。複数のサービス提供単位がある場合は、サービス提供単位ごとに見ます。

**範囲内なら、定員超過はできる**

通知は、次の範囲の定員超過利用は、適正なサービスの提供が確保されることを前提に可能とし、これを**超える**過剰な定員超過利用について減算するとしています。

**判定1：1日あたり**

- 利用定員**50人以下**：1日の障害児の数が、利用定員の**150%**を超えた**その日**
- 51人以上：利用定員に、（利用定員−50）×25%＋25を加えた数を超えた日

例（架空）：利用定員10人なら、10×150%＝15人。**16人以上**になった日が減算の対象です。

**判定2：過去3か月間**

直近3か月の障害児の延べ数が、**利用定員×開所日数×3か月×125%**を超えたら、その1月間が減算になります。

通知の例：利用定員30人、1月の開所日数が22日なら、30×22×3＝1,980人。1,980×1.25＝**2,475人**を超えると減算です。

**利用定員が11人以下のとき**

過去3か月の延べ数が、**（利用定員＋3）×開所日数**（3か月分）を超えた場合に減算します。例（架空）：定員10人、開所日数22日なら、（10＋3）×22×3＝858人です。

**人員欠如と重なったら**

定員超過利用と人員欠如の双方に当たる場合は、減算となる単位数が**大きいほうだけ**が減算されます。通知の例では、定員超過が100分の70、人員欠如が100分の50なら、100分の50で算定します。

**指導と指定への影響**

通知は、減算の対象となる定員超過利用が続く事業所に、都道府県知事等が解消を指導し、従わなければ、特別な事情がない限り指定の取消しを検討するとしています。

**準備で確認すること**

- 利用定員を、サービス提供単位ごとに把握しているか
- 1日の利用人数を、日ごとに記録しているか
- 過去3か月の延べ人数と、125%の基準を、毎月確認しているか
- 定員11人以下の事業所は、「利用定員＋3」の基準を使っているか

**突発の相談は対象外**

通知は、突発的に生じる相談援助（例：家族等からの電話への対応）は対象にならないとしています。「電話を受けたから請求する」はできません。

**（Ⅰ）個別の相談援助**

居宅への訪問、事業所での対面、テレビ電話装置等の活用のいずれかで行います。事業所以外の場で対面で行った場合は、事業所での対面として算定します。障害児が同席していなくても算定できます。テレビ電話は、原則、表情などの様子が分かる状況で行い、通信環境などでやむを得ない場合は電話等でも差し支えないとされています。事前に、家族の通信料の負担が著しくならないか確認します。

**（Ⅱ）グループの相談援助**

事業所での対面、またはテレビ電話装置等で、**2人から8人まで**を1組として行います（同一世帯の複数人は1として数える）。ペアレントトレーニングや、保護者同士のピアの取組が想定されています。

家族が支援場面を観察・参加する機会を提供し、相談援助を行う子育てサポート加算は、月4回に限り算定します。家族支援加算と同じ日に算定できますが、子育てサポート加算の時間帯に行う相談援助には、家族支援加算は算定できません。
