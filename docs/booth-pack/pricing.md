# 価格案：¥1,980

## 結論

**¥1,980（税込表示）** を提案します。AI 版（有料・近日公開、既定 ¥2,980）より低く、「書類をまとめて印刷できる記入例つきの一式」として、迷わず買える価格帯にそろえる案です。

## 理由

1. **AI 版より安く、役割が違う**：AI 版（既定 ¥2,980、1事業所・年間セット）は、事業所の実情に合わせて AI が文章を書き分けるもの。このパックは、定型の雛形に記入例を足したもので、事業所に合わせた文章は自分で書く。役割が違うので、価格を AI 版より低くして、併売しても食い合わないようにする。
2. **無料版との差が、時間の節約として説明できる**：13種別ぶんの記入例、まとめて印刷できる PDF、編集用 Word、チェックリスト追加編がそろう。無料版で同じものを自分で用意するには、種別ごとに入力・保存し、記入例を探す手間がかかる（手間の大きさは、まだ測っていない仮定です）。
3. **初回の購入のハードルを下げる**：BOOTH の商品としては、¥2,000 を下回る価格のほうが、衝動買いに近い気軽さで試してもらいやすい、という仮説。まず買ってもらい、感想と需要を集めて、次の商品（更新版・AI 版・年間セットなど）につなげる。
4. **事業所の予算で考えやすい**：1事業所1回の購入で、研修・委員会の書類の準備に使える。複数事業所の運営法人向けの扱いは、ご利用条件で決める（`product-description.md` の【要判断】）。
