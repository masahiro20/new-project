# オーナー向け：BOOTH 商品ページの差し替え手順

BOOTH の画面の名前や並びは変わることがあります。以下は一般的な順番です。**画面が違う場合は、近い項目で読み替えてください**（BOOTH の画像の推奨サイズ・タグの上限数は、公式の案内で確認できていません。出品画面の表示に従ってください）。

## 用意するもの（すべてこのリポジトリの `docs/booth-pack/` にあります）

| ファイル | 使う場所 |
|---|---|
| `product-description.md` | 商品名・説明文・特商法の表記・タグ |
| `images/v2_01_サムネイル.png`（1200×1200） | 商品画像の1枚目（一覧に出るサムネイル） |
| `images/v2_02〜v2_05_*.png`（1200×1200） | 商品画像の2〜5枚目 |
| `減算ゼロ_書類パック_2026年10月版.zip` | 商品ファイル（変更なし） |

古い画像（`01_表紙.png` など4枚）は、使いません。

## 手順（新規に出品する場合）

1. BOOTH にログインし、ショップ管理（商品の管理）から「新しい商品を登録」を選ぶ。
2. **商品画像**：`v2_01` → `v2_02` → `v2_03` → `v2_04` → `v2_05` の順に追加する。1枚目がサムネイルになるので、順番を間違えない。
3. **商品名**：`product-description.md` の「商品名」の行を貼る。
4. **商品説明**：「キャッチコピー」から「お問い合わせ」までを貼る（見出し記号の `#` などは、BOOTH の書式に合わせて整える）。
5. **カテゴリ**：近いものを選ぶ（例：デジタル商品・データ系）。**ダウンロード商品**にする。
6. **価格**：1,980円。
7. **商品ファイル**：zip を1つ、アップロードする。
8. **タグ**：`product-description.md` の「検索用タグ」を、上から順に入れる（上限があれば、先頭から残す）。
9. **特定商取引法に基づく表記**：ショップの設定に、`product-description.md` の「特定商取引法に基づく表記」の表を入力する。販売者名は「ヒルフェクリエイト」、所在地・電話番号・運営責任者は「請求があれば遅滞なく開示します」。
10. 「プレビュー」で確認する（下の確認欄）。問題がなければ公開する。

## すでに出品している場合（差し替え）

- 商品の編集画面で、手順2〜4・8だけを差し替える。価格・zip・特商法は変えない。
- 画像は、古い4枚を削除してから、新しい5枚を `v2_01` から順に追加する（順番を入れ替える機能があれば、それで並べ替える）。

## 公開後に、BOOTH の URL を公開サイトへ入れる（本部作業）

- 商品ページの URL を本部（ピーター）に伝える。本部が `lib/booth.ts` の `{{BOOTH_URL}}` を置き換える（解説記事の案内カードが表示される）。note の下書きの `{{BOOTH_URL}}` も、投稿前に同じ URL に置き換える。

## 公開前の確認（チェック）

- [ ] 1枚目の画像（サムネイル）が、一覧で読める大きさか。文字が切れていないか。
- [ ] 価格が1,980円（税込）になっている。
- [ ] 「1つの購入につき1事業所」が、説明文に書かれている。
- [ ] 販売者名が「ヒルフェクリエイト」。特商法の所在地・電話番号が「請求があれば遅滞なく開示します」になっている。
- [ ] 返品・返金：お客様都合は不可、と書かれている。
- [ ] zip をダウンロードして、日本語のファイル名が文字化けしないか（Windows で展開して確認）。
- [ ] 商品名・説明文に、「減算を回避できる」「必ず通る」のような、保証に読める言い方がない。

## 判断が必要なこと

- 商品名を検索語重視に変えた点（`improvement-proposals.md` の B）。以前の名前に戻したければ、`improvement-proposals.md` ではなく Git の履歴（`product-description.md` の前のバージョン）から戻せる。
- 「AI の支援を使用」の文は、位置を変えていない（C7 は本部の判断待ち）。
