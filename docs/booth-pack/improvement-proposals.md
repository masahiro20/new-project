# BOOTH 商品ページ 改善提案（2026年10月17日・提案のみ）

**このメモは提案です。商品説明文・画像・zip・価格には、まだ何も反映していません。** 採用する項目を本部（ピーター）とオーナーが決めたら、反映します。BOOTH の URL が届いて出品する前に決めるのが、手間が最も少ないです。

見直した対象：`product-description.md`、`images/` の4枚（01_表紙・02_記入例・03_チェックリスト・04_使い方）、`pricing.md`。

## A. 画像（優先度が高い）

現状の4枚は、パックの PDF のページを、そのまま画像にしたものです（911×1288の縦長）。BOOTH の一覧では、サムネイルは正方形に切り取られて小さく出るため、次の問題があります（BOOTH の画像の推奨サイズ・切り取りの仕様は、出品画面で確認してください）。

| # | 問題 | 提案 |
|---|---|---|
| A1 | 表紙画像の上3分の1が空白で、タイトルが中央に小さく出る。一覧の小さい画面だと、何の商品か読めない | **サムネイル用に、正方形（例：1200×1200）の画像を新しく作る**。大きい文字で「運営指導の前に。虐待防止・身体拘束適正化の書類、13種別・記入例つき」、価格（¥1,980）、「印刷してすぐ使える」を入れる |
| A2 | 画像が「PDFを撮っただけ」で、買って得られるものが一目で分からない | 2枚目に「何が入っているか」の図（フォルダ構成：00 はじめに／01 チェックリスト／02 13種別）を入れる |
| A3 | 無料版との違いが画像にない（説明文の表にしかない） | 「無料版 → このパック」の比較（記入例13種別、まとめて印刷、Word付き、チェックリスト追加編）を1枚の画像に |

| A5 | 04_使い方の内容が、説明文と重なる | 使い方は説明文に任せ、画像は「買う前の不安」に答える内容（架空の例・法的助言ではない・制度の確認先）に変える案もある |

## B. 商品名・キャッチコピー

- 現在の商品名「減算ゼロ 虐待防止・身体拘束適正化 書類パック（13種別・記入例つき）2026年10月版」は、**BOOTH の検索で使われる言葉**（運営指導、書類、放課後等デイサービス、障害福祉）が、先頭に近くない。
- 提案（案）：「【運営指導対策】虐待防止・身体拘束適正化 書類パック｜放デイ・児発ほか13種別 記入例つき」。「運営指導」を先頭に出し、買い手の悩みから入る。ただし、「対策」という言葉が、減算の回避を保証するように読まれないよう、説明文の注意書き（現行どおり）を残す。
- 「2026年10月版」は、古く見えるのを避けるため、商品名ではなく説明文に移す案もある。ただし、制度改定後の最新版であることは、買い手にとって安心材料になる。**判断はオーナー**。

## C. 商品説明文

1. **最初の3行で、買い手の悩みと得られるものを言い切る**。現在は、2文目から「AI が文章を作る商品ではなく…」など、買う前の注意が先に来ている。注意は、後半の「ご購入前にご確認ください」に集まっているので、冒頭は「悩み → 中身 → すぐ使える」にする。
2. **「放課後等デイサービス・児童発達支援」を、冒頭で明示**する。チェックリストの本編が、この2種別向けのため。ほかの種別の買い手が期待外れにならないよう、説明はすでにあるが、冒頭の1行にも入れる。
3. **ページ数・ファイル数を、数字で書く**（例：種別ごとのPDFは30〜50ページ、13種別、全30ファイル）。数字は作り直しのたびに確認する。
4. **「1事業所1購入」の意味を、冒頭近くにも**。複数事業所を持つ法人が、買ってから気づく不満を減らせる。（現在は「ご利用条件」にあるのみ）
5. **サンプルの無料公開への導線**を入れる：「無料版（記入例の見本つき）を、先に見られます」と、公開サイトの /samples へのリンクを入れる。BOOTH 側でリンクを許すかは、BOOTH の規約で確認する。
6. **購入後の次の一手**を書く：「購入後、00_はじめに.pdf を開く」。
7. 「AI の支援を使い…運営事務局が内容を確認」の文は、冒頭の近くにあると、読み手によっては不安になる。事実なので消さず、位置を「ご購入前にご確認ください」の欄に移す案。**判断は本部**。

## D. 商品のラインナップと価格

- **¥1,980 のまま**でよいか：`pricing.md` の仮説（需要は未検証）のとおり。出品後に閲覧と購入を数えてから判断する。
- 「1事業所1購入」のため、**複数事業所の法人向けの別商品**（例：3事業所まで／全事業所）を作ると、単価を上げられる。需要が出てから。
- **種別ごとの単品**（放デイ・児発だけ、など）は、買い手の「自分に要らない種別まで入っている」不安を減らせる。一方、13種別のまとめ買いの魅力が薄れ、出品の管理も増える。まず、まとめ1本で試す案。
- 無料の**お試し版**（BOOTH の無料商品：記入例の見本1種別とチェックリスト本編だけ）を出し、有料版に案内する案。BOOTH の中で見つけてもらえ、お気に入り登録が増える可能性がある。**効果は未検証の仮説**。
