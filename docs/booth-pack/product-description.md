## 商品説明

障害福祉サービス事業所の「虐待防止委員会」「虐待防止研修」「身体拘束等の適正化」の書類を、**13のサービス種別ごとに、記入例つきで**まとめました。ダウンロードして、そのまま印刷でも、Word で編集でもお使いいただけます。AI は使っていません。公開サイト「減算ゼロ」の無料テンプレートと解説を元に、記入例・まとめて印刷できる形・運営指導チェックリストの追加編を加えたものです。

### こんな方に
- 運営指導の前に、虐待防止・身体拘束等の適正化の書類がそろっているか不安な管理者・児童発達支援管理責任者・サービス管理責任者
- 書類の「書き方」が分からず、記入例を見ながら作りたい方
- 無料のテンプレートを、サービス種別ごとに作り直す手間を省きたい方

### 無料版との違い
| | 無料（公開サイト） | このパック |
|---|---|---|
| 記入例 | 放課後等デイサービスの見本のみ | **13種別すべて**に記入例つき |
| 印刷 | サイトで入力して、1種別ずつ Word 保存 | **まとめて印刷できる PDF**＋編集用 Word を最初から用意 |
| チェックリスト | 放課後等デイサービス・児童発達支援向けの本編 | 本編に、**人員・個別支援会議・加算の記録の追加編**を足した記入式 |
| すぐ使える | 入力と保存の手間がある | ダウンロードしてすぐ開ける。ネット環境も不要 |

### 内容（zip 1ファイル・約15MB）
- **00 はじめに（使い方1枚）**：使い方、注意点
- **01 運営指導チェックリスト**（PDF／Word）：本編6章（虐待防止・身体拘束等・業務継続計画・公表と報告・個別支援計画と記録・運営規程と安全）＋追加編（人員と勤務形態一覧表、個別支援会議と加算の記録）。放課後等デイサービス・児童発達支援向け
- **02 書類まとめ（サービス種別ごと PDF）**：**A 記入例（架空の事業所）**＋**B 記入用の白紙様式**
  - 虐待防止委員会セット：年間実施計画表、議事次第、議事録様式
  - 虐待防止研修セット：研修資料（スライド原稿10枚）、理解度テスト（解答つき）、研修実施記録
  - 身体拘束等適正化セット：指針、委員会確認チェックリスト、記録様式、ご説明書（身体拘束廃止未実施減算の対象のサービスのみ）
- **03 Word（記入用）**：白紙様式の Word 版。【要記入】を埋めて使えます

### 対応サービス種別（13）
放課後等デイサービス／児童発達支援／就労継続支援B型／就労継続支援A型／就労移行支援／生活介護／共同生活援助（グループホーム）／居宅介護・重度訪問介護／短期入所／相談支援／自立生活援助／就労定着支援／その他の障害福祉サービス

相談支援・自立生活援助・就労定着支援は、身体拘束廃止未実施減算の対象外のため、身体拘束等適正化セットは含みません。
