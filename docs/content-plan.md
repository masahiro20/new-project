# 解説ページの追加計画（月10本、検索の多い順）

本部バックログ P0-③。**検索の多さは推定**（Search Console がまだ使えないため）。「書き方」「ひな形」「例文」を含む書類作成系の語は検索が多い傾向があり、減算に関わる書類と隣り合う語を優先した。Search Console の表示回数が取れるようになったら（公開から2〜4週間後）、この順位を実測で並べ替える。

制度の記述は既存の解説と同じ確認手順（一次資料で確認、制度チェック担当の照合）を通してから公開する。返還・不適切な支援の事例・通報（集客計画 #14・34・43・44）は、専門家の確認まで書かない（決定記録）。
