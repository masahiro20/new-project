# プロジェクト計画：減算ゼロ

## 結論

**障害福祉事業所向けの「減算対策書類AI」を、営業なしのWeb完結型サービスとして販売する。**
1事業所・年間セット2,980円。**月11件で売上3万円**に届く。

## 条件との照合

| 条件 | このプロジェクト |
|---|---|
| ブルーオーシャン | 記録ソフトや研修動画はあるが、「虐待防止・身体拘束の年間書類を事業所に合わせて一括生成し、単発で安く買える」Webサービスはほとんど見当たらない |
| 人の手がかからない | 入力 → 決済 → AI生成 → Word保存まで自動。在庫なし、サーバーにデータ保存なし、サポートはFAQで吸収 |
| 月3万円以上 | 2,980円 × 11件。対象は全国の障害福祉事業所（数万規模）で、すべてが毎年この書類を必要とする |
| 営業もAI・Web完結 | 検索とAI検索（ChatGPT・Perplexity・GoogleのAI回答）からの流入、無料診断、無料お試しで購入まで誘導 |
| 最新の手法 | 下記 |

## 採用している新しい手法

1. **AI検索最適化（LLMO）を集客の主軸にする**：`llms.txt`、構造化データ（FAQ・Article）、冒頭に結論を書く解説ページ。AIが回答で引用しやすい形にしている
2. **最新のAIエージェント型生成**：Claude の最新モデルでストリーミング生成し、3セットを並列で作成。拒否された場合は自動で別モデルに切り替える
3. **無料AI体験から購入へ**：年間計画を無料で生成し、価値を体験させてから課金する
4. **データを持たない設計**：入力はブラウザ内だけに保存し、決済と入力内容をハッシュで紐づける。個人情報管理のコストとリスクがゼロ

## リスクと対策

- **記録の捏造に使われるリスク**：議事録は実際の会議メモの清書のみ。メモがなければ様式を出力。画面と規約で明示済み
- **制度改正**：解説ページと指示文（`lib/prompts.ts`）を改定のたびに更新する。令和9年度改定（2027年4月）は需要の山でもある
- **生成品質**：公開前に各サービス種別で試し、指示文を調整する
- **士業の業務範囲**：本サービスは事業所が自ら使う作成ツールであり、官公署への提出書類の作成代行は行わない
