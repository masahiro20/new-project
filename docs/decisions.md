| 2026-10-09 | アクセス計測は GoatCounter（Cookie なし）。コードを入れたあと、オーナーがアカウントを作るまでは無効のままにする | 無料・Cookie なし・独自イベントあり。Cloudflare Web Analytics には独自イベントがない（docs/analytics.md） | 月間PVが GoatCounter の「合理的な利用」を超えたとき |
| 2026-10-09 | Search Console の所有確認は「URL プレフィックス＋HTML タグ」（`NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`） | GitHub Pages のプロジェクトサイトでは DNS を使えず、ファイルを増やさずに済む（docs/search-console.md） | 独自ドメインに移したとき |
| 2026-10-09 | 診断（/check）は最初にサービス種別を選ぶ形式にした。相談支援・自立生活援助・就労定着支援には身体拘束の項目を出さない | QA（Ren）の「中」の指摘。対象外のサービスに減算の「おそれ」を出すのは誤り | 令和9年度改定で対象が変わったとき |
