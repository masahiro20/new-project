# アフィリエイト運用計画（毎日のセッション用）

## 目標と方針

- 目標：アフィリエイト報酬 月100万円。確約できる数字ではなく、下の指標で進み具合を毎月判断する
- 方針：営業はしない。障害福祉事業所の経営者・管理者が検索する「選び方・比較・費用」の記事を増やし、検索とAI検索から集客して、提携した広告へ送客する
- 収益化の順番（2026-11-14に決定、運用は任されている）：①自社商品（減算ゼロ 2,980円）で最初の売上を出す → ②購入者の反応を見て月額型の商品を作る → ③アフィリエイトは記事が育ってからの副収入
- そのため、記事は「減算・書類・研修」など自社商品につながるものを優先し、広告カテゴリの記事と交互に追加する

## 収益の計算

月100万円 ＝ 報酬単価 × 成約数。単価1〜3万円の案件なら月35〜100件。
記事から広告へのクリック率と成約率は実測する。単価はASPの管理画面で確認した数字だけを使う。

## 仕組み（実装済み）

| 部分 | 場所 |
|---|---|
| 広告の登録 | `lib/offers.ts` の `OFFERS`。登録するまで記事に広告枠もPR表記も出ない |
| 記事と広告の対応 | `lib/guides.ts` の各記事の `offers`（カテゴリを指定） |
| クリック計測 | `/go/<id>` 経由で遷移。サーバーログの `affiliate_click` を数える |
| PR表記 | 広告がある記事の冒頭と広告枠に自動で表示（ステマ規制への対応） |

## 人が行う作業（最初に1回）

1. 済：サイトを公開（https://gensan-zero.vercel.app 、Vercelプロジェクト `gensan-zero`）。本番ブランチの設定は `claude/ai-monetization-strategies-jfd4mo` のままなので、作業ブランチの変更を本番に出すときはセッションでそのブランチを本番デプロイする。書類作成の有料機能は `ANTHROPIC_API_KEY` と `STRIPE_SECRET_KEY` を設定するまで動かない
2. 一部済：事業者名・責任者・メールは記入済み。所在地は「請求があれば開示」で仮置き中。局長から地番までの住所を受け取ったら `app/legal/page.tsx` を差し替える
3. ASPに登録する（A8.net、アクセストレード、バリューコマース、レントラックスなど。無料）
4. 下の4カテゴリで案件を探して提携申請し、承認された案件の「案件名・報酬単価・成果条件・広告リンク」をセッションに貼る
5. Google Search Console にサイトマップを登録する

## 毎日のセッションで行うこと

1. 記事を1本追加する（下の候補から。事実は公的資料で確認し、出典URLは実在を確かめる）
2. 承認された広告があれば `lib/offers.ts` に登録する。説明文は広告主の公式ページで確認した事実だけを書く
3. 週1回：Search Console の検索語とクリックログを貼ってもらい、伸びている記事の加筆と内部リンクを行う
4. 月1回：指標を確認し、成約が出ているカテゴリに記事を集中させる

## 広告カテゴリと記事の候補

| カテゴリ | 公開済み | 次に書く記事 |
|---|---|---|
| 請求・記録ソフト（`billing-software`） | 請求ソフトの選び方、返戻の原因と対策、乗り換えの手順 | サービス種別ごとの選び方（放デイ、就労B型、グループホーム） |
| 採用（`recruiting`） | 採用方法の比較、サビ管・児発管の採用 | 求人票の書き方、処遇改善加算と給与の見せ方、離職を減らす方法 |
| 資金調達（`factoring`） | 資金繰りと入金サイクル | 開業資金の目安、創業融資の準備、返戻時の資金繰り |
| 開業・運営支援（`startup`） | なし | 指定申請の流れ、法人設立、会計ソフトと税理士の選び方、法人カード |

自社商品につながる記事：公開済みは虐待防止減算、身体拘束減算、運営指導の準備、BCP未策定減算、情報公表未報告減算、虐待防止研修の進め方、サービス管理責任者欠如減算、個別支援計画未作成減算、虐待防止委員会の開き方。次に書くのは、サービス種別ごとの研修・指針（放デイ、グループホーム、就労B型）、身体拘束適正化の指針の書き方。

令和9年度報酬改定（2027年4月施行）の前後は検索が増える。改定内容が確定したら、既存の記事を先に更新する。

## 記事を書くときの決まり

- 冒頭の `summary` に結論を書く（AI検索に引用されやすい形）
- 製品の料金・機能・順位は、確認していないものを書かない。ランキング形式は根拠を示せる場合だけにする
- 金融・法律に関わる内容は一般的な情報にとどめ、専門家への確認を促す
- 記事を追加したら `npm run typecheck` と `npm run build` を通す

## 指標（毎月確認）

| 指標 | 3か月後 | 6か月後 | 12か月後 |
|---|---|---|---|
| 記事数 | 60 | 120 | 200 |
| 検索からの訪問（月） | 1,000 | 8,000 | 30,000 |
| 広告クリック（月） | 50 | 600 | 3,000 |
| 報酬（月） | 初成約 | 10万円 | 50〜100万円 |

数値は目安。3か月後に訪問が伸びていなければ、キーワードの選び方を見直す。
