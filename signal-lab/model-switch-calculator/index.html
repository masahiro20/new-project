API の使用量データを貼り付けると、全トラフィックを別モデルに移した場合の月額コストを試算します。対応: Anthropic Console CSV / Admin API JSON、OpenAI 使用量 CSV / Admin API JSON、汎用 CSV。

プライバシーデータはこのブラウザの中だけで処理され、外部には送信されません。このページは外部への通信を一切行いません。
