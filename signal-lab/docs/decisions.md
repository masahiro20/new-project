- 2026-10-09 決定：Model Switch Calculator v2（calc/）に Google Gemini を 11 モデル追加し、Gemini 3.8 Flash／3.5 Flash-Lite／3.1 Pro Preview の 3 つを主要モデル（初期選択）にする。残りの 3.7 Flash、3.6 Flash、3.5 Flash、3.1 Flash-Lite、3 Flash Preview、2.5 Pro、2.5 Flash、2.5 Flash-Lite は「Older models」に入れる。理由：2026-10-09 に公式ページ（ai.google.dev/gemini-api/docs/pricing、最終更新 2026-10-07）でテキスト系 API モデルとして確認できたため。Live／TTS／画像／埋め込みはトークン単価の比較に合わないので除外する。
- 2026-10-09 決定：Gemini の価格は Paid tier・Standard・テキスト／画像／動画入力の単価にそろえる。Pro 系（3.1 Pro Preview、2.5 Pro）はプロンプト 200K トークン以下の階層を使う。3.8／3.7／3.6 Flash は 2026-12-31 までのプロモ価格（$0.75／$3.75、キャッシュ $0.075）を入れ、2027-01-01 からの価格（$1.50／$7.50／$0.15）を note に書く。理由：既存の OpenAI（272K 以下）、Haiku 5.5（100K 以下）と同じく「標準階層のみ」の方針に合わせるため。
- 2026-10-09 決定：Gemini 宛ての計算では、キャッシュ書き込みトークンを入力単価で数え、キャッシュ保存料（100 万トークン×時間ごと）は計算に入れない。cacheWrite は null にする。理由：Gemini にはキャッシュ書き込み単価がなく、保存料はトークン量ではなく保持時間で決まるため、利用エクスポートからは計算できない。
- 2026-10-09 決定：Anthropic と OpenAI の 24 行を公式ページで再確認したところ、価格の変更はなかった。数値はそのままにして、PRICES.checkedOn だけ 2026-10-09 に更新する。理由：今日公式ページで確認した内容だけを verified とする方針のため。
- 2026-10-09 決定：共有リンクの形式は URL ハッシュ `#s=<base64url(JSON)>` とし、バージョンは v:1 とする。中身は設定（期間、キャッシュ維持、比較モデル、手入力価格）と集計トークン量（合計、価格表 ID ごとの内訳、価格表にないモデルを合算した "other"、日数）だけにする。貼り付けた生データ、日付、価格表にないモデル名は入れない。理由：ハッシュはサーバーに送られず、CSP（通信なし）とも両立するため。また、利用量が分かることを共有前に開示して同意を得られるため。
- 2026-10-09 決定：共有リンクの復元時は、ハッシュ長 8000 文字まで、トークン 1e15 まで、日数 3660 まで、価格 10000 USD/1M トークンまでに制限する。リストは 200 件まで、未知の ID は無視（トークンは "other" に移す）し、負の数・非有限値・文字列の数値は捨てる。復号した文字列は価格表 ID の照合にだけ使い、HTML には出さない。理由：悪意あるリンクによる HTML 注入、極端な値、プロトタイプ汚染を防ぐため。
- 2026-10-09 決定：「Cheapest」は表示精度（セント単位）で最小額に並ぶすべてのモデルに付け、総利用量が 0 のときはどのモデルにも付けない。理由：同額で表示されるモデルの片方だけにバッジが付くと誤解を招き、利用量 0 では「最安」に意味がないため。
- 2026-10-09 決定：価格表で主要モデル以外のグループ名を「Older models」から「More models」に変える。理由：o3／o4-mini などについて、公式価格ページが「旧モデル」と表記していないため。
- 2026-10-09 決定（Atlas R3-03）：Vercel Spend Management の 100% 通知だけでは停止しない。通知を受けたらその場で利用額を取り直し、Budget Guard の予算に達していれば停止する（従来の判定と同じ）。Vercel の通知だけで止めたい人のために、接続ごとのオプトイン「Vercel の 100% 通知でも止める」を用意し、初期値はオフとする。理由：利用者が Vercel 側に置いた予算が Budget Guard の予算と違うと、予期しない本番停止になるため。止める操作は取り消せるが、本番が止まる影響が大きいので、明示した場合だけにするのが安全側である。lp.md と bg/ の記述もこれに合わせて直す。
- 2026-10-09 決定（Atlas R2-05）：Stripe モードでも、メールの索引が有効な Stripe の権利を指している間は、新しい購入で上書きしない（デモと同じ扱い）。前の権利が終了・返金・削除済みなら上書きする。新しい購入は、成功ページとライセンスキーで使える。理由：他人のメールで購入すると、その人のログインリンクの行き先を変えられるため。根本対策はメールの所有確認だが、購入の流れが変わるので今回は見送る。悪用には実際の支払いが要るため、上書きを止めるだけで十分と判断した。
- 2026-10-09 決定（ピーター判断）：料金表の「Hourly checks」を、実装の段階表どおりの文に直す（全接続の合計が50件までは毎時、それ以上は2〜12時間）。「Two months free」は削除する。年払いは実装上は作れるが、Stripe での動作を確かめていないので、Yearly は「年払いは準備中」とし、購入できないようにする。理由：Stripe と実装の両方で本当に使える場合だけ残す、というピーターの条件を満たさないため。また、実際の差額（$29、約3.2か月分）とも合っていなかった。
