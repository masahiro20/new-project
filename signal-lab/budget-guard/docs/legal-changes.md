| **終了後30日で削除する** | **終了の判定**：<br>・Stripe：権利が `canceled`・`refunded`・`unpaid` になった時（`setStatus` が `endedAt` を書く。再開すると消す）<br>・デモの購入（＝試用）：購入から30日（`TRIAL_DAYS`）。その前にサイトがデモモードでなくなったら、その時点（最初に検知したときに `endedAt` を書く）<br><br>**試用が終わったら**：監視とダッシュボードへのアクセスを止める（`trialEnded`）。<br><br>**削除の対象**：終了した権利と、すべてのデモの権利を集合 `retention` に入れておく。cron の作業リストを作る回が、6 時間ごとにこれを調べ、終了から30日を過ぎたアカウントを 1 回に最大 2 件消す（6 コマンド／件）。<br><br>**消すもの**：接続（暗号化トークン・webhook の秘密）、状態、所有者の索引、Slack URL（設定）、アクティビティ（ログ・スナップショット）、cron の索引、ライセンスとメールなどの逆引き、デモの購入記録。<br><br>**残すもの**：最小限の権利の記録（墓標）。ID、プラン、種類、状態、日付、同意の記録。Stripe の場合は、Stripe 側の支払い記録と突き合わせるための customer・subscription・payment intent の ID。メールアドレスとライセンスキーは残さない。墓標は、同じ Stripe のチェックアウト ID から権利が作り直されるのも防ぐ。 | `lib/entitlements.ts`、`lib/guard/retention.ts`、`lib/guard/cron.ts` |
| **アカウント全体の削除（依頼から7日以内）** | `POST /api/admin/accounts/delete`。本文は `{id}`、`{email}`、`{licenseKey}` のどれか。認証は既存の `Authorization: Bearer $ADMIN_TOKEN`。消し方は自動削除と同じ。**Stripe のサブスクリプションは解約しない**ので、先に Stripe で解約する（まだ課金中なら、応答に警告を返す）。 | `app/api/admin/accounts/delete/route.ts`、`lib/admin-auth.ts` |

- **残っている問い（専門家）**：
  - 購入記録を税務・会計のために、どこまで・いつまで残すか。今は上の最小限の記録を期限なしで残している。
  - Stripe 側のデータ（メール、カードの情報、customer の metadata にあるライセンスキー）と、Resend の送信記録は、このアプリの削除の対象外。これを本文でどう書くか。
  - 同意の取り方（チェックボックスとリンク）で有効か。同意しない人は購入できない扱いでよいか。
- **テスト**：`tests/consent-retention.test.ts`。確かめていること：
  - 同意なしで 400
  - 版が古いと 403 になり、再同意で解除される
  - 終了から29日では残り、30日を過ぎると消える。再開したら消えない
  - デモは60日後に消える。デモモードを止めた場合は、止めた日から30日後に消える
  - 1 回の削除は最大 2 件
  - admin の手動削除
- **workerd の Playwright で確認**：購入ボタン・カード画面・接続の追加が、チェックするまで押せない。`/api/checkout` に同意なしで送ると 400。同意したあと、購入から live までの流れが通る。
