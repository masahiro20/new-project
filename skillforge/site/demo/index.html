Kotomark 台本チェッカー

Kotomark（仮称）台本の揺れチェッカー

日英ゲーム台本の訳揺れ・表記揺れ・キャラ名・敬称・口調をまとめて点検します。JA↔EN script consistency checker

台本 Script

CSV / TSV / Excel (.xlsx) / JSON / XLIFF / gettext (.po)。Unity・Unreal の文字列テーブルにも対応。ファイルは複数選択・ドラッグ＆ドロップ可。表は ja / en（または source / target）列が必要です。ja.json と en.json のような言語別ファイルはキーで自動的に対にします。

    用語集・キャラ設定 Glossary (optional)

    JSON・CSV/TSV（Crowdin・Phrase などの用語集エクスポートも可）・TBX。省略しても表記揺れ・話者名・タグ等は検出できますが、訳揺れ・敬称・口調のチェックには用語集が必要です。

    指摘の言語 messages：

    すべての処理はこのブラウザ内で行われます。台本や用語集はどこにもアップロードされません。Everything runs in your browser; nothing is uploaded.

    Kotomark（仮称） — 作業名です。指摘メッセージと Markdown レポートは日本語・英語を切り替えられます（「指摘の言語」）。Messages and the Markdown report are available in Japanese or English.
