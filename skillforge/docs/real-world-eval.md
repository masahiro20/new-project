- カタカナ表記揺れ（例：ユーザ／ユーザー、プレイヤー／プレーヤー、ウィンドウ／ウィンドー）は、ラベルを付けた97件すべてが本物でした。

## 方法

- **設定A：** 用語集なし（`--no-glossary`）。
- **設定B：** 自動作成した用語集（`kotomark draft`）を使って検査。実際の使い始めに近い設定です。
- **ラベル付け：** 指摘ごとに原文と訳文を見て、「ローカライズの QA 担当者として指摘してほしいか」で TP（本物）／FP（誤検知）／判断保留 に分けました。判断保留は精度の計算から外しています。
  - 1回目：指摘が80件以下なら全件、それ以上は乱数で80件（シードは各 source.md に記載）。
  - 2回目（改善後）：1ファイル1設定あたり最大50件。ルールごとに最低3件を含めて抽出（シード 20261010、458件）。
- **見逃し：** 各ファイルから乱数で60エントリを選び、手で確認しました。
- **精度** = TP ÷（TP ＋ FP）。

## 改善したこと

1回目で見つかった誤検知のパターンを、エンジン側で直しました（テストを追加済み）。

- 表示用の `[none]`→`[なし]`、`<unknown>`→`<不明>` をプレースホルダーやタグと誤判定していた件
- 「40% defense」を printf の `% d` と誤判定していた件。Wesnoth の `$var` 形式に対応
- .po の複数形（日本語は1形）で、`{num}` などを毎回「不足」と判定していた件
- カタカナの揺れを広く拾うようにした（プレイヤー／プレーヤー、ウィンドウ／ウィンドー）。間投詞（アアァ）は対象外。複合語での矛盾した助言を解消
- 英→日ファイルでの敬称（「Kalenz 様」「王子」「師匠」）、曲がったアポストロフィ（Li’sar）
- 未翻訳・fuzzy・原文のままの行を、行ごとの指摘として追加
- 用語集の自動作成を厳しくし、無関係な語の組み合わせ（Modify→チャンネル など）を除外。自動用語集からの指摘は「情報」に
- 2回目の QA を受けて：日本語で斜体を外しただけの指摘を「情報」に、丁寧さの指摘を「キャラのプロフィールで指定したときだけ」に変更

## 正直な限界

- **ラベルは1人の評価者（サブエージェント）が付けました。** 口調や用語の判断保留は主観を含みます。
- **未翻訳・fuzzy の指摘が大きな割合を占めます**（SuperTuxKart の未翻訳160件、Wesnoth UI の未翻訳94件・fuzzy 98件）。これらを除いた精度も上に併記しています。
- **見逃し：** 1回目に見つけた見逃し35件のうち、改善後に拾えるようになったのは14〜15件です。残りは次のとおりです。
  - 漢字とかなの揺れ（事／こと、下さい／ください、既定／規定）は未対応
  - 用語集にない訳語の揺れ（Remove が 削除／除去 など）は、自動用語集が厳しくなった分、拾いにくくなりました（自動用語集の指摘のうち、1回目の本物15件は出なくなった）
  - 訳文に英語が残っている単語（Donate など）
- **用語の指摘は用語集の質に左右されます。** 自動用語集は「下書き」で、人が確認してから使う前提です。
- 英→日の .po 6本が中心です。日→英は Misskey の UI 文字列と合成台本だけで、実際のゲーム台本での検証はまだです（下の「日→英の検証」を参照）。

## 調整に使っていないデータでの測定・1回目（2026-10-09）

調整に一度も使っていない5プロジェクト（Freeciv、Warzone 2100、SuperTux、Mastodon、Excalidraw）で、エンジンのコードを読まない評価者が `--no-glossary` の1設定だけを測りました。詳細は `eval/heldout/`。

| 範囲 | 正しい / 誤検知 | 精度 |
|---|---|---|
| 警告・エラー全体 | 187 / 58 | **0.76** |
| 未翻訳ルールを除く | 28 / 58 | 0.33 |
| カタカナ表記揺れ | 18 / 0 | 1.00 |
| 未翻訳・fuzzy | 159 / 0 | 1.00 |
| プレースホルダー | 10 / 47 | 0.18 |
| タグ | 0 / 11 | 0.00 |

- 誤検知58件のうち55件は、YAML・JSON の言語別ファイルを組み合わせるとき、原文の向きを逆に取り（英語が原文なのに日本語側を原文とした）、片方にしかないキーをプレースホルダーやタグの誤りとして出したものです。
- 残りは、gettext の `%2$s` のような順番指定（正しい書き方）を誤りとした2件などです。
- **調整に使ったデータでの 190/190 と比べて大きく低く、調整したデータでの数字は実力を過大に見せることが分かりました。** LP の主な数字は、この値に差し替えました。
- これらの誤りは修正中です。修正後の数字は、さらに別の未使用データで測り直します（今回の5本は、修正に使った時点で「未使用」ではなくなるため）。
