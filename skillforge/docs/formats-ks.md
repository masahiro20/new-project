# KAG / TyranoScript のシナリオファイル（.ks）

吉里吉里（KiriKiri）の KAG3 と TyranoScript（ティラノスクリプト / ティラノビルダー）のシナリオ `.ks` を読む方法をまとめます。実装は `src/core/parsers/ks.ts`、テストは `test/formats-ks.test.ts`、サンプルは `samples/formats/ks/scenario/{ja,en}/first.ks` です。

## 1. 調べたこと（公式ドキュメントより）

参照したもの：

- TyranoScript タグリファレンス：https://tyrano.jp/tag/
- KAG3 の解説：https://kirikirikag.sourceforge.net/contents/Letter.html（文字の表示）、https://kirikirikag.sourceforge.net/contents/Diverge.html（ラベル）、https://kirikirikag.sourceforge.net/contents/Tags.html（タグリファレンス）

| 書き方 | 意味 | 出典 |
|---|---|---|
| `*label` / `*label\|見出し` | 行頭の `*` がラベル。`\|` の後ろはセーブデータに出る見出し（省略可）。ラベル名に空白は入れない | KAG3 Diverge |
| `;` | 行頭の `;` は1行コメント | KAG3 Letter / Tyrano |
| `/*` … `*/` | 複数行コメント（Tyrano。`/*` と `*/` はそれぞれ単独の行） | Tyrano |
| `[tag 属性=値]` | タグ。値は `"…"`、`'…'`、引用なしのどれでも書ける | 両方 |
| `@tag 属性=値` | 行頭の `@` は1行に1つのタグ（`@cm` と `[cm]` は同じ） | KAG3 Letter |
| `[[` | 文字としての `[`（`]` はそのままでよい） | KAG3 Letter |
| 行末 | KAG3 以降、ソースの改行では改行しない。改行は `[r]`（`Config.tjs` の `ignoreCR` で旧動作に戻せる）。Tyrano も同様 | KAG3 Letter |
| 行頭のタブ | KAG3 では無視（空白は無視されない）。Tyrano は行頭の空白を無視し、空白を入れたいときは `_` を先頭に置く | KAG3 Letter / Tyrano |
| `[l]` | クリック待ち（ページは消えない） | 両方 |
| `[p]` | クリック待ちのあと改ページ | 両方 |
| `[r]` | 改行 | 両方 |
| `[cm]` / `[er]` / `[ct]` | 文字を消す（全メッセージレイヤ / 現在のレイヤ / 全部消して message0 に戻る）。`[cm]` などは `[font]` の設定も戻す | 両方 |
| `[ruby text=かん]漢` | **直後の1文字**にルビを付ける。複数の文字には1文字ずつ `[ruby]` を置く | KAG3 Tags / Tyrano |
| `[emb exp=f.name]` | 式（TJS / JavaScript）の値を文中に埋め込む。変数の表示に使う | 両方 |
| `[font …]` / `[resetfont]` | 文字の装飾を変える / 既定に戻す | 両方 |
| `[style …]` / `[resetstyle]` | 行の体裁（揃え・行間など） | KAG3 |
| `[graph storage=…]` | 文中に画像（絵文字など）を出す | 両方 |
| `[mark]` / `[endmark]` | 蛍光ペン風の強調（Tyrano） | Tyrano |
| `[ch text=…]` / `[hch text=…]` | 文字を1つ表示 / 縦中横 | KAG3 |
| `[iscript]` … `[endscript]` | スクリプト（TJS / JavaScript）のブロック。KAG3 ではそれぞれ単独の行 | 両方 |
| `[macro name=…]` … `[endmacro]` | 新しいタグの定義。中身はその場では実行されない | 両方 |
| `#名前` / `#名前:表情` / `#` | 話者名の欄に名前を出す（表情も変える）。`#` だけで名前を消す。`[chara_ptext name=… face=…]` の省略形 | Tyrano |
| `[chara_new name=akane jname=あかね]` | キャラクターの定義。`jname` が名前欄に出る表示名 | Tyrano |
| `[glink text=… target=*…]` | 文字の選択肢ボタン | Tyrano |

KAG3 には話者の決まった書き方がありません（作品ごとのマクロ、`【名前】` の行など）。

多言語化は、シナリオを言語ごとに複製するのが一般的です（`data/scenario/ja/first.ks` + `data/scenario/en/first.ks`、`first.ks` + `first_en.ks` など）。ラベルとタグの構成は揃えたまま、文だけを訳します。

## 2. 「文のまとまり」（1行 = 1単位）の決め方

1つの `.ks` を、**ページ単位の文のまとまり**に分けて、1まとまりを表の1行にします。

- まとまりは、最初の文の行から **`[p]`** までです。`[cm]` `[er]` `[ct]`、話者の行（`#…`、`[chara_ptext]`）、ラベル、ファイルの終わりでも区切ります。
- **`[l]` では区切りません。** 1ページの中で `[l]` をどこに置くか（行の分け方）は訳者が変えることが多く、`[l]` で区切ると以降の対応がすべてずれるためです。`[p]` の数はふつう原文と訳で揃っています。
- `[bg …]` `[playse …]` のような文を含まないタグだけの行や空行は、まとまりを区切りません。
- `[glink]` `[ptext]` `[mtext]` の `text` 属性は、画面に出る文字なので、それだけで1つのまとまりにします（文脈に `[glink]` と書きます）。
- ID は `ラベル名#番号`（番号はラベルの中で1から）。最初のラベルより前の文は `(top)#1` です。同じラベル名が2回出てきても番号は続けて数えるので、ID は重複しません。
- 行番号は、まとまりの最初の文の行です。
- 話者は `#名前`（`:表情` は外します）か `[chara_ptext name=…]`。同じファイルに `[chara_new name=akane jname=あかね]` があれば表示名に置き換えます。話者は `#` で消すまで続きます（Tyrano と同じ。ラベルでは消します）。
- 文脈には `*ラベル|見出し`（見出しがあるとき）を入れます。

## 3. 文の中のタグの扱い

既存のルール（タグ・プレースホルダー・ルビ）がそのまま使えるように、行の文字列は次のように持ちます。

| ソース | 行の文字列 | 理由 |
|---|---|---|
| `[ruby text=かん]漢` | `{漢\|かん}` | ルビの検査（読みが仮名か、壊れていないか、英語側に残っていないか）と、表示文字列（`漢`）での用語照合がそのまま効きます。KAG のルビは1文字ずつなので `[ruby text=ま]魔[ruby text=どう]導…` は `{魔\|ま}{導\|どう}…` になり、表示文字列は `魔導…` です。 |
| `[ruby text=]漢`（読みが空） | `{漢\|}` | `ruby.malformed`（読みが空）として出ます。 |
| `[ruby text=よみ]` の直後に文字が無い | `{\|よみ}` | `ruby.malformed`（親文字が空）。 |
| `[emb exp=f.name]` / `[emb exp='f.name']` | `[emb exp="f.name"]` | 引用符を揃えてから、プレースホルダーとして比べます（`text.ts` の `PLACEHOLDER` に `[emb exp=…]` を追加）。訳で落とすと `placeholder.mismatch` です。式に `"` を含むときは `'…'` で書きます。 |
| `[r]` | 改行 | 改行の位置は訳者が決めるもので、比べません。 |
| `[font …]` `[resetfont]` `[style …]` `[resetstyle]` `[graph …]` `[mark …]` `[endmark]` `[indent]` `[endindent]` | 書かれたまま | `.ks` の表では名前だけを比べます（`[font]` が落ちれば `tag.mismatch`）。値の違いは指摘しません。`[font]` は `[resetfont]` のほか `[cm]` などでも戻るので、閉じ忘れの検査（`tag.unbalanced`）はしません。表示文字列からは除きます。 |
| `[ch text=！]` `[hch text=12]` | `！` `12` | 表示される文字そのものです。 |
| `[l]`、`[wait]` `[delay]` `[nowait]` などの間の取り方、`[playse]` `[bg]` `[jump]` などの演出 | 除く | 文ではありません（Ren'Py の `{w}` などと同じ考え方）。 |
| `[[` | `[[` のまま | Ren'Py の `[[` と同じく、文字としての `[` として扱われます。 |
| 2行にまたがる文 | 日本語の側では何も挟まずにつなぎ、英字どうしは空白1つでつなぐ | エンジンはソースの改行を無視します。英語では用語の照合のために空白を入れます。 |

**ファイル上の行との対応：** ルビだけは書き方を変えますが（`{漢|かん}`）、行番号はまとまりの最初の行で、メッセージにも親文字と読みが出るので、ソースの場所はすぐ分かります。ほかのタグは書かれたままか、表示されないものです。

`text.ts` で変えたこと（ほかの形式への影響は最小限）：

- `PLACEHOLDER` に `[emb exp=…]` を追加。
- 表示文字列（`visibleText`）から、属性付きの `[font …]` `[style …]` `[graph …]` `[mark …]` `[indent …]` と `[resetfont]` `[resetstyle]` `[endmark]` `[endindent]` を除く。属性の無い `[font]` `[style]` などは、ほかの形式では表示用の文字かもしれないので残します。
- `rules.ts`：形式が `ks` の表に限り、上の装飾タグを名前で比べ、プレースホルダーの比較からは外します（`[resetfont]` が「`[word]` 形式の埋め込み」と誤認されないように）。

## 4. 2つのファイルの組み合わせ

- 1つの `.ks` は1言語の表（`singleLang`）です。言語はパスの言語名（`scenario/en/first.ks`、`first_en.ks`）から、無ければ中身から決めます。
- `loadInputs` が日本語と英語の表を組み合わせます。組み合わせ方はほかの1言語ファイルと同じで、言語の部分を伏せた名前（`ja/first.ks` ↔ `en/first.ks`、`first_ja.ks` ↔ `first_en.ks`）、1つずつしか無ければその2つです。`.ks` だけは、言語名の無い原文と `_en` 付きの訳（`first.ks` ↔ `first_en.ks`、`scenario/first.ks` ↔ `scenario/en/first.ks`）も、言語名を取り除いた名前が一致すれば組み合わせます。
- 対応は ID（`ラベル#番号`）で取ります。向き（どちらが原文か）は `pairDirection`（キーの多い方が原文、次に base/default などの名前、最後は日本語）で、`--source-lang` で固定できます。
- **行の場所は訳文のファイルと行**です（Ren'Py と同じく、直すのは訳文なので）。表の名前は `scenario/ja/first.ks+en/first.ks` ですが、各行の `file` は訳文のファイル（`scenario/en/first.ks`）、文脈に `ja: scenario/ja/first.ks:12` と原文の場所を書きます。**原文側の指摘**（原文のルビ、話者名の揺れなど）は、行の `sourceRef` を使って原文のファイルと行を指します（`runChecks` が付け替えます）。
- 片方にしか無いまとまりは、`Row.missing` で表します。訳文に無ければ `untranslated.empty`（警告、場所は原文）、原文に無ければ `untranslated.extra-key`（情報、場所は訳文）。
- ラベルの中のまとまりの数が違うときは、注意（note）に `*stacks (4 / 3)` のように出し、そのまま番号で対応させます。ページを分けたり合わせたりした後ろのまとまりはずれることがあります。片方にしか無いラベルも注意に出します。
- 相手の無い `.ks` は単独で検査します（原文側のルールだけ）。

## 5. 文字コード

UTF-8（BOM 可）、BOM 付き UTF-16（LE/BE）、Shift_JIS（UTF-8 として不正なとき。注意が出ます）を読みます。既存の `decodeText` を使います。ブラウザのデモも Shift_JIS を読めます。MCP には文字列で渡すので、呼び出し側で変換済みです。

## 6. 制限

- 話者は Tyrano の `#名前` と `[chara_ptext]` だけです。KAG3 の作品ごとの話者マクロ（`[nm t=…]` など）や `【名前】` の行は読みません（文の一部になります）。
- 対になったファイルの話者は原文側のものを使います。訳文側の話者名（`#Lisette` と `#Lizette` の揺れなど）は検査しません。
- `[chara_new]` の表示名は同じファイルの中だけで探します（別のファイルで定義していれば `#akane` のままです）。
- `[if]` … `[endif]` の中の文は、条件に関係なくすべて読みます。`[link]` … `[endlink]` の中の文は普通の文として読みます。
- マクロ（`[macro]` で作ったタグ）の中身は展開しません。文を出すマクロ（例：`[say text=…]`）は読めません。
- 文中の `{` `|` `}` は、ほかの形式と同じく `{0}` のような埋め込みや `{漢|かん}` 形式のルビとして読まれることがあります。
- KAG3 の旧動作（`ignoreCR=false`。ソースの改行がそのまま改行になる）は考えません。
