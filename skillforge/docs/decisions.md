| 2026-10-09 | 用語集は Kotomark JSON に加え、TBX（v2 martif / v3 tbx）と CSV/TSV の用語ベース書き出し（Crowdin・Phrase 形式、ja,en 列）を読み込む。言語名で列が分かれる形式は台本の方向に合わせて読み、preferred→訳語・admitted→許容・deprecated/superseded→禁止とする。キャラ設定は TBX では表せないため JSON に残す | 翻訳会社・ローカライズ基盤の既存用語集をそのまま使えるようにするため。XML は依存なしの小さな読み取り器で読む（src/core をブラウザ安全に保つため） |

| 2026-10-09 | Ren'Py のテキストタグと埋め込みを規則検査で解釈する。`{/名前}` と `{名前=値}`（名前が Ren'Py のタグ名一覧にあるもの）はどの形式でも常にタグ。裸の `{b}` `{w}` などは、Ren'Py の表か、同じ原文・訳文の組に `{/名前}` か `{名前=値}` があるときだけタグとし、それ以外（CSV/JSON の `{b}` `{0}` `{name}`）は従来どおりプレースホルダー。`{w}` `{p}` `{nw}` `{fast}` `{done}` `{clear}` は比べない。値付きタグは名前だけ比べる。`{s}` は強調扱いにしない（HTML の `<s>` と同じ）。`[[` は常に文字の `[`、`{{` は文字の `{` だが `{{name}}` は i18next/Mustache のプレースホルダーとして残す。`[名前!t]` `[名前:.2f]` はフラグ・書式込みで一致を見る | `{/b}` や `=` 付きのタグはプレースホルダーには現れないので曖昧さが無い。裸の `{b}` は他形式で添字のプレースホルダーとして使われうるため、根拠があるときだけタグにする。`{{name}}` は JSON ロケールで広く使われるため壊さない |
| 2026-10-09 | P1 の名前 Kotomark と Action リポジトリ名 kotomark-action は「使える（暫定）」とする。代替案は 1番目 YureLint、2番目 Honorifix（docs/name-check-kotomark.md） | npm・PyPI・crates.io・GitHub・Marketplace・ウェブ・ドメイン（kotomark.com ほか）で衝突が見つからないため。ただし J-PlatPat などの商標登録簿は自動で見られず未確認。正式公開の前にオーナーが J-PlatPat で称呼「コトマーク」（第9類・第42類）を確認する。似た名前のコトバンク・Kotozna（翻訳アプリ）は混同の恐れは低いと見るが要確認 |
