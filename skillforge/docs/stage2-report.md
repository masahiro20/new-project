## 作ったもの（`skillforge/`、ルートの「減算ゼロ」には未変更）

- **製品の仮称は「Yuragi（揺らぎ）」**です。商標調査はまだで、名前に「Claude」は使っていません。
- **一貫性チェックのエンジン**（`src/core`）
  - **入力:** CSV、TSV、JSON、XLIFF 1.2 / 2.0 と用語集（JSON または CSV）。日→英、英→日のどちらの向きも自動で判定します。
  - **出力:** `ファイル名:行番号` 付きの Markdown レポートと JSON です。
  - **中核の検査**
    - 用語の訳揺れ。使われた訳語ごとの件数も出します。
    - カタカナの表記揺れ（サーバー／サーバ、ルーンゲート／ルーン・ゲートなど）
    - キャラ名の揺れ。禁止表記、綴りの近い誤記、話者ラベルの揺れを見ます。
    - 敬称の揺れ。話者→相手ごとの訳し方のばらつき、敬称方針（keep / localize）への違反、原文側の呼び方の変化を見ます。
    - 口調の揺れ。一人称、丁寧さ、英語の短縮形、使わない語を見ます。
  - **おまけの検査:** プレースホルダー、タグ、ルビ、文字数
- **判断が要る箇所は「レビュー用パケット」にまとめます。** キャラごとの口調や、用語集にない繰り返し語が対象です。判断はユーザー自身の Claude が行います。
- **リモートMCPサーバー**（`src/server`）
  - Streamable HTTP で、状態を持ちません。台本は保存せず、ログにも本文を残しません。
  - 認証は Bearer トークンです。
  - ツールは `check_script`、`get_review_packets`、`validate_glossary` と、プロンプト `review-script` です。
  - 当社側で判断する機能は初期状態でオフです。当社のAPIキー（`YURAGI_ANTHROPIC_API_KEY`）を設定したときだけ有効になります。ユーザーの認証情報は受け取りません。
- **薄い Claude Code プラグイン**（`plugin/`）: スキル、`/lqa-check` コマンド、`.mcp.json` の3つです。
- **その他**
  - **自作サンプル:** 日→英の台本 CSV と JSON、英→日の XLIFF です。実在作品の文章は使っていません。
  - `docs/sample-report.md` に、サンプルを検査した結果のレポートがあります。
  - README があります。
  - LP 原稿 `docs/lp.md` があります。未公開で、公開前に確認が必要な主張の一覧を付けています。

## テスト結果

- `npm test` は **38件すべて成功**しました。内訳は次のとおりです。
  - 読み込み（パーサー）
  - 各検査
  - レビュアー指摘の回帰テスト
  - MCP を HTTP 越しに通したテスト（認証の拒否を含む）
- `tsc` の型チェックとビルドも通りました。
- **レビュアー（サブエージェント）の指摘:** 重大4件と中程度7件を受け、すべて修正しました。
  - **重大:** 英→日の表の列の向きの誤判定、XLIFF の `<bpt>` 誤検出、XLIFF 2.0 の複数セグメント、`<br>` 誤検出
  - **中程度:** CSV の閉じていない引用符、性能、複数形と改行、ありふれた英単語を名前の誤記と誤検出する件、名前の大小文字、一人称の取りこぼし、`名前` 列の扱い
  - **軽微:** 一部を修正しました（殿下、ますます、ルビの属性、printf 書式）。
- **性能:** 2万行×用語200件で、約16秒が0.6秒になりました。
