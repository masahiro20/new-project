# Kotomark（仮称）試用協力候補リスト（草案）

> **社内用です。まだ誰にも連絡していません。** このリストは「声をかける候補」の下調べで、送信の許可ではありません。
> 実際に連絡するときは `outreach-templates.md` の「使い方の注意」に従い、宛先と文面の両方について1通ずつオーナーの承認を取ってから送ります。
> ステージゲート：外部の試用者5名。

---

## 1. 調べ方

- **調査日：** 2026-10-09
- **使った情報：** 公開情報だけです。各社・各団体の公式サイト、公開の求人・講座告知、業界ニュース記事（gamebiz、Gematsu、GameBusiness.jp など）、公開のイベント・コミュニティページを見ました。
- **やっていないこと：** 誰にも連絡していません。アカウントは作っておらず、どこにも投稿していません。個人のメールアドレス・電話番号・私的なSNSアカウントも集めていません。連絡先の欄には、会社・団体の**一般的な問い合わせページのURL**（フォーム、または一般窓口が書かれたページ）だけを載せています。
- **存在の確認：** 各候補の公式サイトを 2026-10-09 に開き、表示されることを確かめました（HTTP 200、またはページの中身を取得）。確かめられなかった点は表の中に **【未検証】** と書いています。
- **選び方：** 小規模〜中規模で、日英（英日）のゲームの仕事が公開情報から分かる相手を優先しました。大手（Keywords、PTW/Side、Lionbridge など）は、試作品を試してもらえる見込みが低いので外しました。

### 表の見方

- **区分：** a = ローカライズ会社・LQA会社、b = パブリッシャー（日→英、または英→日で出している）、c = ファン翻訳・オープンソースのコミュニティ（**非商用の意見集めだけ**に使う）、d = 大学・翻訳学校
- **規模：** 小 = 数名〜20名程度、中 = 数十名〜数百名、大 = それ以上（公開情報からの推定）
- **適合度：** 1〜5（5がいちばん合う）
- **テンプレ：** `outreach-templates.md` の 1 = ローカライズ会社向けの初回メール、2 = インディー向けの短いDM、3 = 紹介経由（共通の知人がいる場合だけ）。d区分はテンプレ1を学術向けに書き換えて使う想定です。
- **ファイル形式の注意：** Kotomark が読めるのは CSV/TSV、XLSX、JSON、XLIFF 1.2/2.0、gettext PO、YAML、Ren'Py の翻訳ファイル（`game/tl/`）、Unity/Unreal の文字列表です（2026-10-09 時点）。TyranoScript（`.ks`）と吉里吉里の台本は**まだ読めない**ので、該当する相手には書き出しの手間が懸念点になります。

## 4. 注意（送信前に必ず読む）

1. **送信はオーナーの承認を取ってからです。** このリストは下調べで、連絡の許可ではありません。宛先と、個別に書き換えた文面の両方について1通ずつ承認を取ります。一斉送信はしません。
2. **特定電子メール法（日本）：** 広告・宣伝にあたる可能性があるメールは、原則として相手の事前の同意が必要です。例外は、相手が**自分のアドレスをウェブサイトなどで公表している場合**などに限られ、その場合も「広告メールお断り」と書かれていれば送れません。各社の問い合わせページに営業メールお断りの記載がないかを、送る前に必ず確認します。送信者の氏名（名称）、連絡先、配信停止の方法を本文に書きます。
3. **営業メールの規制（海外）：** 米国は CAN-SPAM（送信者の明記、配信停止の方法、申し出から10営業日以内に停止、所在地の記載）。オーストラリア（UQ）は Spam Act 2003 で、原則として同意が必要です（公表された業務用アドレスへの、その業務に関係する連絡は「推定同意」になりうるが、要確認）。
4. **GDPR（EU・英国。Fruitbat Factory、Shloc、Altagram、Level Up、Shinyuden、PQube、LocalizeDirect など）：** 連絡先は公開されている業務用の窓口に限ります。個人のアドレスを推測したり、個人のSNSに送ったりしません。連絡の根拠（正当な利益）を説明できるようにし、削除の求めがあれば連絡先リストから消します。英国は PECR、EU各国の電子通信の規制にも注意します。
5. **フォーム・SNSの使い方：** 問い合わせフォームに「営業目的の利用はお断り」とある場合は使いません。ユーザーサポート用の窓口（例：Flyhigh Works の「MAIL US」、TyranoScript の要望フォーム）は、試用の依頼に使うのが適切か、送る前に判断します。DM は、業務用アカウントがDMを受け付けている場合だけ送ります。コミュニティ（c区分）の公開の場には宣伝の投稿をしません。
6. **成人向けの作品を扱う相手（MangaGamer、Sekai Project、Shiravune など）：** 相手の作品名を連絡文に書くときは、全年齢の作品を選びます。当社のサンプルや資料に成人向けの内容を入れません。
7. **NDA と台本：** こちらから台本の送付を求めません。試用は付属のサンプルか、相手が選んだNDAに触れない抜粋で、相手の手元（ブラウザ版デモかローカル版）で行ってもらいます（`outreach-templates.md` の注意9、`data-policy.md`）。
8. **大学（d区分）：** 学生に試してもらう場合は、教員を通して、学生の任意の参加と、結果のデータの扱い（個人が分からない形での集計）を事前に合意します。
9. **【未検証】の項目：** 連絡の前に、相手の公式サイトでもう一度確かめます。特に Frognation、ロックハッチ、Sekai Project の連絡経路は未確認です。
10. **記録：** 断られた・停止を求められた相手は、すぐにこの表の行に「連絡不要」と書き、二度と送りません。フォローアップは1回までです。
