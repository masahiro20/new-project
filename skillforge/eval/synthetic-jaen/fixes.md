| 1 | `src/core/text.ts`（`enPhraseRegex`、`containsPhrase`）、`checks/terms.ts` | **英語の語形変化**。訳文側の照合（`loose=true`）に限り、最後の語の変化形を一致とみなします。複数形は両方向（notes ⇔ Note）、`-s/-es`、`-ed/-d`、`-ing`（e の脱落 Renote → Renoting、短い語の子音の重複 ban → banned）、y → ies/ied/ying です。`-ion` は語末が `-ct/-te` の場合だけ許可します（react → reaction、delete → deletion）。用語が `-ction/-ation` で終わる場合は動詞に戻して照合します（reaction → reacted、federation → Federating）。`station` → `state` のような短い語幹（5文字未満）は対象外です。`-er` は入れていません（Stone → Stoner は別の語）。原文側、禁止訳、キャラ名の照合は従来どおり厳密です。また、変化形で承認訳に一致した行でも、禁止訳が同じ行にあれば禁止訳を優先します（禁止訳が承認訳の変化形である場合に `term.forbidden` を失わないため）。 |

| 3 | `checks/voice.ts`（一人称） | `余`・`我`・`吾` を追加しました。余計・余裕・余り・我慢・我々 は一致しません。数字の後の 余（10余）も一致しません。**我が・吾が（我が国）と 我ら は数えません**。一人称が何であっても改まった場面で使われ、Wesnoth の .po で「私」のキャラの「我ら」を一人称の揺れとして拾ったためです（下記）。我々 も「we」なので数えません。プロフィールの `firstPerson` に書かれた語は、組み込みのリストになくても常に検出します（用語集全体のプロフィールから集めるので、ゼノの 余 はガルドの台詞でも拾います）。わたくし・わたし・あたし は、連体形の語尾 `[るたいなだのう]` の後でも許可しました（巫女である**わたくし**、戦う**あたし**）。渡し・私服・見わたして・まあたしかに・いたします は一致しません（テストあり）。 |
| 4 | `checks/voice.ts`（丁寧さ） | プロフィールで `politeness` が指定されたキャラに限り、文末の `〜る。` `〜ない。` `〜た。` `〜う。` `〜ている。` を常体とみなします。た は動詞らしいかなの後だけ（あなた・また は除外）、う は い/あ/わ の後と ろう/よう/こう だけ（ありがとう・おはよう・そう・どう は除外）です。プロフィールがないキャラ（多数決）は従来どおりで、判定は広げていません。 |

## 英→日の .po（6ファイル、設定 A `--no-glossary`）：回帰なし

godot-editor、luanti、pixelorama、stk、wesnoth/httt、wesnoth/lib のルール別の指摘数は、修正前と同じです。

途中の版では、wesnoth/httt の `voice.first-person`（情報）が 2 → 5 件に増えました。「私」と「我ら」を使うキャラの 我ら を一人称 我 と数えたためです（例：「私」が多数のキャラで「我」を少数派として、また「我ら」が多いキャラで「私」を少数派として指摘）。我ら は「we」で、話し手の一人称と関係なく改まった場面で使われるので、我が と同じく数えないことにしました。その結果、6ファイルとも修正前と同数に戻りました。

## 再現方法

```bash
cd skillforge
S=/tmp/synth; D=eval/synthetic-jaen; mkdir -p $S
# README.md の「方法」と同じ4回の check のあと
node $D/score.mjs --truth $D/truth.csv --clean-G $S/clean.G.json --drifted-G $S/drifted.G.json \
  --clean-A $S/clean.A.json --drifted-A $S/drifted.A.json --out $D/results.json --before $D/results.json
```

`--before` は、指定した results.json の `before`（なければ `configs`）を新しい results.json の `before` に引き継ぎます。Misskey は `eval/misskey/source.md` の手順で CSV と自動用語集を作り直して検査しました（自動用語集 draft.json は修正前に作ったものをそのまま使い、B の差がエンジンの照合だけによるものになるようにしています）。

## 限界

- 合成ベンチマークの見逃しは、README の「見逃しの上位3つ」をそのまま直したものです。同じ評価者が、正解を知ったうえで直しているので、再現率 1.00 は「修正が効いた」ことの確認にすぎません。実際の台本での再現率を示すものではありません。
- Misskey の修正後の精度は、修正前の抽出を絞り込んだ推定です。抽出数が減ったため（B 38件、C 50件）、誤差は大きくなっています。
- 丁寧さの判定を広げたのは、プロフィールで丁寧さを指定したキャラだけです。実データ（丁寧キャラの独り言、怒ったときに崩れる敬語など）で誤検知が増える可能性があり、まだ検証していません。
