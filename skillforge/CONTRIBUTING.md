# Contributing / コントリビューションについて

## 日本語

- **外部からのプルリクエストは、今のところ受け付けていません。** 届いた PR は読まずに閉じることがあります。
  Kotomark はソース公開（source-available）の製品で、コントリビューター契約（CLA）を用意していないためです。
- **Issue（不具合の報告・要望）は歓迎します。** リポジトリが公開されたら GitHub の Issue からお寄せください。
- **セキュリティ上の問題の報告先は未定です（TBD）。** 決まるまでは、公開の Issue に脆弱性の詳細を書かないでください。
- ライセンス：Action（`action/`）は MIT、エンジンと CLI は Elastic License 2.0 です。詳しくは `LICENSE`、
  `action/LICENSE`、`licenses/KOTOMARK-USAGE-TERMS.md`（下書き）を見てください。

## English

- **External pull requests are not accepted for now.** PRs may be closed without review. Kotomark is
  source-available and has no contributor license agreement (CLA).
- **Issues (bug reports, feature requests) are welcome** once the repository is public.
- **Security reports: the reporting channel is TBD.** Until it is set up, please do not post vulnerability
  details in public issues.
- License: the Action (`action/`) is MIT; the engine and CLI are under the Elastic License 2.0. See `LICENSE`,
  `action/LICENSE` and `licenses/KOTOMARK-USAGE-TERMS.md` (draft).
